# Объекты интерфейса

## Канвас

Бесконечная рабочая область с сеткой. Панорамирование — Space+drag / средняя
кнопка / тачпад; зум — Ctrl+колесо к курсору (0.05×–4.0×) или pinch. Тему
(тёмная/светлая), вид и плотность сетки можно поменять в настройках
(Ctrl+,). Всё, что вы раскладываете, хранится в `.canvas`-файле — обычном
JSON [JSON Canvas 1.0](https://jsoncanvas.org/spec/1.0/).

## Заметки

Создаются двойным кликом по пустому месту. Поддерживают инлайн-редактирование
(многострочность, выделение, Ctrl+C/X/V/A, кириллица) и markdown-подмножество:
`**жирный**`, `*курсив*`, `==подсветка==`. Цвет карточки — через палитру по ПКМ
(пресеты 1–6); цвет текста подбирается автоматически так, чтобы контраст
оставался читаемым. Карточка растёт под контент; точный размер — ручной resize
за правый нижний угол. В заметках работают формулы в стиле Numi — см.
[Расчёты](calculations.html).

## Файловые карточки

Перетащите файл из проводника — карточка появится на канвасе. Превью
строится по уровням детализации: иконка → тамбнейл → превью содержимого.
Двойной клик открывает файл ассоциированным приложением; ПКМ — «Открыть
папку с файлом», «Скопировать путь», «Переименовать». Если файл недоступен
(переименован, удалён, сетевой диск отвалился) — карточка помечается серой
рамкой «битой ссылки»; верните файл на место — карточка восстановится сама
(файловый вотчер следит за изменениями).

## Группы

- Выделите несколько нод (Ctrl+клик, рамка выделения от пустого места) и
  нажмите **Ctrl+G** — вокруг них появится группа.
- Перетащите ноду на группу — она «втянется» внутрь с короткой анимацией.
- ПКМ по группе → «Действия» → «Разгруппировать».

## Связи

Связь соединяет две ноды: потяните ЛКМ от порта одной ноды к другой.
Подпись — двойной клик по линии. Хэндлы на концах выделенной связи позволяют
перепривязать её без удаления. По умолчанию связь **сама выбирает порты по
кратчайшему пути** и пересчитывает их при перетаскивании нод и автораскладке;
закрепить конец можно через ПКМ по связи → «Порты». Вид связи настраивается:
стиль (сплошная/пунктир/точки), толщина (тонкая/обычная/толстая), цвет —
через палитру связи. Опция «Связи огибают ноды» в настройках включает
маршрутизацию линий мимо чужих карточек. Связь с потоком значений
(`Shift + drag`) подсвечивается бирюзовым и показывает текущее значение —
см. [Расчёты](calculations.html).

## Режим фокуса

Клавиша **F** (или пункт меню канваса, или настройка) включает фокус-режим:
при наведении на ноду её связи и соседи подсвечиваются, остальная сцена
притемняется. Удобно разбирать запутанные графы.

## Миникарта

Правый нижний угол, 220×140. Клик — камера отцентрируется по выбранной ноде;
drag белой рамки — быстрое панорамирование. На сценах от 500 нод линии связей
на миникарте скрываются для скорости.

## Поиск

**Ctrl+F** — панель поиска. Ищет файлы по имени и содержимому (txt/md),
заметки — по заголовку и тексту, группы — по метке. Enter или клик — полёт
камеры к результату; F3 / Shift+F3 — переход между результатами. Свёрнутые
ветки mindmap в поиске не участвуют, пока не развёрнуты.

## Палитра (ПКМ по объекту)

Контекстное меню объекта собрано в группы:

- **Цвет** — пресеты 1–6 / «Без цвета»; при мультивыделении применяется ко всем.
- **Раскладка** — «Дерево →», «Дерево ↓», «Радиально»: автораскладка связанных
  нод от выбранной (связи следуют за нодами).
- **Действия** — Переименовать, Дублировать, Сгруппировать; для файлов —
  «Открыть файл», «Открыть папку с файлом», «Скопировать путь»; для заметок —
  «Очистить текст»; для групп — «Разгруппировать»; для виджетов —
  «Перезагрузить виджет», «Разрешения виджета…».
- **Ветвление** (заметки) — «Добавить дочернюю», «Добавить сиблинга»,
  «Свернуть/Развернуть ветку» — режим mindmap.
- Для связи — **Стиль**, **Толщина**, **Цвет**, **Поток** (значение/контроль),
  **Порты** (авто/закрепить исток/закрепить сток).

## Панель настроек

Открывается кнопкой ⚙ (угол настраивается) или **Ctrl+,**. Настройки
сгруппированы в три секции (FR-026):

- **Канвас** — сетка вкл/выкл, вид сетки (линии/точки), плотность.
- **Связи и порты** — «Связи огибают ноды», зона портов (насколько «широко»
  ловится потягивание связи у ноды, 10–40 px — больше зона, легче
  целиться), режим фокуса связей (как клавиша F).
- **Приложение** — угол кнопки настроек, HUD при старте.

Тумблеры (булевы настройки) переключаются кликом по строке. Многозначные
настройки — выпадающие меню: клик по строке («Угол кнопки», «Вид сетки»,
«Плотность сетки», «Зона портов») открывает список всех значений с галочкой
у текущего; выбор — кликом или с клавиатуры (↑/↓ и Enter), Esc закрывает
только меню, клик вне меню — тоже (панель остаётся открытой).

Тема: тёмная / светлая — кнопкой ☀/🌙 рядом с ⚙ (вне панели). Конфиг
хранится в `~/.canvasdesk/config.toml`.

## HUD и оверлей хоткеев

- **F3** — HUD: fps, p95 времени кадра, счётчики. Полезно на больших сценах.
- **F1** — экранная шпаргалка по горячим клавишам (полный список —
  в разделе [Горячие клавиши](hotkeys.html)).

## Виджеты

JS/HTML-виджеты (календарь, стикер, часы и свои — из
[SDK](https://github.com/danku13/CanvasDesk/tree/main/sdk)): перетащите папку
виджета на канвас — виджет установится. Живой рендер — на Windows (WebView2);
на Linux/macOS виджет показывается снапшотом. Разрешения и перезагрузка —
через палитру виджета.

## Режим «вместо рабочего стола» (Windows)

Запуск `canvasdesk --desktop` встраивает канвас в рабочий стол: карточки и
заметки живут прямо на обоях, иконки рабочего стола скрываются. Повторный
запуск в обычном режиме возвращает окно. Подробности — в README репозитория.
