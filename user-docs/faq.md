# FAQ

## Данные и формат

### Где CanvasDesk хранит мои данные?

Раскладка канваса — в `.canvas`-файле рядом с тем, что вы открыли
(по умолчанию `default.canvas`). Это обычный JSON в формате
[JSON Canvas 1.0](https://jsoncanvas.org). Настройки — `~/.canvasdesk/config.toml`;
кэш тамбнейлов и поисковый индекс — `~/.canvasdesk/cache.db`. Файлы-карточки
нигде не копируются — канвас хранит только ссылки на них.

### Как сохранить работу? Есть ли автосохранение?

Есть: правки сохраняются автоматически через 2 секунды. Рядом с
`.canvas`-файлом приложение держит `.bak` — предыдущую версию. Если канвас
повредился или правка не нужна, закройте приложение и переименуйте `.bak`
в `.canvas`.

### Можно ли открыть канвас в Obsidian (и наоборот)?

Да. Формат — совместимый JSON Canvas 1.0: раскладка откроется в Obsidian
Canvas, а канвасы Obsidian — в CanvasDesk. Расширения CanvasDesk
(`canvasdesk.*`, `edgeStyle`, `edgeWidth` и т.п.) переживают round-trip:
Obsidian сохранит их как неизвестные поля.

## Ноды и связи

### Как создать заметку / добавить файл?

Заметка — двойной клик по пустому месту. Файл — перетащите его из проводника
на канвас (Windows; на Linux/macOS drag&drop по плану M7 — пока можно
создавать ноды через ПКМ).

### Почему связь прицепилась не туда, куда я хотел(а)?

По умолчанию связи **умные**: они сами выбирают порты так, чтобы линия шла
кратчайшим путём, и пересчитывают это при каждом перетаскивании нод и
автораскладке — чтобы граф не путался. Если нужен строго фиксированный порт:
ПКМ по связи → «Порты» → «Закрепить исток/сток» (зафиксируется текущее
положение); «Авто» снимает закрепление.

### Как сделать связь «потоком значений» для расчётов?

Потяните связь от порта с зажатым **Shift** — она станет бирюзовой
value-связью. Или создайте обычную связь и переключите её в палитре
(ПКМ по связи → «Поток»). Подробности — в
[Расчётах](calculations.html).

### Пишет «Обнаружен цикл…» — что это?

Value-связи образуют граф потока данных, где циклы запрещены (DAG) — иначе
пересчёт невозможен. Приложение предлагает создать обычную контрольную связь
(без потока значений): «Да» — связь создастся, расчёт не пострадает.

### Я удалил(а) ноду, а связи остались висеть. Это баг?

Нет, это осознанное поведение: связи — самостоятельные объекты канваса.
Висящую связь можно перепривязать (выделите — потяните хэндл на конце) или
удалить (Del). Undo (Ctrl+Z) вернёт ноду вместе со связями.

### Как расставить много нод красиво?

Выделите центральную ноду → ПКМ → «Раскладка»: «Дерево →», «Дерево ↓» или
«Радиально» — связанные ноды разложатся автоматически, связи подстроятся.
Поможет и режим фокуса (**F**) — подсвечивает связи выбранной ноды.

## Расчёты

### Формула не считается. В чём может быть дело?

- Строка должна быть вида `имя = выражение` (или чистое выражение).
- Единицы пишутся сразу после числа: `1000 rps`, а не `1000rps rps`.
- Сложение требует одной размерности: `1 sec + 500 ms` — ок,
  `1 sec + 5 rps` — ошибка.
- Ошибочная строка красная — остальной лист считается дальше; downstream
  через value-связи получит «вход отсутствует», пока ошибка не исправлена.
- Строки внутри блоков кода (тройные кавычки) не вычисляются.

Подробный синтаксис — в [Расчётах](calculations.html).

### Что показывает число на связи?

Лейбл value-связи дополняется значением источника: `label · 1000 rps`. Это
живое значение — меняете формулу источника, меняется и подпись.

## Поиск

### Поиск не находит мой файл/заметку

- Файлы ищутся по имени и содержимому **текстовых** файлов (txt/md до 256 КБ);
  PDF и картинки — только по имени файла (полноценное извлечение — в планах).
- Заметки ищутся по заголовку и тексту.
- Нода внутри **свёрнутой ветки mindmap** не ищется — разверните ветку.
- Файлы, не добавленные на канвас, не ищутся: поиск работает по нодам канваса.

## Виджеты

### Как установить виджет?

Перетащите папку виджета (с `widget.json`) на канвас. Встроенные — календарь,
стикер, часы. Свои виджеты пишутся на JS/HTML через
[SDK](https://github.com/danku13/CanvasDesk/tree/main/sdk) — шаблон и примеры
(todo-panel, dashboard) в репозитории.

### Виджет не работает / показывает заглушку

Живой рендер виджетов сейчас на Windows (WebView2). На Linux/macOS виджет
показывается снапшотом/плейсхолдером. Битый виджет: ПКМ → «Действия» →
«Перезагрузить виджет»; разрешения — «Разрешения виджета…».

## Платформы и сборка

### Есть ли версия для Linux / macOS?

Ядро (канвас, заметки, связи, миникарта, поиск, undo, расчёты) работает на
всех трёх ОС. Платформенные фичи (drag&drop, тамбнейлы, MCP, desktop-режим,
живые виджеты) полноценно работают на Windows — перенос по плану
[M7](https://github.com/danku13/CanvasDesk/blob/main/docs/plans/M7-crossplatform.md).

### macOS не открывает приложение («файл повреждён» / карантин)

Без подписи Apple Developer ID macOS ставит карантин на скачанное. В терминале:
`xattr -cr CanvasDesk.app` — и открывайте как обычно (двойной клик или
`./canvasdesk` из терминала).

### Где скачать готовую сборку?

GitHub Actions → workflow **CI** → последний зелёный запуск → артефакты
`build-windows` / `build-linux` / `build-macos-universal` (universal2 —
Apple Silicon + Intel).

## Производительность

### Сколько нод выдержит приложение?

Целевая метрика — 5000 нод при 60 fps (spatial index + culling). Проверить
можно самому: `canvasdesk --stress 5000`, HUD по F3 покажет fps и p95. На
сценах от 500 нод миникарта скрывает линии связей — это оптимизация, не баг.

### Клавиши не работают — раскладка русская?

Хоткеи работают в обеих раскладках: Ctrl+С/М/В («с»=C, «м»=V, «в»=D и т.д.).
Полный список — в [Горячих клавишах](hotkeys.html) и по F1 в приложении.

## AI-интеграция

### Что такое MCP и зачем он?

CanvasDesk умеет работать с AI-клиентами (например, Claude) через
[Model Context Protocol](https://modelcontextprotocol.io): агент может
читать/править ноды, считать поток значений (`flow_recalc`), управлять
связями. На Windows — `canvasdesk.exe mcp` (один exe, посредник сам поднимает
сервис). Конфигурация и список инструментов —
[docs/BYOK.md](https://github.com/danku13/CanvasDesk/blob/main/docs/BYOK.md).
