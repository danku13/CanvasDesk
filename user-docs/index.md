# CanvasDesk — справка

**CanvasDesk** — визуальная система математического моделирования:
бесконечный зумируемый канвас, на котором строятся исполняемые модели —
расчётные ноды (Numi-формулы и шаблоны), соединённые связями, по которым
значения **проливаются** и пересчитываются мгновенно. Карточки — это ваши
настоящие файлы на диске; формулы, единицы измерения и теория очередей —
встроены в ядро. Канвас хранится в формате
[JSON Canvas](https://jsoncanvas.org) (`.canvas`) — его можно открыть в Obsidian
и наоборот.

## Где взять сборку

Готовые бинари каждой сборки — на странице
[GitHub Actions → CI](https://github.com/danku13/CanvasDesk/actions) в артефактах
`build-windows` / `build-linux` / `build-macos-universal`. Сборка из исходников —
`cargo build --workspace --release` (подробнее в
[README репозитория](https://github.com/danku13/CanvasDesk#сборка-и-запуск)).

> macOS: без подписи Apple Developer ID система ставит карантин на скачанное
> приложение. Распакуйте архив и выполните `xattr -cr CanvasDesk.app`, затем
> откройте приложение как обычно.
