# Быстрый старт

## 1. Запуск

- **Windows**: запустите `canvasdesk.exe`. Без аргументов откроется канвас
  `default.canvas` рядом с исполняемым файлом (или последний открытый).
- **Linux / macOS**: бинарь `canvasdesk` — те же правила запуска.
- Можно открыть конкретный файл: `canvasdesk путь/до/file.canvas`.
- Нагрузочный тест: `canvasdesk --stress 5000` — сцена из 5000 нод.

Требования — Rust 1.80+ для сборки; готовые сборки лежат в артефактах CI
(см. [главную страницу](index.html)).

## 2. Создайте первую заметку

1. **Двойной клик по пустому месту** канваса — появится заметка.
2. Печатайте текст. **Ctrl+Enter** (или клик мимо) — зафиксировать,
   **Shift+Enter** — перенос строки, **Esc** — отменить правку.
3. **ПКМ по заметке** — палитра: цвет (пресеты 1–6), «Действия»
   (переименовать, дублировать, очистить текст) и другое.
4. Выделите слово и нажмите **Ctrl+B** (жирный), **Ctrl+I** (курсив),
   **Ctrl+H** (подсветка) — форматирование совместимо с Obsidian.

## 3. Добавьте файлы

Перетащите файлы или папку из проводника прямо на канвас — появятся
карточки с превью. Карточка — это **ссылка на настоящий файл**:

- **Двойной клик** по карточке — открыть файл в ассоциированном приложении.
- **ПКМ** → «Открыть папку с файлом», «Скопировать путь».
- Файл переехал или недоступен — карточка станет серой («битая ссылка»);
  верните файл на место, и она оживёт сама.

## 4. Свяжите объекты

1. Наведите курсор на ноду — по краям появятся **4 порта**.
2. Потяните ЛКМ от порта и отпустите на другой ноде — связь создана.
3. **Двойной клик по линии** — подпись связи.
4. Связь можно **перепривязать**: клик по линии → потяните кружок-хэндл
   на конце → отпустите на другой ноде.
5. **Shift + drag** от порта — связь-**поток значений** для расчётов
   (см. [Расчёты](calculations.html)).

Связи сами выбирают ближайшие порты: перетащите ноду — и линия мгновенно
перепрыгнет на кратчайший путь. Хотите зафиксировать порт — ПКМ по связи →
группа «Порты» → «Закрепить».

## 5. Навигация

- **Space + drag** (или средняя кнопка, или тачпад) — панорамирование.
- **Ctrl + колесо** — зум к курсору; pinch — на тачскрине.
- **Миникарта** в правом нижнем углу: клик — камера прыгнет к ноде,
  drag белой рамки — быстрая прокрутка сцены.
- Заблудились? **Поиск Ctrl+F** найдёт файл по имени и содержимому,
  заметку — по тексту. **Enter** — полёт камеры к результату,
  **F3** — следующий результат.

## 6. Сохранение

CanvasDesk сохраняет канвас **автоматически** через 2 секунды после правки.
Рядом с `.canvas`-файлом держится `.bak` — предыдущая версия: если что-то
пошло не так, просто переименуйте `.bak` в `.canvas`.

Все действия обратимы: **Ctrl+Z** / **Ctrl+Y** (глубина истории — 50 шагов).
