# Горячие клавиши

Эта же шпаргалка доступна в приложении по **F1**. Хоткеи работают и на
латинской, и на кириллической раскладке (Ctrl+С = Ctrl+C и т.д.).

## Навигация и вид

| Ввод | Действие |
|---|---|
| Space + drag / средняя кнопка / тачпад | Панорамирование |
| Ctrl + колесо / pinch | Зум к курсору (0.05×–4.0×) |
| F | Фокус на связях (подсветка соседей выбранной ноды) |
| F3 | HUD (fps, p95) / следующий результат поиска |
| Shift+F3 | Предыдущий результат поиска |
| Ctrl+F | Поиск по канвасу |
| Esc | Закрыть меню и панели |

## Выделение

| Ввод | Действие |
|---|---|
| ЛКМ | Выделить ноду / связь |
| Ctrl + клик / Shift + клик | Добавить к выделению / убрать из него |
| ЛКМ + drag от пустого места | Рамка выделения |
| Del | Удалить выделенное |

## Ноды

| Ввод | Действие |
|---|---|
| Двойной клик по пустому месту | Новая заметка |
| Shift + клик по пустому месту | Радиальное меню шаблонов (см. [Шаблоны нод](templates.html)) |
| Ctrl+P | Фокус в поиск палитры шаблонов (палитра по умолчанию свёрнута в левую полосу категорий; Ctrl+P разворачивает док, Esc — сворачивает) |
| Наведение на категорию в левой полосе | Раскрыть список шаблонов категории справа; колесо — прокрутка списка; клик по категории — закрепить, повторный клик/Esc — закрыть |
| Двойной клик по заметке | Редактирование |
| Двойной клик по файловой карточке | Открыть файл |
| Ctrl+Enter | Зафиксировать заметку (Enter тоже; Shift+Enter — новая строка, Esc — откат) |
| ↑ / ↓ в popup подсказок | Выбрать вариант автодополнителя (см. [Расчёты](calculations.html)) |
| Enter / Tab в popup подсказок | Принять вариант (заметка не фиксируется; Enter вне popup — фиксирует) |
| Esc в popup подсказок | Закрыть подсказки (повторный Esc — откат правки) |
| Ctrl+B / Ctrl+I / Ctrl+H | Жирный / курсив / подсветка выделенного текста |
| Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D | Копировать / вырезать / вставить / дублировать ноды |
| Ctrl+G | Сгруппировать выделенное |
| Ctrl+Z / Ctrl+Y | Отмена / возврат (глубина 50) |
| ПКМ | Палитра объекта (цвет, раскладка, действия, ветвление) |
| ПКМ по заметке → «Ветвление» | Добавить дочернюю/сиблинга, свернуть ветку (mindmap) |
| ПКМ по ноде → «Раскладка» | Дерево → / Дерево ↓ / Радиально |

## Связи

| Ввод | Действие |
|---|---|
| ЛКМ от порта (наведите на ноду) | Протянуть связь |
| Shift + ЛКМ от порта | Связь-поток значений (см. [Расчёты](calculations.html)) |
| ЛКМ за хэндл конца выделенной связи | Перепривязать связь |
| Двойной клик по линии | Подпись связи |
| ПКМ по связи | Стиль / толщина / цвет / поток / порты |
| Del (связь выделена) | Удалить связь |

## Панели

| Ввод | Действие |
|---|---|
| F1 | Список горячих клавиш (этот оверлей) |
| Ctrl+, | Панель настроек |
