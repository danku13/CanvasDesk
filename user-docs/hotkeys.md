# Горячие клавиши

Эта же шпаргалка доступна в приложении по **F1**. Хоткеи работают и на
латинской, и на кириллической раскладке (Ctrl+С = Ctrl+C и т.д.).

## Навигация и вид

| Ввод | Действие |
|---|---|
| Space + drag / средняя кнопка / тачпад | Панорамирование |
| Ctrl + колесо / pinch | Зум к курсору (0.05×–4.0×) |
| F | Фокус на связях (подсветка соседей выбранной ноды) |
| F3 | HUD (fps, p95) / следующий результат поиска |
| Shift+F3 | Предыдущий результат поиска |
| Ctrl+F | Поиск по канвасу |
| F2 | Карта потока — панель всех проливаний значений (клик по строке — переход к источнику) |
| Ctrl+B | Индикаторы узких мест (рамки/бейджи ρ и W; в тексте редактора Ctrl+B — жирный) |
| Esc | Закрыть меню и панели; в открытом онбординге — отложить тур; в открытой детализации пучка (main stage) — закрыть её |

## Проверка цепочки цифры (FR-048)

| Ввод | Действие |
|---|---|
| Наведение на вычисленную цифру | Пилюля «?» (клик по цифре — тоже открывает проверку) |
| Клик по узлу с бейджем «+N глубже» | Раскрыть ветку дерева происхождения |
| Клик по чипу-крошке в шапке окна | Вернуться к соответствующему уровню дерева |
| Клик по подсвеченной ноде канваса | Подсветить соответствующий узел дерева (У2) |
| Space в режиме защиты | Раскрыть следующий уровень цепочки |
| Esc | Режим защиты → обычный вид окна; повторный Esc — закрыть окно |

## Main stage — детализация пучка связей (FR-042)

| Ввод | Действие |
|---|---|
| Клик / ПКМ / двойной клик по толстой линии с бейджем `×N` | Открыть детализацию пучка: обе ноды и все связи веером с подписями и значениями |
| Клик по линии внутри stage | Выделить связь (живая связь канваса — видна после закрытия) |
| Клик по затемнённому фону | Закрыть stage |
| Esc | Закрыть stage |

## Выделение

| Ввод | Действие |
|---|---|
| ЛКМ | Выделить ноду / связь |
| Ctrl + клик / Shift + клик | Добавить к выделению / убрать из него |
| ЛКМ + drag от пустого места | Рамка выделения |
| Del | Удалить выделенное |

## Ноды

| Ввод | Действие |
|---|---|
| Двойной клик по пустому месту | Новая заметка |
| Shift + клик по пустому месту | Радиальное меню шаблонов (см. [Шаблоны нод](templates.html)) |
| Ctrl+P | Фокус в поиск палитры шаблонов (палитра по умолчанию свёрнута в левую полосу категорий; Ctrl+P разворачивает док; Esc сворачивает док всегда — и с фокусом, и без) |
| Наведение на категорию в левой полосе | Раскрыть список шаблонов категории справа; колесо — прокрутка списка; клик по категории — закрепить, повторный клик/Esc — закрыть |
| Двойной клик по заметке | Редактирование |
| Двойной клик по файловой карточке | Открыть файл |
| Ctrl+Enter | Зафиксировать заметку (Enter тоже; Shift+Enter — новая строка, Esc — откат) |
| ↑ / ↓ в popup подсказок | Выбрать вариант автодополнителя (см. [Расчёты](calculations.html)) |
| Enter / Tab в popup подсказок | Принять вариант (заметка не фиксируется; Enter вне popup — фиксирует) |
| Esc в popup подсказок | Закрыть подсказки (повторный Esc — откат правки) |
| Ctrl+B / Ctrl+I / Ctrl+H | Жирный / курсив / подсветка выделенного текста |
| Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D | Копировать / вырезать / вставить / дублировать ноды |
| Ctrl+G | Сгруппировать выделенное |
| Ctrl+Z / Ctrl+Y | Отмена / возврат (глубина 50) |
| ПКМ | Палитра объекта (цвет, раскладка, действия, ветвление) |
| ПКМ по пролитой строке (значение с адресом источника) | Меню параметра: «Показать источник», «Отключить проливание», «Что если…» |
| ПКМ по заметке → «Ветвление» | Добавить дочернюю/сиблинга, свернуть ветку (mindmap) |
| ПКМ по ноде → «Раскладка» | Дерево → / Дерево ↓ / Радиально |

## Связи

| Ввод | Действие |
|---|---|
| ЛКМ от порта (наведите на ноду) | Протянуть связь |
| Shift + ЛКМ от порта | Связь-поток значений (см. [Расчёты](calculations.html)) |
| ЛКМ за хэндл конца выделенной связи | Перепривязать связь |
| Двойной клик по линии | Подпись связи |
| ПКМ по связи | Стиль / толщина / цвет / поток / порты |
| Del (связь выделена) | Удалить связь |

## Панели

| Ввод | Действие |
|---|---|
| F1 | Список горячих клавиш (этот оверлей) |
| Ctrl+Shift+I | What-if режим: подмены значений и сценарии (см. [Расчёты](calculations.html); двойной клик по строке расчёта в режиме — подмена, Esc — выход) |
| Ctrl+, | Окно настроек (модалка, FR-039) |
| Клик по многозначной строке настроек | Открыть выпадающее меню значений (FR-026) |
| ↑ / ↓ в меню настроек | Сдвинуть выделение пункта (закольцовано) |
| Enter в меню настроек | Применить выделенное значение и закрыть меню |
| Esc в меню настроек | Закрыть только меню (повторный Esc — окно настроек) |
| Клик по затемнению вне окна настроек | Закрыть окно настроек (FR-039) |
| Клик вне меню настроек | Закрыть меню (панель остаётся открытой) |
