# Экспорт и артефакт защиты

Защита расчёта перед командой, C-level или инвесторами не всегда происходит
вживую: чаще стейкхолдер просит «пришлите это» — и ему нужно отправить
что-то, что открывается без установки CanvasDesk, без доступа к вашему
диску и без живой сессии. Для этого существует **HTML-артефакт** (FR-076):
один самодостаточный файл, который содержит весь снимок канваса и все
вычисленные значения.

## Что такое HTML-артефакт

Артефакт — это обычный HTML-файл (например, `runway.html` рядом с
`runway.canvas`). Весь контент встроен в файл: CSS, JavaScript и SVG-снимок
канваса не тянут ресурсов из сети, поэтому файл работает офлайн — его можно
открыть в любом современном браузере, переслать по почте или мессенджеру,
положить в тикет или вложить в презентацию как ссылку на файл в репозитории.
Идея перенесена из открытого проекта Archify (практика «portable by
default»): результат моделирования — коммуникационный артефакт, а не только
живой документ.

Внутри файла три смысловых блока. Первый — шапка с именем канваса и
счётчиками объектов, кнопками темы (светлая/тёмная) и зума. Второй —
SVG-снимок канваса: группы-подложки, карточки с заголовками и строками
формул, рёбра со стрелками; у формульных строк справа показаны вычисленные
значения, у карточек с итогом — строка результата, на value-рёбрах —
переносимые значения. Третий — таблица сравнения what-if сценариев
«переменная | База | Сценарий…» с дельтами, если сценарии в канвасе есть.

## Как экспортировать

| Платформа | Действие |
|---|---|
| Десктоп | **Ctrl+Shift+E** — файл `<имя>.canvas>` → `<имя>.html` записывается рядом с канвасом; путь приходит тостом |
| Веб-версия | Кнопка **«Экспорт HTML»** на панели хранилища — браузер скачивает файл |

Экспортируются значения **базовой** модели (последний пересчёт без активных
what-if подмен). Сценарии, сохранённые в канвасе, попадают в таблицу
сравнения — так стейкхолдер видит не только базу, но и заготовленные
альтернативы с дельтами. Артефакт детерминирован: один и тот же канвас
всегда даёт байт-в-байт одинаковый файл — его можно положить в git и
смотреть диффы ревизий.

## Что НЕ входит в артефакт

Артефакт — снимок, а не копия приложения. Внутри нет редактора: изменить
формулу или переставить ноду в HTML нельзя (это защищает расчёт от
случайной правки при пересылке — получатель видит ровно то, что вы
проверили). Нет live-пересчёта, интерактива проверки цепочки (FR-48),
виджетов и файлов-карточек с превью — файловые карточки показываются
заголовком. Веб-версия и PNG-экспорт выбранной области — отдельные
направления развития (см. дорожную карту).

## Рекомендации по отправке

Для письма инвестору достаточно артефакта и одного абзаца контекста: файл
самодостаточен, получателю нужен только браузер. Если защищаете расчёт
вживую — открывайте артефакт вместо приложения на чужом ноутбуке: ничего
устанавливать не нужно, тема переключается под проектор (светлая), зум
кнопками работает на больших схемах. Для ревью изменений кладите артефакт
рядом с `.canvas` в репозиторий: детерминированный файл показывает в диффе,
какие значения реально поменялись.
