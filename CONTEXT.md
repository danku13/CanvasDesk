# Глоссарий CanvasDesk

Единый язык проекта. Только термины — решения и детали реализации живут
в `docs/adr/` и коде. Продукт — визуальная система математического
моделирования (ADR-0007): термины расчётного ядра первичны.

## Канвас и объекты

- **Нода** — элемент канваса. Типы: `file` (файловая карточка), `text`
  (заметка; может быть Numi-нодой или шаблонной), `group` (контейнер),
  `widget` (JS/HTML-виджет, M5). Тип `link` из JSON Canvas spec 1.0
  сохраняется при round-trip как неизвестный, в приложении не используется.
- **Карточка** — визуальное представление ноды на канвасе.
- **Заголовок ноды** — строка в шапке карточки: имя файла / первая строка
  заметки / подпись группы.
- **Связь (edge)** — линия между нодами; может иметь подпись, стиль линии,
  толщину и цвет. Бывает **контрольной** (визуальная связь) или
  **value-связью** (поток значений, `canvasdesk.flow.kind = value`).
- **Сгруппировать** — команда создания группы по bbox текущего выделения.
- **Блок GFM** — блочный элемент markdown в теле заметки: заголовок, список,
  чекбокс, цитата, кодовый блок.

## Расчётное ядро (моделирование)

- **Numi-лист** — текст ноды как программа: строки-присваивания
  (`rps = 1000 rps`) и выражения, считающиеся построчно; переменные
  протекают сверху вниз; проза и код-фенсы игнорируются (FR-013).
- **Numi-движок** — парсер/eval расчётного ядра (`canvas-core/src/expr/`):
  числа с суффиксами, единицы измерения с размерностями, функции
  (`sum`/`avg`/`max`/`min`/`percentile`, доменные — см. ниже).
- **Поток значений (value-flow)** — распространение значений по value-связям:
  значение источника доступно приёмнику как `$in` / `$1..$N` (позиционно)
  или как `$параметр` (проливание в шаблон); граф — DAG, циклы блокируются;
  live-ревал при любой правке (FR-014).
- **Value-связь** — связь, несущая значение; отображается бирюзовой с
  live-подписью значения.
- **Шаблон** — расчётная роль ноды с манифестом `template.json`:
  `params` (типизированные параметры) + `expr` (формула с `$param`);
  45 builtin-шаблонов в трёх категориях (инфраструктура, юнит-экономика
  `ue-*`, продуктовая аналитика `pa-*`) + custom (FR-018/019/020/027).
- **Шаблонная нода** — text-нода со снапшотом `canvasdesk.template`
  (id, версия, expr, params, icon, color); текст — Numi-лист значений
  параметров.
- **Порт значений** — точка входа/выхода расчётной ноды: именованный выход
  (`outputs` манифеста / строка Numi-листа) или параметрический вход
  (`toParam`); адресация именем канонична, индекс строки (`fromLine`) —
  legacy (ADR-0003, FR-029).
- **Проливание** — передача значения по value-ребру во вход-параметр
  приёмника с перекрытием локального значения («проливание сильнее
  дефолта») без правки формулы.
- **Доменные функции** — queueing (`mm1`, `mmc`, `utilization`,
  `littles_law`, `erlang_c` — FR-015) и финансы (`npv`, `cagr`, `irr`,
  `cohort_ltv` — FR-027); детект перегрузки ρ ≥ 1 → `Overload`.
- **Эталонная модель** — проверяемый сценарий, который агент собирает через
  MCP проливанием значений: Instagram MVP (ADR-0005), каталог №1–№5
  (ADR-0006).

## Интеграция

- **MCP-инструмент** — функция, которую внешний AI-агент (Claude и другие
  MCP-клиенты) вызывает по протоколу MCP для управления канвасом:
  чтение/правка нод, связи, поток значений, шаблоны (22 инструмента, T24).
- **Канал `canvasdesk`** — именованный канал Windows между процессом
  canvas-mcp и запущенным canvas-app (на Linux/macOS — UDS, план M7).
