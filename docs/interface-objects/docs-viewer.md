# Просмотрщик документации (`docs-viewer`) — интерфейсный объект

Документ по FR-027: доступ к пользовательской документации из приложения.
Фиксирует состояние v1 (кнопка «?», меню помощи, подменю разделов, правый
док-просмотрщик со скроллом и внутренними ссылками), интерфейс
взаимодействия, ограничения и точки расширения.

---

## 1. Определение

Просмотрщик документации — панель-док у правого края окна, отображающая
пользовательскую документацию (`user-docs/`, 7 страниц) без браузера и сети.
Страницы вшиты в бинарь на этапе сборки (`include_str!`): версия доков =
версия бинарника, отсутствие файла ломает сборку (доки нельзя «забыть»),
wasm-переносимо (план `docs/plans/wasm-port.md` §3).

Вход — кнопка **«?»** (третий элемент летающего кластера ⚙/тема/помощь,
настройка `button_corner` переносит кластер целиком). Клик открывает меню
помощи: «Документация ▸» (подменю 7 разделов) и «Пройти онбординг» (FR-028).

**Границы ответственности:**
- `canvas-render/src/gfm.rs`: блоки GFM + **таблицы за флагом**
  `parse_blocks_opts(text, tables)`; `inline_segments_links` — инлайн-сегменты
  с `href`. Поведение заметок не меняется (`parse_blocks` = флаг выкл,
  инвариант регрессии — юнит-тест).
- `canvas-app/src/docs_ui.rs` (чистая модель): `DOCS_PAGES` (вшитые страницы),
  `strip_front_matter`, классификация ссылок `link_target`, геометрия меню
  помощи/просмотрщика с клампом, раскладка `layout_page` (строки/квады/ссылки
  с переносом по консервативной оценке ширины глифа), `ScrollState`, hit-тесты.
- `canvas-app/src/main.rs` (рендер/ввод): оверлеи `help_menu_overlay` /
  `docs_overlay` (квады + screen-тексты), клики, колесо, Esc-цепочка.

---

## 2. Состояния и взаимодействия

| Состояние | Вход | Переход |
|---|---|---|
| Закрыто | Клик «?» | Открыто меню помощи (кламп к окну, паттерн dropdown FR-026) |
| Меню помощи | Клик «Документация ▸» | Тогл подменю 7 разделов (паттерн `ContextMenu.submenu`) |
| Меню помощи | Клик «Пройти онбординг» | Запуск тура FR-028 (счётчик откладываний не трогается); меню закрыто |
| Меню помощи | Esc | Двухэтапно: подменю → меню → закрыто (семантика FR-026) |
| Меню помощи | Клик мимо | Закрыто; клик глотается (dismiss не создаёт заметку) |
| Подменю | Выбор раздела | Просмотрщик открыт на странице; меню закрыто (одна «панель помощи» активна) |
| Просмотрщик | Колесо над панелью | Скролл контента, кламп `[0, max(0, content − view)]` |
| Просмотрщик | Клик по внутренней ссылке | Переход на страницу (offset = 0) |
| Просмотрщик | × / Esc / клик вне панели | Закрыто; клик-закрытие глотается |
| Просмотрщик | Окно 320×240 | Панель не шире окна, контент/шапка/футер в окне (инвариант клампа) |

Внешние ссылки (`http(s)://`) и якоря — обычный текст: не кликабельны и
рендерятся без акцента (v1). Внутренние — акцентный цвет + подчёркивание-квад.

## 3. Модель данных и рендер

- Страница: `DocsPage { id, label, md }` — `id` = basename файла, `label` =
  подпись в подменю («Главная», «Быстрый старт», …; инвариант полноты:
  пункт ↔ страница, юнит-тест).
- `strip_front_matter` срезает Jekyll-шапку `---\n…\n---\n` (не более 10 строк
  поиска; незакрытая — файл как есть).
- `layout_page(page, width)`: `parse_blocks_opts(body, true)` → строки
  `DocLine { x, y, kind, spans }` (заголовки H1–H6 — иерархия кеглей
  20/16/14/13; цитаты — бар-квад; код — моно-цвет; списки — маркер «•»/«N.»/
  «[x]»; таблицы — ячейки с одного y, ширины колонок по максимальной ячейке
  с пропорциональным сжатием) + `DocQuad` (линии/подчёркивания шапок таблиц/
  бары цитат) + `LinkRect` (только внутренние). Пересчёт при смене страницы
  или ширины панели — не покадрово.
- Перенос: консервативная оценка ширины глифа `CHAR_W_FACTOR = 0.62` —
  screen-тексты рендерятся с `Wrap::None`, переоценка переносит строку раньше
  реальной границы (никогда не вылезает за клип); зона ссылки чуть шире
  визуала — безопасно для клика.
- Инварианты (юнит-тесты `docs_ui`): полнота меню ↔ страницы; парсинг всех
  страниц без паник; линк-чек (битая внутренняя ссылка валит CI); кламп
  скролла; кламп геометрии; монотонность строк раскладки.

## 4. Ограничения v1 / точки расширения

- Внешние ссылки не открываются (нет крейта `webbrowser`): v2 — «открыть в
  браузере» с согласия владельца.
- Хоткея «?» нет (`Shift+/` раскладкозависим): v2 — вместе с клавиатурной
  навигацией меню.
- Поиск по документации — отдельный FR (строка в шапке).
- Ширина панели фиксированная (480 px с клампом): v2 — резиновая drag'ом.
- Иллюстрации в страницах не поддерживаются (текст + таблицы GFM).
