# dev-researches

Исследовательские документы и технические анализ-обзоры, не вошедшие в
основной поток документации (PRD / FR / CR / ADR / plans / market-researches).

Отличия от соседних директорий:

| Директория | Что лежит |
|---|---|
| `prd/` | Постановки продуктов (PRD-NNNN) — что и зачем делаем |
| `change-requests/` | Change Requests / Feature Requests (CR-NNN, FR-NNN) — конкретные правки |
| `adr/` | Architectural Decision Records — решения по архитектуре |
| `plans/` | План-файлы задач (T-NN, M-NN, mw-NN) — когда и кто делает |
| `market-researches/` | Рыночные исследования, CJM, аудит конкурентов |
| `articles/` | Статьевые разборы фич (если применимо) |
| `dev-researches/` (эта) | **Технические исследования, alternatives-обзоры, протоколы анализа** — без обязательства реализовать; для рецензии владельцем перед превращением в PRD/FR |

## Соглашения

- Имя файла: `kebab-case-<тема>.md`, например `layered-3d-canvas-analysis.md`.
- Заголовок верхнего уровня `#` — название исследования.
- Метаданные в начале: дата, тип (analysis/proposal/spike/alternatives), автор,
  коммит-база (git rev), источники.
- Если исследование привело к рекомендации — отдельный раздел «Рекомендация»
  с обоснованием и (опционально) фазами.
- Если исследование превратилось в PRD/FR/CR — добавить ссылку в конце:
  «Превращено в PRD-NNNN / FR-NNN от YYYY-MM-DD».
