## Описание (What)

PRD-0007 требует «цепочку расчёта любой цифры»: у любой вычисляемой цифры
(итог ноды, построчный результат) появляется триггер «?» и фолбэк-клик по
цифре, открывающие плавающее окно проверки поверх полноэкранного канваса
с полным рекурсивным деревом происхождения до листьев-констант/допущений,
синхронной подсветкой цепочки на канвасе с затемнением остального,
подменой листа-допущения через рантайм what-if FR-017, автосвязью таблиц
по совпадающим именам присваиваний и режимом защиты (состояние Defense
того же окна: ×1.5, пошаговое раскрытие, скрытие прозы). MCP-агент получает
текстовую выдачу объяснения (`explain_number`). Реализуется по дорожной
карте §13: X0 (этот FR) → X1 lineage-ядро → X2 триггер+окно+подсветка →
X3 what-if из дерева → X4 автосвязь → X5 режим защиты → X6 интеграция/MCP.

## Анализ (Root Cause — чего нет в коде)

- Нет lineage-модели: `value_path` (`flow.rs:870`) — только кратчайший путь
  между нодами, без дерева, строк и значений; `inbound_slots_with_lines`
  (`flow.rs:555`) дают входы одной ноды без рекурсии.
- Нет триггера и окна объяснения: полоса D и построчные ряды не имеют
  hit-зон «?»; main stage (fr-044) ограничен парой нод пучка.
- Нет what-if из дерева: override-цели `(node, line)` адресуются только из
  бара FR-017.
- Нет детектора автосвязи: `line_kind` (`expr.rs:1719`) есть, но скан
  совпадающих имён присваиваний между нодами и ревью-диалог отсутствуют.
- Нет режима защиты: укрупнение ×1.5 и пошаговое раскрытие существуют
  только в HTML-прототипе v4.
