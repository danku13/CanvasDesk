# FR-082: колесо над развёрнутой панелью шаблонов — прокрутка списка

- **Статус:** реализовано
- **Тип:** FR (ревизия FR-025/FR-024)
- **Приоритет:** важно (UX быстрого доступа к шаблонам)
- **Владелец:** агент-сессия (Super Z), по запросу владельца
- **Источник:** запрос владельца 2026-10-01: «проверь работу левой палеты
  с быстрым доступом к шаблонам». Аудит выявил: развёрнутый док
  (`Ctrl+P`, 62 встроенных шаблона, окно `MAX_VISIBLE_ROWS` = 12 строк)
  не реагировал на колесо — жест уходил в пан канваса ПОД панелью
  (список двигался только стрелками с фокусом; колесо работало лишь у
  flyout свёрнутой полосы).
- **Связанные задачи:** FR-018/FR-024/FR-025 (панель), FR-054 (измеренный
  текст), FR-019/FR-027 (реестр 62 шаблона)
- **Создан:** 2026-10-01
- **Обновлён:** 2026-10-01

## Описание

Аудит «левой палеты с быстрым доступом к шаблонам» (`template_ui.rs`,
`on_mouse_wheel`): развёрнутый док — единственная списковая поверхность,
у которой колесо не скроллило список. При 62 шаблонах (окно 12 строк +
секции) остальной список был доступен только стрелками при фокусе; для
мыши — никак. Пан канваса под курсором над панелью — неожиданный побочный
эффект.

## Решение

- **`PanelLayout::max_scroll`** — «приклейка хвоста»: наибольшее
  `scroll_top`, при котором хвост списка показывается ЦЕЛИКОМ (последняя
  строка у нижней границы окна строк), а число шаблонов хвоста ≤
  `MAX_VISIBLE_ROWS` (иначе кэп обрывает список раньше конца). Условие
  видимости строки — то же, что в цикле раскладки; расчёт suffix-суммами
  за O(n) без повторных прогонов `panel_layout`. Крайний случай: панель
  теснее одной строки — `max_scroll = 0`.
- **`TemplatePanel::scroll_by(delta, max_scroll)`** — кламп
  `scroll_top` к `[0, max_scroll]` (образец `TemplateHover::scroll_by`).
- **`on_mouse_wheel`** — блок для развёрнутого дока: курсор над
  `panel_rect` → `scroll_by(−lines·PANEL_WHEEL_LINES, lay.max_scroll)`
  + `request_redraw` + `return` (канвас не панорамируется). Шаг —
  `PANEL_WHEEL_LINES` = 3 строки/щелчок (60+ шаблонов; у flyout
  построчный шаг сохранён). Знак — как у всех списков репозитория:
  колесо от себя (y<0) двигает вниз.
- **`PANEL_WHEEL_LINES`** — константа шага (документирована).

## Тесты

- `panel_scroll_by_clamps` — кламп с двух сторон; `max=0` — прокрутки нет.
- `panel_max_scroll_tail_glued_to_bottom` — реальный реестр
  (`TemplateRegistry::builtin`, 62 шаблона): `max_scroll > 0`; при
  `scroll_top = max_scroll` последняя строка видна; кламп колеса.
- `panel_max_scroll_micro_window_is_zero` — микроокно → 0.
- Вся существующая геометрия панели — без изменений (rects
  бит-в-бит прежние: `max_scroll` — чисто вычисляемое поле).

## Инварианты

- Колесо над панелью НИКОГДА не панорамирует канвас (и наоборот —
  пан над списком не уходит в канвас).
- `scroll_top` после колеса ≤ `max_scroll` — пустота под списком
  невозможна (хвост приклеен).
- Клавиатурная навигация (`move_selection`, окно `SCROLL_WINDOW`)
  работает как раньше; колесо не двигает выделение.
