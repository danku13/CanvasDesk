# FR-094: Витрина интерфейса падает в wasm — «no default font found»: прод-путь Row на внешний пул шейпинга

- **Статус:** выполнено
- **Тип:** FR (дефект wasm-сборки → фикс контракта продакшн-потребления)
- **Приоритет:** критично (краш rAF-цикла на проде)
- **Владелец:** агент (сессия web-f324f377, 2026-10-03)
- **Источник:** запрос владельца 2026-10-03 — лог из записи сеанса (PostHog Replays, консольный плагин rrweb):
  «canvas-web: паника в …/cosmic-text-0.12.1/src/shape.rs:251: no default font found» + «Uncaught RuntimeError: unreachable», поверхность — витрина интерфейса (`kit_gallery`)
- **Связанные задачи:** FR-055 (витрина кита), FR-068 W3 (компонентный слой Row/Table), FR-089/FR-090 (телеметрия — лог пришёл из записи сеанса), §4.7/CR-015 (инвариант «шейпинг тем же пулом, что рендер»)
- **Создан:** 2026-10-03

## Описание

Владелец прислал лог из записи сеанса: при открытии «Витрины интерфейса (UI kit
v1)» приложение падает — паника cosmic-text «no default font found»
(shape.rs:251), за ней `Uncaught RuntimeError: unreachable` (wasm-трап после
паники внутри rAF-колбэка), витрина «замирает» на последнем отрисованном кадре.

Диагностика (репро на live-бандле main@ece0079, agent-browser, WebGL2-фолбэк):
паника воспроизводится при прокрутке витрины до секции компонентного слоя —
верхние секции (Buttons/Chips/Dropdown/Toast/Table) рисуются без ошибок,
падение — в секции «Row (компонент)».

Корень — единственный продакшн-вызов ДЕФОЛТНЫХ путей kit-компонентов:

- `crates/canvas-app/src/app/overlays.rs` (`kit_gallery_overlay`), секция
  компонентного слоя: `Row::new(props)` + `Component::layout/paint` —
  дефолтные методы ходят во ВНУТРЕННИЙ пул компонента
  (`font_system: RefCell<FontSystem>` = `FontSystem::new()`).
- В браузере `FontSystem::new()` даёт ПУСТУЮ fontdb (системных шрифтов в
  wasm нет): первый же шейпинг (`row_guides` → cosmic-text `Buffer::shape`)
  не находит дефолтное лицо → паника «no default font found» → трап.
- На десктопе пул наполнен системными шрифтами — путь «работал» и дефект
  не ловился нативными тестами (CI без браузера не проверял витрину до
  секции Row; FR-092-сессия открывала только верх витрины).

Контракт при этом давно существовал: продакшн-потребители обязаны передавать
ОБЩИЙ пул рендера (§4.7 — так уже делают все Table-потребители:
`guides_with(m, fs)` / `row_layout_with(m, fs)` с внешним `fs`;
`fs` в `kit_gallery_overlay` = `canvas_render::text::measure_font_system()`
— тот самый пул с вшитыми шрифтами). Витрина нарушила контракт только в
секции Row.

Сопроводительные строки лога (не баги приложения):

- `Uncaught TypeError: chrome.action.show is not a function` — исключение
  из РАСШИРЕНИЯ браузера (MV3-API `chrome.action` вне расширения не
  существует); rrweb-console-record просто записал всё из консоли страницы.
  К CanvasDesk отношения не имеет.

## Влияние

| Объект | Что сломано | Где |
|---|---|---|
| canvas-app (web/wasm) | витрина кита: секция «Row (компонент)» роняет rAF-цикл паникой, витрина замирает | `app/overlays.rs` (draw витрины) |
| canvas-ui (Row) | дефолтные пути несут скрытый wasm-хазард: внутренний пул пуст, любое прод-использование паникует | `component/row.rs` |

## Решения

- **`Row::layout_row_with(m, fs, slot)`** — вёрстка с ВНЕШНИМИ пулами
  (тело прежнего `layout_row` бит-в-бит; продакшн-контракт §4.7).
- **`Row::layout_row(slot)`** — делегирует `layout_row_with` через
  внутренние поля (RefCell-бэраунды, поведение тестов неизменно).
- **`Row::paint_with(painter, m, fs, rects)`** — отрисовка с внешним пулом
  (прежде `Component::paint` внутри пересчитывал геометрию через внутренний
  пул — вторая точка паники).
- **Витрина (`overlays.rs`)**: секция Row переведена на
  `layout_row_with`/`paint_with` с `m`/`fs` функции (как у Table);
  локальный `use …Component as _` удалён (трейт в блоке больше не нужен).
- Дефолтные пути Row/Table/TextField остаются путями тестов/standalone —
  контракт задокументирован в доке `layout_row_with` (wasm: внутренний пул
  пуст — «no default font found»; прод обязан передавать внешний).

## Приёмка

- Гейты локально (тулчейн 1.99): `cargo fmt --all -- --check` — чисто;
  `cargo check/test -p canvas-ui` — 207 passed / 0 failed (+1 новый);
  `cargo check/test -p canvas-app` — все зелёные; `clippy` (натив
  + `--lib --target wasm32-unknown-unknown`) — 0 предупреждений.
- Новый тест `layout_row_with_matches_internal_on_same_font`:
  внешний пул = внутренний на том же лице (геометрия rect'ов и элементы
  `Painter`'а совпадают) — оракул контракта §4.7/CR-015.
- E2E на live (до фикса): открытие витрины → прокрутка до секции Row
  (синтетический `wheel` на канвасе) → консоль:
  `паника … shape.rs:251: no default font found` — репро подтверждено
  на бандле b99777f (main@ece0079). После выката фикса — тот же сценарий
  должен проходить без паники (секция Row рисуется, консоль чистая).
