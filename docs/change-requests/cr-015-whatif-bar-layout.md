# CR-015: Вёрстка нижнего бара what-if — чипы и кнопки налезают друг на друга

- **Статус:** выполнено
- **Тип:** CR
- **Приоритет:** важно
- **Владелец:** агент (анализ + реализация)
- **Источник:** скриншот пользователя (сессия 2026-09-19): чипы «База»/«Сценарий N»,
  счётчик «подмен: 0» и кнопки Apply/Сброс/Сравнить перекрывают друг друга,
  «Сравнить» обрезано правым краем бара.
- **Связанные задачи:** FR-017 (what-if режим), ACCEPTANCE §28 (FR-017.8 — ввод режима),
  SPEC §8 (ввод)
- **Создан:** 2026-09-19
- **Обновлён:** 2026-09-19

## Описание

В нижнем баре what-if режима подписи элементов шире отведённых им чипов и
фиксированных кнопок: текст одного элемента рисуется поверх соседнего, кнопка
«Сравнить» обрезана правым краем полосы, а «✕» уходит за край. Выявил
пользователь скриншотом; дефект чисто визуальный — логика режима (подмены,
сценарии, Apply) не затронута.

## Влияние

| Объект | Что сломано | Где в документации |
|---|---|---|
| `whatif-bar` (нижняя полоса режима) | Чипы/кнопки перекрываются, «Сравнить» обрезано | ACCEPTANCE §28 (FR-017.8), `user-docs/calculations.md` (раздел «What-if сценарии») |
| `whatif` compare/override списки | Не затронуты (раскладка над баром — отдельные функции) | ACCEPTANCE §28 |

## Анализ

Три причины, усиливающие друг друга:

1. **Заниженная оценка ширины текста.** `text_width` (`crates/canvas-app/src/whatif_ui.rs:53-55`)
   считает средний глиф `0.58` кегля, тогда как реальные метрики Noto Sans Display
   для кириллицы ≈ `0.62` (проекция `CHAR_W_FACTOR = 0.62` в
   `crates/canvas-app/src/docs_ui.rs:399`). Чипы `chip_width` (`whatif_ui.rs:116-118`)
   получаются уже подписей → текст физически шире чипа.
2. **Центровка «влево» при переполнении.** Рендер screen-текстов
   (`crates/canvas-render/src/text.rs:2515-2522`): сдвиг центровки
   `((width − line_w) * sf).max(0.0) / 2` обнуляется, когда строка шире выделенной
   ширины → текст прилипает к левому краю чипа и переливается вправо на соседа;
   `TextBounds` (`text.rs:2532-2537`) жёстко клипит справа (обрезанное «Сравнить»).
3. **Фиксированные ширины кнопок.** `BTN_WIDTH = 74` (`whatif_ui.rs:31`) не зависит
   от подписи: «Сравнить» (9 кириллических глифов ≈ 85–95 px) не влезает. Дополнительно
   ширина бара клампится к окну (`whatif_ui.rs:142-143`), но элементы продолжают
   раскладку за пределы rect (`take`, `whatif_ui.rs:152-156`) — при нехватке ширины
   элементы уезжают за правый край.

Отрисовка бара — `crates/canvas-app/src/app.rs:2159-2257` (квады чипов + screen-тексты,
подпись сценария берётся из `scenario.name` напрямую, `app.rs:2214-2220`).

## Требуемые изменения

1. `crates/canvas-app/src/whatif_ui.rs`:
   - коэффициент `text_width` `0.58` → `0.62` (синк с `docs_ui::CHAR_W_FACTOR`);
   - `CHIP_PAD_X` 10 → 12 и запас `CHIP_SLACK = 4.0` в `chip_width`;
   - новый `btn_width(label) = max(BTN_WIDTH, text_width(label, 13) + BTN_PAD_X * 2)`;
     Apply/Сброс/Сравнить раскладываются по нему;
   - новый `pub fn chip_label(name) -> String` — кап имени сценария 24 символа с «…»
     (единый источник для ширины чипа и подписи при отрисовке);
   - узкое окно: все элементы клампятся внутрь rect бара.
2. `crates/canvas-app/src/app.rs:2214-2220` — подпись чипа сценария рисовать через
   `whatif_ui::chip_label` (чип и текст не разойдутся).
3. Рендер-центровку `text.rs:2521` не менять (общий путь других оверлеев); после
   исправления раскладки ветка `max(0.0)` для бара недостижима.
4. Тесты `whatif_ui.rs`: непересечение элементов, `btn_width ≥ подпись`,
   кап `chip_label`, узкий вьюпорт — элементы внутри бара.
