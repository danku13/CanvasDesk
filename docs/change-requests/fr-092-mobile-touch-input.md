# FR-092: Мобильный тач-ввод web-версии — тап/драг одним пальцем, пан+пинч двумя

- **Статус:** выполнено
- **Тип:** FR (дефект ввода → фича жестов)
- **Приоритет:** важно
- **Владелец:** агент (сессия 2026-10-03)
- **Источник:** запрос владельца 2026-10-03: «Нужно проверить почему на мобильных устройствах работает только html оверлей, но не работает wasm»
- **Связанные задачи:** wasm-port §7/§9 («Тач-жесты (мобильные Chromium)» — вне v1, заявка волны 2), CR-014 (dvh/touch-action CSS), FR-052 (диспетчер поверхностей — глушение жестов над UI)
- **Создан:** 2026-10-03

## Описание

Симптом владельца: на мобильных устройствах в web-сборке (Pages `/app/`) «работает
только HTML-оверлей, но не работает wasm». Диагностика (headless-браузер,
мобильная эмуляция, задеплоенный бандл + локальный) показала: wasm **стартует и
рисует** — двухступенчатый выбор GPU (FR-WASM-02) корректно фолбэкается на
WebGL2, канвас живой. Мёртв именно **ввод**: winit-web для `pointerType=touch`
шлёт ТОЛЬКО `WindowEvent::Touch` (совместимые mouse-события подавлены
`prevent_default` — pointer.rs winit 0.30), а canvas-app обрабатывал только мышь
(`CursorMoved`/`MouseInput`) и клавиатуру — ветки `WindowEvent::Touch` не было
вовсе. Телефонный пользователь видел канвас и DOM-оверлеи (пикер, тур DOM-часть,
тулбар), но не мог ни тапнуть, ни драгнуть, ни зазумить canvas-UI.

Дополнительно проверено и закрыто смежное: машина жестов чистая и тестируемая
(нативные тесты CI), two-finger жесты — стандартная механика canvas-приложений.

## Влияние

| Объект | Что сломано | Где |
|---|---|---|
| canvas-app (web) | касания не обрабатывались — приложение неотзывчиво на тач-устройствах | `crates/canvas-app/src/app/handler.rs` (ветка `WindowEvent::Touch` отсутствовала) |
| жесты зума/пана | pinch/два пальца — вне v1 (wasm-port §9), на мобиле нет альтернативы зуму | `crates/canvas-core/src/touch.rs` (новое) |
| натив (Windows-тачскрины) | риск двойной обработки при ungated Touch-ветке — исключён cfg-гейтом | `#[cfg(target_arch = "wasm32")]` |

## Решения

- **canvas-core `touch.rs` (новое)** — чистая машина `TouchGesture::step(id, phase, pos, scale) -> Action`:
  первый палец ведёт одиночный жест (`Press`/`Move`/`Release` → левая кнопка мыши,
  курсор обновляется ДО нажатия — `on_left_button` работает по `self.cursor`);
  второй палец ОТМЕНЯЕТ одиночный жест без коммита (`Action::Cancel` →
  `cancel_pointer_transients`: драг ноды/резиновый прямоугольник не оставляются)
  и переводит пару в режим «пан серединой + pinch-зум отношением дистанции»
  (якорь — середина, лог. px; фактор клампнут [0.5; 2.0]); любой палец вверх в
  двухпальцевом режиме завершает жест целиком — оставшийся не подхватывается;
  `Cancelled` (pointercancel) — отмена без коммита; выродившаяся дистанция
  (наложение пальцев) — база не обновляется мусором. 8 unit-тестов.
- **canvas-app** — `on_touch` (wasm32-гейт; натив не затронут) применяет
  `Action` к существующему мышино му пайплайну/камере; `TwoFinger` глушится под
  модалкой и над screen-space UI (паритет `on_pinch`/FR-052). Debug-оракулы
  `touch: событие/действие` — по образцу `mouse: левая кнопка` (?log=debug).
- **Диагностика харнесса** (для будущих сессий): синтетический тач в headless
  требует (1) `getCoalescedEvents → [self]` — winit итерирует ТОЛЬКО coalesced
  список и молча роняет Moved; (2) `button: -1` на pointermove — иначе winit
  трактует событие как chorded-button и шлёт MouseInput вместо Touch.
- **Попутно**: `telemetry.rs` thread_local → `const { RefCell::new(None) }`
  (clippy `missing_const_for_thread_local` на wasm32; CI-гейт это не ловит —
  там на wasm32 только `check`).

## Приёмка

- 8 unit-тестов машины жеста (canvas-core, натив CI).
- Браузерный дым (headless, мобильный вьюпорт 390×700, синтетический
  pointerType=touch): тап по canvas-кнопке «Пропустить» закрывает онбординг;
  тап «Пустой холст» очищает сид; Moved доставляется, машина шлёт
  `Move`/`Cancel`/`TwoFinger{pan:[30,15], factor:1.64}` (лог-оракулы); пан
  сдвигает сетку, pinch меняет масштаб (пиксельный diff скриншотов + adaptive
  сетка скрывает minor-линии при отдалении); жест над flyout поглощается
  поверхностью (FR-052).
- Гейты: fmt, clippy -D warnings (натив; wasm32 lib — строже CI), test
  --workspace (83 набора зелёные), wasm_gate.sh --check.
