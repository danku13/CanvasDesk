## Описание (What)

Аудит вёрстки палитры шаблонов (FR-024) выявил три дефекта: (1) последняя
видимая строка списка **перекрывает футер-подсказку** «Enter — вставить ·
Esc — закрыть» (~12 px) — в геометрии панели нет резерва под футер; (2) ширина
чипов категорий считается **по байтам**, а не по символам — кириллические
категории дают чип вдвое шире текста, чипы вылезают за панель, а не влезшие
категории молча отбрасываются; (3) заливки палитры (подложки, чипы, плитки,
селекшн) **захардкожены тёмными константами** — в светлой теме палитра
останется тёмной. Кто выявил: агент (аудит кода).

## Влияние (Impact)

| Объект | Что сломано | Где в документации |
|---|---|---|
| Палитра шаблонов (Ctrl+P) | Строка налезает на футер-подсказку | `user-docs/interface.md` (палитра) |
| Палитра шаблонов | Кириллические категории — неверная ширина чипов, часть категорий недоступна | `user-docs/templates.md` |
| Темы оформления | Светлая тема ломает палитру (тёмные карточки на светлом фоне) | `docs/interface-objects/` (темы), `user-docs/interface.md` |

## Анализ (Root Cause)

- **Строки на футере:** `crates/canvas-app/src/template_ui.rs:335` —
  `bottom_limit = y + height − PANEL_PADDING(10)` — кламп видимых строк не
  учитывает футер; футер рисуется от `panel_bottom − 22`
  (`crates/canvas-app/src/main.rs:3344-3354`, кегль 10 + отступы) → пересечение
  ≈ 12 px для последней влезшей строки. В `PanelLayout` нет `footer_rect`.
- **Чипы по байтам:** `template_ui.rs:321` — `w = category.len() as f32 * 7.5
  + 20.0`; `str::len()` — байты UTF-8, кириллица = 2 байта/символ → чип ~вдвое
  шире текста → чипы выходят за `x + width − PANEL_PADDING`, срабатывает `break`
  (template_ui.rs:323) — остальные категории исчезают без индикатора. С
  латинскими именами (мок-реестр) не проявляется — тесты зелёные.
- **Хардкод цветов:** `main.rs:3240-3246, 3286-3294, 3310` — заливки
  дефолтных чипов/подложек/плиток/селекшна константами
  (`[0.13,0.14,0.18,…]`, `[0.18,0.29,0.48,…]`). Светлая тема существует
  (`crates/canvas-render/src/theme.rs:100-101`), соседний `search_overlay`
  для дефолтной заливки использует палитру `palette.search_row_fill`
  (`main.rs:2852`) — образец палитурной заливки рядом.

## Требуемые изменения (Changes)

1. **`crates/canvas-app/src/template_ui.rs`**
   - константа `PANEL_FOOTER_H: f32 = 24.0`; `bottom_limit = y + height −
     PANEL_PADDING − PANEL_FOOTER_H`;
   - `PanelLayout { footer_rect, … }` — прямоугольник футера (единый источник
     для рендера и hit-test, инвариант WYSIWYG);
   - ширина чипа: `category.chars().count() as f32 * 7.5 + 20.0` (или
     текстовый замер, если появится); чипы, не влезшие в ширину, — как раньше
     отбрасываются, но теперь по корректной ширине.
2. **`crates/canvas-app/src/main.rs`** — рендер футера из `lay.footer_rect`;
   заливки палитры из `ThemeColors`/`palette` (по образцу `search_overlay`,
   `main.rs:2852`): подложка панели, подложки карточек, чипы (default/active),
   плитки, hover/селекшн-акцент. Поля в палитру темы — по аналогии с
   `search_row_fill` (тёмная и светлая темы).
3. **Тесты** (`template_ui.rs`) — инвариант: ни один `row_rect` не пересекается
   с `footer_rect` (AABB-тест по всем видимым строкам); ширина чипа для
   кириллической категории ≤ ширины текста + паддинга (чип влезает в панель
   наряду с соседями для типового набора категорий); геометрия панели без
   изменений в остальных частях.
4. **Документация** — `user-docs/interface.md` (палитра: футер, темы),
   при необходимости `theme.rs` — новые поля палитры.

## Проверка (Verification)

- Палитра на реестре с максимумом категорий: ни одна видимая строка не
  пересекает текст футера (юнит AABB + визуально).
- Кириллические категории (например «Базы данных», «Очереди»): чипы по ширине
  текста, все категории, влезающие в ширину панели, видны.
- Переключение тёмной/светлой темы: палитра (подложки, чипы, карточки,
  селекшн) перекрашивается палитурно, без тёмных пятен в светлой теме.
- Гейты: `cargo fmt --check`, `clippy --workspace -- -D warnings`,
  `cargo test --workspace` — зелёные.
