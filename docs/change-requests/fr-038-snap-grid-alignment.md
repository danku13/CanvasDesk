## Описание

Требуется магнитная раскладка канваса для расчётных схем (unit-экономика, ИТ-инфраструктура, value flow): ноды при перетаскивании притягиваются к фоновой сетке (snap-to-grid срабатывает в момент отпускания кнопки мыши, во время драга — визуальный предпросмотр) и к соседним нодам (smart guides: направляющие по краям/центрам/серединам, majority-alignment, равные интервалы). Дополнительно: batch-операции выравнивания/распределения для выделения N≥3, collision-avoidance (опционально), клавиатурная точная корректировка (стрелки 1px, Shift+стрелки 10px), детерминированность и разделение snap-операций в undo. Функционала снаппинга в кодовой базе нет — требование выявлено владельцем.

## Анализ (что отсутствует — с код-ссылками)

- **Snap-выравнивания нет**: поиск `snap|alignment|guide` по `crates/` даёт только snapshot-хиты (виджеты). Ни движка, ни API, ни render-прохода не существует.
- **Drag**: `DragState { primary, grab_world, origins: Vec<(usize, Vec2)> }` — `crates/canvas-app/src/lib.rs:561`; старт drag — `app.rs:7741`; применение дельты `origin + delta` — `app.rs:8200`; undo по факту перемещения — `app.rs:~2403` (`push_undo` снапшотом, модель FR-006 — полный `Canvas`). Snap-at-release встраивается в завершение drag; nudge — рядом с обработкой клавиш.
- **Сетка**: шаг уже настраиваемый пресетами `GridDensity` — `crates/canvas-core/src/settings.rs:105-113` (Dense 10/50, Medium 20/100, Sparse 40/200 world-px, minor/major); рендер — `crates/canvas-render/src/grid.rs` + `shaders/grid.wgsl`. Zoom-адаптивности (sub/coarse) и снапа к ней нет.
- **Настройки**: `Settings` c `#[serde(default)]` — `settings.rs:148`; паттерн добавления полей без ломки старых `config.toml` отработан (`line_ports` FR-025, `bottleneck_overlay` FR-016); группы UI — `SettingsGroup` (`crates/canvas-app/src/settings_ui.rs:78`, FR-026).
- **Клавиши**: стрелки заняты оверлеем поиска (`app.rs:3396-3420`, ветка поиска); глобального nudge выделения нет — добавить в общий keybinding-контур с условием «поиск закрыт, есть выделение».
- **Оверлеи**: прецеденты — SDF-проход секторов `canvas-render/src/sectors.rs` (+ WGSL, FR-022), рамка выделения `select_rect` (`app.rs:677/7756`), bottleneck-бейджи (FR-016). Направляющие — отдельный проход поверх нод, ниже wheel-меню.
- **Зум**: `zoom: f32` — `crates/canvas-scene/src/scene.rs:48`, доступ `camera.zoom()` — `app.rs:6289`; пересчёт экранных px → world на кадр.

**Задачи реализации:**

## Проверка

- Сетка: drag ноды → призрак snapped-позиции виден во время драга; отпускание → нода на шаге сетки; шаг = текущий `GridDensity`; zoom > 150% — sub-линии, < 50% — coarse-линии.
- Guides: приближение к соседу в пределах tolerance → magenta-направляющая по совпавшей оси (край/центр/середина); интенсивность растёт при приближении; исчезает при отпускании или выходе из допуска.
- Majority: при нескольких кандидатах выбирается ось с наибольшим числом совпадающих соседей; grid-vs-guide — минимальная дельта.
- Equal spacing: три ноды в ряд со средним перетаскиваемым — направляющая равных интервалов.
- Групповой drag: взаимное положение выделения сохраняется, snap по bbox.
- Collision (флаг вкл): нода останавливается на границе зазора; флаг выкл — прохождение сквозь.
- Настройки: три тумблера раздела «Snap» независимы; мастер-тумблер гасит весь снап без сброса остальных; старый `config.toml` грузится.
- Undo: drag без снапа — один шаг; со снапом — два (drag, коррекция); batch-выравнивание — один; Ctrl+Z/Ctrl+Y корректны.
- Nudge: стрелки — 1px, Shift+стрелки — 10px, работает при включённом снапе, каждый шаг в undo.
- Детерминизм: повторный драг из тех же позиций даёт идентичный результат.
- Гейты: `fmt --check`, `clippy -D warnings`, `test --workspace`, `scripts/wasm_gate.sh`, `scripts/mcp_wasm_gate.sh` — зелёные; CI на merge-коммите зелёный.
