# CR-002: Перепривязка связей к другим нодам/портам без удаления

- **Статус:** в работе
- **Тип:** CR
- **Приоритет:** критично
- **Владелец:** агент (реализация)
- **Источник:** сообщение пользователя (сессия 2026-09-13): «связи должна быть возможность перепривязать к другим точкам без удаления»
- **Связанные задачи:** TASKS.md T8 (связи); CR-001 (выделение); CR-003 (зона портов); docs/interface-objects/edge.md §4, §7

## Описание (What)

Связь нельзя перепривязать: единственный способ изменить её конец — удалить связь
и создать новую (`Delete`, затем edge-drag от порта). Пользователь требует: захват
конца существующей связи и перенос его на другую ноду (или другой порт) без
удаления. Выявлено пользователем.

## Влияние (Impact)

| Объект | Что меняется | Где в документации |
|---|---|---|
| `edge` | Новое взаимодействие: drag конца выделенной связи = перепривязка; рендер хэндлов концов | `docs/interface-objects/edge.md` §4 (взаимодействия), §5 (состояния) |
| `node` | Порты ноды под курсором при выделенной связи уступают хэндлам концов (порядок hit-теста) | `docs/interface-objects/node.md` §4 |
| `canvas-app` | `EdgeDrag` расширяется режимом Rebind; логика отпускания ЛКМ | `crates/canvas-app/src/main.rs`, `src/lib.rs` |

## Анализ (Root Cause)

- `EdgeDrag` (`crates/canvas-app/src/lib.rs:263`) — структура с полями
  `from_node`/`from_side`: описывает ТОЛЬКО создание новой связи. Режима
  «тянем конец существующей связи» нет.
- `on_left_button` (`crates/canvas-app/src/main.rs:3266`): при нажатии ЛКМ
  проверяется только порт hover-ноды (`port_at`) — старт новой связи. Хит-тест
  концов существующих связей отсутствует.
- Отпускание ЛКМ (`main.rs:3347-3370`): `edge_drag.take()` создаёт НОВУЮ связь
  (`Edge::new` + `add_edge`). Ветви «перенаправить существующую» нет.
- `Edge::from_node/from_side/to_node/to_side` (`crates/canvas-core/src/model.rs:235-244`) —
  изменяемые поля, модель перепривязки не препятствует; мешает только ввод.
- Сторона связи при `from_side == None` (авто) вычисляется геометрией
  (`edge_curve`, `crates/canvas-core/src/edgegeom.rs:157`) — для позиции хэндла
  нужен тот же резолв.

## Требуемые изменения (Changes)

1. `canvas-app/src/lib.rs`: `EdgeDrag` → enum
   `New { from_node, from_side } | Rebind { edge_index, end }` (+ `EdgeEnd`
   `From/To`); чистая функция `retarget_edge` — применить перепривязку к модели
   (проверка: цель ≠ противоположный конец, запрет петель).
2. `canvas-core/edgegeom.rs`: `edge_endpoint(canvas, edge, end)` — разрешённая
  сторона + точка порта конца связи (резолв как в `edge_curve`).
3. `main.rs` `on_left_button` (Pressed): если выделена связь и курсор в допуске
   зоны (CR-003, `port_zone_px`) хэндла конца — `EdgeDrag::Rebind`
   (проверка ДО портов: занятый хэндл важнее старта новой связи).
4. `main.rs` (Released): `Rebind` → `retarget_edge` на ноду под курсором
   (`selective_hit`, `nearest_side`); пустота/та же нода — отмена без изменений.
5. Рендер: хэндлы концов выделенной связи (кружки на концах, `cards.rs`,
   паттерн `build_port_instances`); во время rebind-drag исходная линия связи
   скрыта, резиновая линия — от НЕПОДВИЖНОГО конца к курсору (переиспользуем
   `edge_draft`), т.е. `SceneView` получает `hidden_edge: Option<usize>`.

## Проверка (Verification)

- Выделить связь (клик по линии) → на обоих концах кружки-хэндлы.
- Drag хэндла на другую ноду → связь следует за курсором от неподвижного конца;
  отпускание на ноде — `fromNode`/`toNode` и сторона обновились, id связи и
  настройки (лейбл/цвет/стиль) сохранены, автосейв сработал.
- Отпускание в пустоте/на той же ноде/на противоположной ноде — связь без
  изменений (отмена).
- Unit-тесты: `retarget_edge` (успех, отмена-петля, отмена-пустота),
  `edge_endpoint` (явные и None-стороны).
