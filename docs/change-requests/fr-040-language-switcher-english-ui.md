## Описание (What)

Все интерфейсные тексты CanvasDesk захардкожены по-русски прямо в коде
UI-модулей: лейблы настроек и значения (`settings_ui.rs`, `label()` в
`canvas-core`), пункты контекстного меню, категории палитры шаблонов,
тексты подсказок, шаги онбординга, панель хоткеев, what-if панель,
wheel-меню, тосты, модальные диалоги. Русский — единственный язык;
смена языка невозможна без правки кода.

Требуется: (1) **механизм локализации** — интерфейсные тексты переводятся
в таблицы строк по ключам, ни одного UI-литерала в коде рендера/моделей;
(2) **переключатель языка** — dropdown «Язык» в разделе «Внешний вид»
модалки настроек (FR-039); выбор применяется **на лету** (без перезапуска)
и сохраняется в `config.toml` (новое поле `language` с `#[serde(default)]` —
старые конфиги не ломаются); (3) **полный перевод на английский** всех
UI-элементов; язык по умолчанию — русский. База — таблица строк настроек,
введённая в FR-039 (§5), здесь она обобщается на весь UI.

## Исследование бест-практик (Research)

Источники:

- **VS Code / Obsidian, «Display Language»**: переключатель в настройках;
  смена языка применяется сразу (VS Code — после reload, Obsidian —
  на лету); отсутствующие переводы — fallback на английский; выбор
  сохраняется в конфиге пользователя.
- **gettext-модель**: строка-источник/ключ → таблица переводов на язык;
  полнота таблиц проверяется инструментально (missing-key тесты).
- **iOS/macOS HIG «Localization»**: интерфейсные строки не конкатенируются
  из кусков — каждая полная фраза отдельный ключ (правильные порядки слов
  в языках); это правило переносим: ключ = полная фраза, без склейки
  «лейбл + ": " + значение» (значение — контрол, FR-039).

Применение к CanvasDesk: ноль внешних крейтов — статические таблицы
`[(ключ, [&str; N_языков])]` в чистом модуле `i18n` крейта `canvas-app`;
язык — поле `Settings`; все UI-модули читают тексты через `tr()`.
Шрифтовая база готова: Noto Sans Display/Mono (`assets/fonts/`) покрывают
латиницу — английские тексты рендерятся без новых шрифтов (проверить
набор глифов атласа рендера на этапе реализации).

## Анализ (Root Cause — чего нет в коде)

Механизма локализации нет — язык вшит в код. Инвентаризация поверхностей
с хардкод-RU (переносить на ключи):

| Поверхность | Примеры хардкода | Где |
|---|---|---|
| Настройки (FR-039) | лейблы, описания, заголовки табов, значения, подсказка «Ctrl+,» | таблица строк настроек — база уже заложена FR-039 §5 |
| Значения настроек из core | «верхний левый», «линии», «частая», вкл/выкл | `Corner::label`, `GridStyle::label`, `GridDensity::label`, `Theme::label` (`canvas-core/src/settings.rs:33-142`) — в рендер не идут, ключи в app-таблице |
| Контекстное меню | «Новая заметка», «Цвет…», подменю | `ContextMenu` (`canvas-app/src/lib.rs`, рендер в `app.rs`) |
| Панель хоткеев | строки `HOTKEYS` (описания) | `canvas-app/src/lib.rs:379+` (`ui::HOTKEYS`) |
| Палитра шаблонов | категории, кнопки доков | `template_ui.rs` (FR-024/030) |
| Подсказки-попапы | тексты подсказок | `hints_ui.rs` (FR-021) |
| Онбординг | шаги тура, кнопки | `onboarding_ui.rs` (FR-028) |
| Меню «?» / docs-viewer chrome | пункты меню документации | `docs_ui.rs` (FR-031); сам контент md — вне скоупа |
| What-if | панель сценариев | `whatif_ui.rs` (FR-017) |
| Wheel-меню | пункты выбора шаблонов | `app.rs` (FR-018/022) |
| Поиск | placeholder/подписи панели | `search_ui.rs` / `app.rs` (FR-014) |
| Тосты/бейджи | «риск», предупреждения узких мест | `app.rs` (FR-016) |
| Модальный диалог T21 | вопрос + кнопки Да/Нет | `app.rs:8759+` (T21) |
| Заголовки/хинты оверлеев | «Настройки», «Горячие клавиши» | `app.rs:6057-6104` |

Чего нет в коде: enum `Language` и поле в `Settings`
(`settings.rs:148-197`); таблиц строк; API выборки по ключу; переключателя
в UI. Шрифты латиницу покрывают (см. Research) — рисков нет, проверить
только набор глифов атласа (если он фиксированный — расширить).

## Требуемые изменения (Changes)

### 1. Модель: язык в конфиге (`canvas-core`)

- `Language` enum: `Ru` (default) / `En`, `#[serde(rename_all = "snake_case")]`,
  сериализация «ru»/«en» — паттерн `Theme` (`settings.rs:44-71`).
- `Settings`: + `pub language: Language`, `#[serde(default)]` на struct
  уже есть — старые конфиги без поля грузятся как `Ru` (паттерн
  `focus_mode`/`onboarding_done`); round-trip и `field_names_snake_case`
  тесты обновляются (+ `language`).
- Смена языка — обычное поле настроек: сохранение тем же хвостом
  `settings.save(config_path)`.

### 2. Механизм: модуль `canvas-app/src/i18n.rs` (чистый, с тестами)

- Ключи — константы (`pub const SETTINGS_TITLE: &str = "settings.title";` …);
  таблицы: `RU_TABLE: &[(&str, &str)]`, `EN_TABLE: &[(&str, &str)]`
  (статические, ноль внешних крейтов).
- API: `pub fn tr(language: Language, key: &str) -> &'static str` —
  `match language` → поиск в таблице; отсутствующий перевод — fallback
  на RU (и паника в тестах, не в рантайме).
- Ключ = полная фраза (без склейки кусков) — правило локализации из
  Research; значения-подстановки (например, номер шага онбординга) —
  ключ целиком с местом подстановки, форматирование на стороне вызова.
- Таблица настроек из FR-039 (§5) переносится в общий модуль (тот же
  формат ключей) — единый источник текстов.

### 3. Перевод всех UI-поверхностей на ключи (таблица из Анализа)

- Каждая поверхность из таблицы Анализа переходит с литералов на `tr`:
  контекстное меню, панель хоткеев (`ui::HOTKEYS` — описания), палитра
  шаблонов (категории/кнопки), подсказки, онбординг, меню «?»,
  what-if, wheel-меню, поиск, тосты/бейджи, диалог T21, заголовки
  оверлеев. Рендер/модели не содержат UI-литералов.
- **EN-таблица — полный перевод** всех ключей (ни одного пропуска —
  инвариант полноты ниже).
- Названия шаблонов (`assets/templates/*/template.json`) и контент
  документации (`user-docs/*.md`) — данные, не UI-код: не переводятся
  (ограничение v1, см. Открытые вопросы).

### 4. Переключатель языка (UI)

- Раздел «Внешний вид» модалки настроек (FR-039): строка «Язык» с
  dropdown-кнопкой — значения «русский» / «English» (ключи таблицы);
  выбор — `settings.language = …` + сохранение + перерисовка (все тексты
  читаются по кадру — паттерн рендера уже такой, пересборка текстов
  не нужна).
- Механика строки — существующий `RowKind::Dropdown`
  (`dropdown_options`/`apply_dropdown_value` — новая ветка или соседний
  контрол; значение из `settings.language`).
- Клавиатурные алиасы (`Ctrl+Б`/`Ctrl+И` — кириллические раскладочные
  соседи запятой/B) остаются: они привязаны к физической раскладке
  пользователя, не к языку интерфейса.

### 5. Совместимость и регрессии

- Старый `config.toml` без `language` — русский (serde default).
- Тесты, сравнивающие русские строки UI (`label()`-порождения,
  тексты подсказок), обновляются на ключи/таблицы.
- Документация и названия шаблонов — не меняются (см. выше).

## Архитектура тестируемости (инварианты FR-040)

1. **Полнота:** `ALL_KEYS` — у каждого ключа есть непустой RU и непустой
   EN перевод; дублей ключей нет (тест перечислением).
2. **Схема:** `language = "en"` читается; отсутствие поля — `Ru`;
   round-trip сохраняет выбор; `field_names_snake_case` содержит
   `language`.
3. **Переключение:** `tr(En, key) != tr(Ru, key)` для репрезентативного
   набора (заголовок настроек, лейбл «Сетка», пункт меню, шаг онбординга);
   выбор dropdown языка меняет `settings.language`.
4. **Fallback:** отсутствующий ключ в EN — RU-значение в рантайме и
   провал теста полноты в CI (перевод не теряется молча).

## Открытые вопросы дизайна

- **Автоопределение языка системы** при первом запуске (Windows locale /
  `navigator.language` в web) — v2; v1 — дефолт `Ru`.
- **Переключатель вне настроек** (кнопка в кластере ⚙/☀/?) — не нужен v1
  (язык меняется редко, Obsidian/VS Code держат его в настройках).
- **Третьи языки** — таблица и `Language` расширяемы (добавить вариант
  enum + таблицу); добавление — по запросу владельца.
- **Перевод контента** (названия/описания шаблонов в `template.json`,
  `user-docs/*.md`, статьи) — отдельное решение владельца, вне скоупа
  этого FR (данные, не UI-код).

## Проверка (Verification)

### Юнит-тесты (i18n)

- Полнота таблиц: все ключи имеют непустые RU и EN, дублей нет.
- `tr`: переключение `Ru` → `En` меняет репрезентативные тексты;
  fallback отсутствующего ключа (в тестовом наборе) на RU.
- Ключи настроек из FR-039 (лейблы, описания, табы, значения) присутствуют
  в общей таблице в обоих языках.

### Юнит-тесты (canvas-core/settings)

- `Language`: serde «ru»/«en», дефолт `Ru`, round-trip; старый конфиг
  без `language` — `Ru` без предупреждения.
- `field_names_snake_case` — прежний набор + `language`.

### Ручная приёмка

- `Ctrl+,` → «Внешний вид» → «Язык: English» — контекстное меню, палитра,
  панель хоткеев, подсказки, онбординг, what-if, поиск, тосты, диалоги,
  модалка настроек — весь UI на английском, **без перезапуска**.
- Перезапуск — язык сохранился (`config.toml`: `language = "en"`).
- Старый конфиг без поля — интерфейс русский.
- Латиница рендерится корректно (нет квадратов/пропусков глифов) в обеих
  темах; гейты: fmt, clippy -D warnings, test — зелёные.
