## Решения владельца (Q&A)

**Вопрос Q4 (сессия 2026-10-08): «Как подсказывать входящие параметры в автодополнении?»**

| Вариант | Суть |
|---|---|
| **Имя без $ + после $ ← выбрано** | Ввод имени без `$` подсказывает входы; кириллица — формат «Нода.параметр» (грамматика поддерживает), ASCII — `$имя` |
| Только после $ | Доработать список после `$`, ввод имени не триггерит |
| Панель входов | Ввод имени показывает постоянную панель «входы ноды» рядом с попапом |

**Дополнительное решение владельца (примечание к Q4):** триггер по имени — обязателен («не требовало обязательного запоминания кодового символа»).

---

## Описание (What)

Автодополнение в Numi-строках не предлагает входящие параметры: по `$` предлагаются только `$in`/`$1..$N` (и `$параметры` манифеста шаблона), а по вводу имени параметра — вообще ничего. Требуется: (1) подсказки работают при вводе имени **без `$`**; (2) в список после `$` входят именованные входы; (3) формат вставки зависит от языка токена: кириллица → `Нода.параметр` (qualified, грамматика поддерживает), ASCII → `$имя` (рантайм-резолв уже работает). Дополнительно фиксируется ложный счётчик `$N`.

## Влияние (Impact)

| Объект | Что меняется | Где в документации |
|---|---|---|
| `HintContext` | Имена входов: toParam-спиллы, qualified-ключи, выходы источников | FR-021 (расширение), ADR-0003 |
| `hint_items` | Новые ветки: `$`-токен матчит по имени без `$`; идентификаторный токен матчит `$`-рефы и `Объект.Поле` | FR-021 |
| Формат вставки | Кириллица → `Объект.Поле`, ASCII → `$имя` (без правки грамматики) | FR-050 Р-6, FR-013 |
| Счётчик `$N` | `inbound` исключает toParam-рёбра (фикс ложных `$2`) | FR-014 |

## Анализ (Root Cause)

Полный разбор — UR-001-05/07. Слои:

1. `HintContext` (`crates/canvas-app/src/app/overlays.rs:2137-2164`) не содержит имён: только количество value-рёбер и параметры манифеста; спиллы `to_param` резолвятся как `$имя` в рантайме (`flow.rs:1057-1066`, тесты `flow.rs:2102-2141`), но в подсказки не заведены; qualified-ключи (`QualifiedNames::edge_keys`, `flow.rs:1120-1129`; obj = title ноды — `dataref.rs:60-90`) тоже.
2. `$`-ветка (`hints_ui.rs:137-171`) генерируется только при токене с `$` (`strip_prefix('$')`); идентификаторный токен уходит в переменные/функции/единицы (`hints_ui.rs:208-240`); токен не включает `.` (`hints_ui.rs:109-123`); ветки qualified в `hint_items` нет.
3. **Форма `$Купон.купон` из handtest грамматикой не поддерживается**: `$`+кириллица = валюта (`dollar_param_ident` ASCII-only — `expr.rs:351-370`; fallback `Tok::Unit("$")` — `expr.rs:1098-1103`; `$` в UNIT_TABLE — Money, `expr.rs:298`) → парсится как «1 доллар × Купон.купон»; рабочая форма — `Купон.купон` без `$` (адресованное ребро) или `$in`/`$1` (неадресованное).
4. **Сайд-финд:** `ctx.inbound` считает все value-рёбра, включая `toParam`, а слоты их исключают (`flow.rs:942-959`, фильтр `:955`) → ложные `$2`.

**Происхождение:** неполнота согласованного скоупа FR-021 v1 (именованные входы ADR-0003 не вошли); счётчик — «тихий» дефект.

## Требуемые изменения (Changes)

1. `overlays.rs:2156-2163` — `ctx.params` объединяет: параметры манифеста, имена `to_param` входящих value-рёбер, qualified-ключи построчных рёбер (`Нода.имя_присваивания` через `spill_source_field`, `flow.rs:1503-1526`).
2. `overlays.rs:2144-2154` — `inbound`: `&& edge.to_param.is_none()` (зеркало flow.rs:955).
3. `hints_ui.rs:137-171` — `$`-токен: матчинг по имени без `$` (ввод `$куп` находит `Купон.купон`); порядок: именованные входы → `$in`/`$N` → функции → единицы; дедуп; приоритизация при `HINT_LIMIT=8` (имена раньше номеров, номера свёрнуто при N > 4).
4. `hints_ui.rs:208-240` — идентификаторный токен: дополнительно матчит имена входов (без `$`), `insert` — рабочая форма (кириллица → `Нода.параметр`, ASCII → `$имя`); деталь подсказки — источник («проливание из ноды X», новое i18n-поле по паттерну `hints.var/unit/param` — `i18n.rs:462-470, 1303-1310, 2522-2529`).
5. Грамматика не меняется (рантайм уже резолвит обе формы); строка `$Купон.купон` остаётся невалидной — при желании владельца поддержки `$Объект.Поле` оформить отдельным FR (изменение грамматики FR-013, риск конфликта с валютой `$`).

## Проверка (Verification)

- Репродуктор handtest: в ноде «Корзина за вычетом…» ввод `купо` (без `$`) → подсказка `Купон.купон` (деталь: источник «Купон»); ввод `$` → `$in`, `$1..$N`, `Купон.купон`, `Скидка.скидка` (спиллы), параметры манифеста (если шаблон); ввод `$купо` → тот же результат по имени.
- Счётчик: нода с 1 позиционным ребром + 1 toParam-ребром → подсказки `$1` и имя спилла; `$2` не предлагается.
- Вставка токена заменяет только набранный хвост (`replace_token_before_caret`), каретка после вставки.
- Тесты: `hints_dollar_refs` (hints_ui.rs:420-434) расширен кириллическим кейсом; golden-тесты suggest не трогаются.
