# Дефект: множественное выделение нод не работает

## Выявлено
Пользователь сообщил: **не работает множественное выделение нод** — ни через `Shift` + клик, ни через `Shift` + `drag` (рамка выделения).

## Анализ кода (`crates/canvas-app/src/main.rs`)

### 1. Структура выделения (`SceneState`, строка 189–190)
```rust
selected: Option<Selection>,
```
`Selection` (из `canvas_core` или `canvas_app`) — это `Node(index)` или `Edge(index)`. **Только один объект.** Нет `Vec<usize>` или `HashSet<usize>` для множественного выделения нод или связей.

### 2. Обработка клика ЛКМ (`on_left_button`, строка 3082–3195)
При клике на ноду (`Some(index)`):
```rust
self.scene.selected = Some(Selection::Node(index));
```
**Всегда перезаписывает** `selected`, не добавляет к существующему. Нет проверки `self.modifiers.shift_key()`.

При клике на пустое место (`None`):
```rust
self.scene.selected = self.selective_hit(world)
    .map(Selection::Node);
```
Или связь (`edge_at`):
```rust
self.scene.selected = edge_at(...).map(Selection::Edge);
```
**Нигде не учитывается `Shift`** для добавления к выделению или для создания рамки (`drag` с `Shift`).

### 3. Обработка `Shift`-клавиши
`ModifiersState` (`self.modifiers`) содержит `shift_key()`, но **ни в одном месте кода** (`on_left_button`, `on_key`, `window_event`) не используется `shift` для выделения:
- `on_key` (строка 2880–2906): `Shift` не упоминается (только `Delete` для `delete_selected`).
- `window_event` (`KeyboardInput`): передаётся в `on_key`, но `Shift` не обрабатывается.
- `ModifiersChanged` (строка 2177): обновляет `self.modifiers`, но не влияет на выделение.

### 4. Drag (рамка выделения)
`dragging` (`SceneState`, строка 192) — это `(usize, Vec2)` — **одна нода + смещение**. Нет механизма для `drag`-рамки (выделение нескольких нод через протаскивание с `Shift` или без `Shift`). `left_pressed` + `drag` — это перемещение ноды (`self.scene.dragging`), не выделение.

### 5. Рендер (`canvas-render` — `SceneView`)
`selected` передаётся в `SceneView` (строка 2339):
```rust
selected: self.scene.selected,
```
Рендер (`renderer.render`) использует `selected` для подсветки (рамка или цвет). **Нет поддержки нескольких выделенных нод** (нет `selected_ids` или `selected_nodes`).

## Рекомендация (для расширения функционала)
Для исправления множественного выделения потребуется:
1. **Изменить `SceneState.selected`** с `Option<Selection>` на структуру, поддерживающую несколько нод (`Vec<usize>` или `HashSet<usize>`) и связи (`Vec<usize>` или `HashSet<usize>`), или добавить отдельные поля (`selected_nodes: HashSet<usize>`, `selected_edges: HashSet<usize>`).
2. **Обновить `on_left_button`** для проверки `self.modifiers.shift_key()`:
   - `Shift` + клик по ноде → добавить/удалить из `selected_nodes` (тоггл).
   - `Shift` + `drag` (рамка) → выделить все ноды в прямоугольнике (`rstar` `query_rect` или `selective_hit` для каждой точки в прямоугольнике; или `rstar` `query_rect` с прямоугольником рамки).
3. **Обновить `delete_selected`** для удаления всех выделенных нод или связей (а не одной).
4. **Обновить рендер** (`SceneView`, `renderer.render`) для подсветки нескольких нод (рамка или цвет для каждой выделенной ноды; возможно, подсветка связей при выделении связанных нод — `T23` «динамическая подсветка связей»).
5. **Обновить документы интерфейсных объектов** (`node.md`, `edge.md`, `minimap.md`, `search.md`) после реализации.
