## Описание (What)

Пользователь не имеет возможности узнать горячие клавиши приложения: список
нигде не выводится (README частично, в приложении — ничего). Требуется меню со
списком клавиш и их описаний, позиция — у левого края окна, вертикально
по центру. Выявлено пользователем.

## Влияние (Impact)

| Объект | Что меняется | Где в документации |
|---|---|---|
| `canvas-app` | Новый screen-space оверлей (панель хоткеев), переключение F1/Esc, закрытие кликом мимо | `crates/canvas-app/src/main.rs`, `src/lib.rs` |
| рендер | Без изменений — переиспользуется `FrameOverlay.screen_instances/screen_texts` (паттерн панели настроек) | `crates/canvas-render/src/renderer.rs:97` |

## Анализ (Root Cause)

- Экранного списка хоткеев нет: `on_key` (`crates/canvas-app/src/main.rs:2899`)
  содержит разрозненные ветки (F3, Del, Ctrl+F, Ctrl+`, F, Space), но данные не
  сведены в структуру и не отображаются.
- Готовый паттерн рендера: `settings_overlay()` (`main.rs:2026`) — screen-квады
  `CardInstance` + `ScreenText` через `FrameOverlay`; геометрия панели — чистые
  функции (`panel_rect`, `canvas-app/src/lib.rs:206`).
- Позиции «посередине слева» нет: `panel_rect` прижимает панель к углам кнопки.

## Требуемые изменения (Changes)

1. `canvas-app/src/lib.rs` (ui): `HOTKEYS: &[(&str, &str)]` — единый источник
   данных (клавиша → описание) для оверлея; константы
   `HOTKEYS_PANEL_WIDTH/ROW_HEIGHT/PADDING/HEADER`;
   `hotkeys_panel_rect(viewport) -> [f32; 4]` — x = SETTINGS_MARGIN,
   y = (viewport.h − panel_h)/2 (кламп высоты в viewport);
   `hotkeys_panel_hit(rect, point)` — hit-тест панели.
2. `main.rs`: поле `hotkeys_open: bool`; `F1` — toggle (раскладконезависимо);
   `Esc` — закрыть (в цепочке Esc: меню → хоткеи → настройки); клик мимо
   панели по канвасу — закрыть (клик не проходит в канвас).
3. Рендер: в `settings_overlay` (или рядом) — панель + строки «клавиша —
   описание» (клавиша — акцентным цветом слева, описание — body справа),
   паттерн ScreenText как у панели настроек; строка-подсказка «F1 — закрыть».

## Проверка (Verification)

- `F1` → панель у левого края, вертикально по центру, список «клавиша — описание»
  читаем, фон непрозрачный, скруглённый.
- Повторный `F1` или `Esc`, или клик мимо панели — закрылась; канвас под клик
  не проваливается (не создаётся заметка двойным кликом).
- Открытая панель не ломает поиск/редактирование/меню (приоритет ввода:
  редактор > поиск > F1-панель закрывается по Esc после меню).
- Малое окно (высота < панели) — высота клампится, низ не вылезает за экран.
- Unit-тесты: `hotkeys_panel_rect` (центрирование слева, кламп),
  `HOTKEYS` непустые пары, `hotkeys_panel_hit`.
