# CR-016: Создание what-if сценария падает «уже существует» + toast рисуется поверх бара

- **Статус:** выполнено
- **Тип:** CR
- **Приоритет:** важно
- **Владелец:** агент (анализ + реализация)
- **Источник:** скриншот пользователя (сессия 2026-09-19, после фикса CR-015):
  клик по «+» в what-if баре показал toast «сценарий уже существует: Сценарий 2»,
  нарисованный поверх бара.
- **Связанные задачи:** FR-017 (what-if режим), CR-015 (вёрстка бара), ACCEPTANCE §28
- **Создан:** 2026-09-19
- **Обновлён:** 2026-09-19

## Описание

Два дефекта, видимых на одном скриншоте. (1) Кнопка «+» бара what-if не
создаёт сценарий: автоимя считается как «Сценарий {количество+1}» и при
любой непоследовательности имён («Сценарий 2», «Сценарий 3») коллидирует с
существующим — вместо сценария пользователь получает ошибку в toast.
(2) Toast нижнего центра (`ty = viewport − 44`) рисуется поверх what-if бара
(бар занимает `[viewport − 56, viewport − 12]`) — сообщение перекрывает чипы
и кнопки и читается с трудом.

## Влияние

| Объект | Что сломано | Где в документации |
|---|---|---|
| `whatif-bar` (чип «+») | Создание сценария падает при непоследовательных именах | ACCEPTANCE §28 (FR-017.8) |
| `toast` (T21) | Перекрывает what-if бар (и в принципе любой нижний центральный UI) | ACCEPTANCE §21 (T21) |

## Анализ

1. **Автоимя.** `SceneState::whatif_create_scenario`
   (`crates/canvas-scene/src/scene.rs:553-567`): имя по умолчанию —
   `format!("Сценарий {}", self.scenarios.len() + 1)`; коллизия →
   `Err("сценарий уже существует: …")`. Оба UI call sites дублируют ту же
   формулу сами (`crates/canvas-app/src/app.rs:1629` — создание из override-
   поля, и `app.rs:1952` — чип «+»), поэтому ветка пустого имени в scene
   не используется и коллизия доходит до пользователя. Воспроизведение:
   сценарии «Сценарий 2», «Сценарий 3» → «+» → «Сценарий 3» → ошибка.
2. **Toast.** Рендер toast'а (`app.rs`, блок T21): `ty = viewport[1] − 44.0`;
   бар what-if занимает `[viewport − BAR_MARGIN − BAR_HEIGHT, viewport −
   BAR_MARGIN]` = `[−56, −12]` (`whatif_ui.rs` `BAR_MARGIN/BAR_HEIGHT`).
   Toast перекрывает бар полностью (ширина `viewport − 80`).

## Требуемые изменения

1. `crates/canvas-scene/src/scene.rs::whatif_create_scenario`: пустое имя →
   первый свободный «Сценарий N» (N с 1 вверх, пропуск занятых) вместо
   `len+1`. Явные имена (MCP) — без изменений: коллизия по-прежнему ошибка.
2. `crates/canvas-app/src/app.rs` оба call sites: передавать `""` (имя по
   умолчанию из единого места — scene), убрать дублирование формулы.
3. `app.rs` (toast T21): при активном what-if (`self.scene.whatif_active`)
   поднимать toast над баром: `ty = viewport − BAR_MARGIN − BAR_HEIGHT −
   (высота строки + зазор)`.
4. Тесты (canvas-scene `tests.rs`): автоимя занимает первый свободный номер
   («Сценарий 2», «Сценарий 3» → новый «Сценарий 1»); после удаления —
   повторное создание даёт освободившийся номер; явное дублирующее имя —
   по-прежнему `Err`.
