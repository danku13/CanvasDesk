# CR-031: Онбординг v2 — финальный выбор, ролевое value, вёрстка 50/50; галерея на ките; фон-точки

- **Статус:** в работе (этапы S1–S6, сессия 2026-10-09)
- **Источник:** UR-002 — обратная связь владельца по онбордингу (`docs/user-reporting/ur-002-onboarding-v2.md`)
- **Затрагивает:** FR-028 (онбординг), FR-049 (галерея схем), FR-087 (роли), дефолты settings

## What

Семь правок первого запуска (см. UR-002):

- **S1. Поток до финала.** Шаг «Шаблоны нод» ведёт «Далее» (CTA
  `action_key`/`GALLERY_TRY` удалён — он досрочно завершал тур и открывал
  галерею вместо шаблонов нод). Финальный шаг — предложение выбора двумя
  полноширинными CTA-опциями над футером: «Открыть шаблонную схему»
  (primary — тур завершён, открыта галерея схем) и «Начать самому»
  (secondary — тур завершён, чистый холст). Шаг 9 «UI-консоль» выведен из
  тура (служебный экран перегружал новичка; меню «?» сохраняет доступ) —
  8 шагов. `OnboardingButton::{FinalGallery, FinalEmpty}`, `option_rects`,
  зона `ONBOARDING_OPTION_ZONE` резервируется из тела.
- **S2. Вёрстка 50/50.** Карточка тура: слева иллюстрация шага, справа
  текстовый блок с кнопками (50/50); узкие окна — одноколонный фолбэк.
- **S3. Ролевое value-приветствие.** Тело шага «Добро пожаловать» — value
  выбранной при входе роли (FR-087) либо универсальное описание без роли.
- **S4. Ревизия текстов.** «Заметки» — без лишнего про markdown-детали,
  Ctrl+Enter/Esc; «Связи» — два типа связей (logical / data); остальные —
  правка на value.
- **S5. Галерея схем на ките.** Панель/чипы/инпут/строки — стили и токены
  ui-kit (`modal_style`, `RADIUS_CHIP`, `RADIUS_PANEL`) вместо off-слотов и
  жёстких радиусов.
- **S6. Фон-точки.** Дефолт `GridStyle` — `Dots` (плотность Medium уже по
  умолчанию): сетка «рябила в глазах» у новых пользователей.

## Impact

Онбординг доводит пользователя до осмысленной развилки (шаблонная схема /
самостоятельный старт) вместо досрочного выхода на шаге 7; приветствие
говорит на языке роли пользователя; фон и панель галереи соответствуют
дизайн-системе.

## Verification

- `cargo test -p canvas-app onboarding` — карусель/кламп/hit-тесты/финальные CTA;
- draw-тесты оверлея (`we_onboarding_draw_tests`) — ужимание тела, слоты темы;
- интеграционные гейты workspace + `scripts/wasm_gate.sh --check` — на финале сессии.
