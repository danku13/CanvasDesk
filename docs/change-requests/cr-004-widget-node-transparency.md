# CR-004: Виджет-нода должна быть полностью прозрачной под контентом виджета

- **Статус:** выполнено
- **Тип:** CR (Change Request)
- **Приоритет:** важно
- **Владелец:** агент (анализ)
- **Источник:** сообщение пользователя (сессия 2026-09-15): «виджеты не должны быть на нодах или ноды для них должны быть полностью прозрачными»
- **Связанные задачи:** FR-009 (настройка прозрачности в меню), CR-006 (ввод поверх виджетов), SPEC.md §7.6 (движок виджетов), WIDGETS.md §7–§8
- **Создан:** 2026-09-15
- **Обновлён:** 2026-09-16 (аудит реализации)
- **Документ-шаблон:** `docs/change-requests/cr-template.md`

---

## Описание (What)

Пользователь сообщил: виджеты не должны «лежать на нодах» — либо виджеты не
должны быть нодами, либо нода под виджетом должна быть **полностью
прозрачной**. Сейчас виджет-нода рисуется как обычная карточка: непрозрачная
заливка `theme.card_fill`, мягкая тень, рамка, заголовок-полоса; контент
виджета (live WebView2 или снапшот) накладывается только на внутреннюю
область контента. Вокруг контента и в снапшот-режиме видна непрозрачная
подложка карточки — визуально виджет «сидит на ноде». Выявил пользователь.

## Влияние (Impact)

| Объект | Что меняется | Где в документации |
|---|---|---|
| `widget` (нода) | Заливка и тень карточки — полностью прозрачные | `docs/WIDGETS.md` §7 (LOD), §8 (ограничения) |
| `node` (карточка) | Новый режим рендера карточки по типу ноды | `docs/interface-objects/node.md` §3, §5 |
| Хром виджет-ноды | Заголовок (28 px) и рамка (8 px) остаются drag-зонами, но не видны как «карточка» | `WIDGETS.md` §8.5 |
| Placeholder | Битый пакет остаётся серой карточкой (не прозрачной) | `WIDGETS.md` §7, §10 |
| Миникарта/поиск | Отображение виджет-нод без изменений | `minimap.md`, `search.md` |

## Анализ (Root Cause)

- **Карточка виджет-ноды рисуется общим путём:** `card_instance`
  (`crates/canvas-render/src/cards.rs:149-171`) — для не-group нод
  `fill = card_color(node)` (`cards.rs:61`) → непрозрачный
  `theme.card_fill`; тень — в шейдере (`cards.wgsl:87-91`), рамка
  выделения — `cards.wgsl:96-97`.
- **Контент виджета покрывает не всю карточку:** область контента —
  `WidgetGeom::content_rect` (`crates/canvas-widgets/src/layout.rs:90-98`)
  с инсетами `HEADER_H = 28` сверху и `EDGE_INSET = 8` по бокам/снизу
  (`layout.rs:10-12`). Live-режим — дочерний `WS_CHILD` HWND ровно над
  областью контента (`crates/canvas-widgets/src/host/mod.rs:8-9, 431-451`;
  `webview_rect`, `layout.rs:102`); снапшот — квад в той же области
  (`widget_pass.rs:10-11, 222-320`).
- **Итог:** полоса заголовка и 8-px рамка вокруг live-виджета, а также вся
  подложка под полупрозрачными/не закрывшими область снапшотами — это
  видимая непрозрачная «нода» под виджетом.
- **Механизм частичной готовности:** шейдер уже поддерживает «без тени»
  (`params.w`, `cards.wgsl:21, 91`) и альфа-заливку (`cards.wgsl:80-85`) —
  прозрачная карточка реализуется данными инстанса без изменений шейдера.
- Placeholder (битый пакет/нет рантайма) намеренно серый —
  `Target::Placeholder` (`crates/canvas-widgets/src/lod.rs:59-63`),
  `WIDGETS.md` §10 — его прозрачность **недопустима** (пользователь должен
  видеть, что пакет сломан).

## Требуемые изменения (Changes)

1. `cards.rs` → `card_instance` (`cards.rs:149-171`): для
   `NodeKind::Widget` — `fill = [0.0, 0.0, 0.0, 0.0]` (полностью
   прозрачная заливка) и `params.w = 1` (без тени); рамка выделения
   (`params.y`) сохраняется — согласована с CR-006 (рамка, не заливка).
2. Хром (заголовок 28 px + рамка 8 px) остаётся функциональной drag/resize/
   выделение-зоной (`WIDGETS.md` §8.5), но не рисуется как непрозрачная
   полоса; вариант v1: лёгкая подсветка хрома только при hover/выделении
   (открытый вопрос ниже).
3. Placeholder — без изменений: серая карточка (`RenderMode::Broken`,
   `lod.rs:78-85`), проверка не даёт случайно применить прозрачность к
   битому виджету.
4. Снапшот-квад и live-HWND — без изменений (области и размеры те же).
5. Тесты: юнит на `card_instance` для `Widget` (прозрачный fill, без тени);
   smoke-тест рендера — прозрачность не влияет на quadrature снапшотов.

## Открытые вопросы дизайна

- Виден ли заголовок виджета (имя пакета) в v1? Предложение: скрыть до
  hover; имя остаётся в поиске и меню.
- Выделение: только рамка по контуру всей ноды (текущий `params.y`) —
  достаточно; заливки нет (стык с CR-006).
- FR-009: пользовательская настройка «прозрачность карточки» для прочих
  типов нод — отдельное решение, не входит в этот CR.

## Проверка (Verification)

- Живой виджет (часы/стикер/календарь): вокруг контента просвечивает сетка
  канваса; нет светлой подложки, тени и полосы заголовка.
- Snapshot-режим (зум < 0.23 или за live-лимитом): фон вокруг
  снапшот-квадов прозрачен; снапшот не «плавает» на карточке.
- Drag виджета за верхнюю зону (0–28 px) и рамку (8 px) работает; resize
  за угол работает; выделение показывает рамку.
- Битый пакет: серый placeholder непрозрачен (регрессия не пройдена).
- Миникарта и поиск находят виджет-ноды как раньше; rorder/z-order не
  изменился (`zorder.rs` smoke-тесты).
