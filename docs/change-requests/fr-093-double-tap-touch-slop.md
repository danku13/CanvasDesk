# FR-093: Двойной тап не создаёт заметку на мобильных — тач-допуск сдвига в детекторе двойного клика

- **Статус:** выполнено
- **Тип:** FR (дефект мобильного ввода → фикс допуска детектора)
- **Приоритет:** важно
- **Владелец:** агент (сессия 2026-10-03)
- **Источник:** запрос владельца 2026-10-03: «проверил на телефоне сейчас не работает создание новой ноды» (след за FR-092)
- **Связанные задачи:** FR-092 (мобильный тач-ввод — фундамент), T7 (двойной клик — детектор), FR-072 (title_then_body — цепочка создания)
- **Создан:** 2026-10-03

## Описание

После FR-092 (тап/драг/пан/пинч на мобильных) владелец проверил телефон:
создание новой ноды не работает. Создание «пустой заметки» на пустом месте —
двойной клик (T7), на таче — двойной тап: два `Action::Press` подряд через
мышиный пайплайн FR-092.

Диагностика (headless-Chromium, мобильная эмуляция 390×700 DPR 3, синтетический
touch, live Pages-бандл main@0e4028d, оракулы `?log=debug` + тур-сигнал
`canvas:note-created`): тап-пайплайн полностью рабочий (`press: вход в канвас`,
`hit=None` в обеих пробах), но детектор `DoubleClick::register` засчитывает
пару только при сдвиге ≤ **5.0 лог. px** (`DOUBLE_CLICK_DIST`, T7 — норма для
мыши). Живой двойной тап пальцем гуляет на 10–20 лог. px: проба с джиттером
ровно 5.0 лог. px прошла на границе, 10/20/40 лог. px — не засчитаны, нода не
создавалась. Мышиного допуска на тач не хватило — дефект геометрии детектора,
не пайплайна.

## Влияние

| Объект | Что сломано | Где |
|---|---|---|
| canvas-app (web/тач) | двойной тап по пустому месту не создаёт заметку (основной способ создания на телефоне — клавиатуры нет) | `crates/canvas-app/src/lib.rs` (`DoubleClick`), `crates/canvas-app/src/app/input.rs` |
| смежные жесты | двойной тап по text-ноде (редактирование) и по связи (лейбл) — тот же допуск | там же, точка `register` одна |

## Решения

- **`DoubleClick::register(at, pos, slop)`** — допуск сдвига параметром.
  Мышь — прежний `DOUBLE_CLICK_DIST = 5.0`; новый
  `DOUBLE_CLICK_DIST_TOUCH = 32.0` (лог. px; ~треть ширины пальца, меньше
  зазора между соседними нодами — случайная пара тапов по двум близким нодам
  не сойдёт за двойной тап). Интервал 500 мс общий (живой двойной тап
  150–400 мс между нажатиями).
- **Происхождение нажатия** — `App.press_from_touch`: ставится в `on_touch`
  (`Action::Press`, wasm32) до `on_left_button(Pressed)`, гасится
  `std::mem::take` в начале `on_left_button` (один учёт на нажатие, хвосты не
  текут в Released и мышиные события). Натив не затронут: флаг всегда false →
  мышиный допуск бит-в-бит прежний.
- **Тесты**: `double_click_detection` переведён на явный slop; новый
  `double_click_touch_slop` — джиттер 12/16 лог. px засчитан (мышиный 5.0
  отверг бы), граница 32, за допуском 40, интервал общий, мышиный допуск
  не изменился.
