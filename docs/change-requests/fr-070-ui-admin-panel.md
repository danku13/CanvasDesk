## Описание

Владельцу проекта нужна админпанель, в которой в первом подходе доступно:
(1) отображение каждого элемента UI во всех состояниях, (2) отображение
контейнеров с разным наполнением (пустое / среднее / полное), (3) вывод
всех доступных для настройки значений UI, влияющих на UI и дизайн
(design-токены, слоты палитры), с live-правкой значений в сессии и сбросом.

Решения владельца (опрос 2026-09-25): in-app Rust (эволюция витрины
FR-055); навигация — левый сайдбар (секции → демо-зона справа, паттерн
Storybook); расширенная матрица состояний (5 из ST1 + Focused + Error там,
где применимо); расширенный набор контейнеров наполнения (список, карточка,
текстовое поле, чипы, dropdown, таблица строк kit-Row, тосты, палитра
шаблонов, wheel-меню); состояния сущностей канваса ST4 включить (ноды,
рёбра, порты); токены — live-правка в сессии с кнопкой сброса; темы — как
сейчас (кнопка цикла в шапке); подписи — по-русски (EN-переводы ключей
заполняются для паритета i18n, интерфейс витрины остаётся двуязычным по
контракту RU/EN FR-040); git — feature-ветка + PR; документация — полный
цикл (docs + user-docs + шаг онбординга).

## Анализ

Отсутствует: единой поверхности, сводящей (а) полную матрицу состояний
контролов и сущностей канваса, (b) режимы наполнения контейнеров, (c)
каталог настраиваемых значений UI. Существующая витрина `kit_gallery`
(FR-055, `crates/canvas-app/src/kit_ui.rs`) покрывает компоненты × 4
состояния (Normal/Hover/Pressed/Disabled + частично Focused/Selected), но
не показывает: Selected системно, Error, уровни наполнения, сущности
канваса (ST4), каталог токенов и не позволяет переопределять слоты палитры
на живую.

Точки опоры в коде:
- Паттерн блок-модали + хиты + Esc/✕ — `kit_ui.rs` + `app.rs`
  (`kit_gallery_overlay`, `click_kit_gallery`, реестр
  `app/ui_registry.rs::KIT_GALLERY`).
- Машина состояний и draw-слой — `canvas-ui/src/widget.rs`,
  `canvas-ui/src/paint.rs`, стили `canvas-ui/src/kit.rs`
  (`button_style`/`chip_style`/`text_field`).
- Слоты палитры — `canvas_ui::kit::KitPalette` (Copy) из
  `canvas-render::theme::ThemeColors`.
- Токены-примитивы — `canvas-core/src/tokens.rs` (константы, паритет с
  `design/tokens/*.json`).
- Сущности ST4 — `canvas-render/src/cards.rs` (рамки/заливки состояний
  карточек), `edgegeom.rs`/`cards.rs` (цвета рёбер), порты
  (`cards.rs`/`edit.rs`).
