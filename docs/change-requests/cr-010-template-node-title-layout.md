# CR-010: Вёрстка шапки шаблонной ноды — заголовок налезает на квад-иконку

## Описание (What)

У шаблонной ноды (text-нода из шаблона, снапшот `canvasdesk.template`) длинное
имя заголовка рисуется **под квад-иконкой шаблона** в правом верхнем углу
карточки: клип текста заголовка резервирует место только под иконку-заглушку
файловой ноды, а квад-иконка шаблона занимает правый край шапки. Плюс два
смежных дефекта вёрстки: асимметрия горизонтальных отступов шапки (6 px справа
у иконки против 12 px слева у заголовка) и недооценка стартовой высоты новой
шаблонной ноды при переносах строк. Кто выявил: агент (аудит кода рендера).

## Влияние (Impact)

| Объект | Что сломано | Где в документации |
|---|---|---|
| `node` (шаблонная) | Заголовок перекрыт иконкой при длинном имени; шапка визуально «уезжает» вправо | `docs/interface-objects/node.md` §3 (визуальная структура) |
| `node` (шаблонная) | Новая нода из шаблона — начальная высота без учёта переносов (длинные значения параметров) | `docs/interface-objects/node.md` §3 |

## Анализ (Root Cause)

- `crates/canvas-render/src/text.rs:1224,1340,1705` — ширина клипа заголовка
  резервирует место под иконку только когда `has_icon = extension_letter(node)
  .is_some()`; для шаблонных нод (`kind = Text`, без `file`) это всегда
  `false` → правый край клипа = `x + width − TITLE_PADDING(12)`.
- `crates/canvas-render/src/cards.rs:250-257` — квад-иконка шаблона занимает
  `x + width − 22 … x + width − TEMPLATE_ICON_MARGIN(6)` → полоса пересечения
  с текстом ≈ 10 px. Файловые ноды не затронуты (у них резерв корректный).
- Асимметрия: `TITLE_PADDING = 12` (`text.rs:71`) против
  `TEMPLATE_ICON_MARGIN = 6` (`cards.rs`) — правый край иконки на 6 px ближе
  к краю, чем левый край заголовка.
- `crates/canvas-app/src/main.rs:201-216` — `fit_template_node_height` считает
  высоту как `text.lines().count() * BODY_LINE_HEIGHT`, тогда как тело
  шейпится с `Wrap::WordOrGlyph`: длинная строка параметра даёт два визуальных
  ряда, но одну `\n`-строку → стартовая высота недооценивается (компенсируется
  только при последующем редактировании через `fit_note_size`).

## Требуемые изменения (Changes)

1. **`crates/canvas-render/src/text.rs`** — резерв ширины заголовка под
   квад-иконку шаблона: `has_icon`-эквивалент для шаблонных нод (снапшот
   `canvasdesk.template` присутствует) — правый край клипа заголовка =
   `x + width − 22 − зазор` (тот же резерв, что для файловых иконок);
   единый helper, чтобы файловая и шаблонная иконки не расходились.
2. **`crates/canvas-render/src/cards.rs` / `text.rs`** — симметричные отступы
   шапки: `TEMPLATE_ICON_MARGIN` = `TITLE_PADDING` (12 px) либо общая
   константа `HEADER_SIDE_PAD`; обновить инвариант-тест геометрии шапки.
3. **`crates/canvas-app/src/main.rs`** — `fit_template_node_height`: оценка
   числа визуальных рядов с учётом переноса (ширина тела / средняя ширина
   символа, как в раскладчике текста, или вызов той же wrap-логики), либо
   стартовая высота по `fit_note_size` сразу после инстанциации.
4. **Тесты** — юнит-инварианты в `text.rs` (по образцу существующих):
   клип заголовка шаблонной ноды не пересекается с прямоугольником иконки;
   отступы шапки симметричны; `fit_template_node_height` на строке с переносом
   даёт высоту ≥ двух рядов.

## Проверка (Verification)

- Шаблон с длинным именем («Database Primary with Long Name») → заголовок
  обрезается клипом ДО квад-иконки, налезания нет (скриншотная проверка +
  юнит на геометрию клипа).
- Шапка: левый отступ заголовка = правый отступ иконки (12 px).
- Новая шаблонная нода с длинным значением параметра (перенос на 2 ряда) —
  карточка сразу нужной высоты, текст не упирается в футер результата.
- Файловые ноды — без регрессий (их резерв под иконку не изменился).
- Гейты: `cargo fmt --check`, `clippy --workspace -- -D warnings`,
  `cargo test --workspace` — зелёные.

## История изменений (Changelog)

- `2026-09-16` — агент: реализовано, статус `выполнено`. Клип заголовка:
  `title_clip_width` (text.rs) — резерв под иконку и для шаблонных нод
  (`has_icon = extension_letter(...) || node.template().is_some()`, фаза
  шейпинга); тест-инвариант `template_title_clip_clears_quad_icon`. Симметрия:

  (оценка рядов с переносами, CJK ×2) в `fit_template_node_height`; тесты
  `wrapped_body_rows_counts_visual_rows`, `fit_template_height_covers_wrapped_lines`.
  Попутно: пресуществующий stale-ожидание `gfm_body_smoke` (42 → 48:
  `HEADER_HEIGHT` 28→34 по FR-023, ожидание не обновили) — исправлено.
- `2026-09-16` — агент: документ создан по итогам аудита вёрстки (субагент,
  обход `cards.rs`/`text.rs`/`main.rs`); статус `выявлено`. Анализ:
  `text.rs:1224/1340/1705`, `cards.rs:250-257`, `main.rs:201-216`.
  Расхождений с FR-023 (кегли, HEADER_HEIGHT, футер результата) не найдено —
