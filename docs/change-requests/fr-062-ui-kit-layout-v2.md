# FR-062: Усиление кита — layout v2 (measured-дети, flex-факторы, Wrap, Grid-lite) + фокус-связка + геометрические снапшоты

- **Статус:** выявлено (постановка по ADR-0013 п.3; реализация по приказу владельца)
- **Тип:** FR
- **Приоритет:** важно
- **Владелец:** не назначен (любой агент; контракты F-13…F-18 замораживаются при старте реализации)
- **Источник:** запрос владельца (сессия 2026-09-23) «почему не taffy, какие выигрыши против актуального плана, как усилить свой UI kit»; **ADR-0013** (taffy 0.14.0 замерен: flexbox-only ≈ 108.5 КБ wasm = весь G7-остаток волны — главные выигрыши закрываются расширением собственных примитивов)
- **Связанные задачи:** PRD-0009 (V-5, F-7, §7.2/§7.4); FR-053 (TextMeasurer F-6); FR-056 (scissor — клип действует на всё); FR-057 (Painter/WidgetState/FocusRing); FR-058 (компоненты v2 — сигнатуры не меняются); FR-060 (волна 2 миграции — строгий порядок слива); FR-061 (этап E kit-Row — потенциальный потребитель F-13/F-14/F-16); ADR-0008 (0 новых зависимостей сохраняется); ADR-0011 (wasm-гейт)
- **Создан:** 2026-09-23
- **Обновлён:** 2026-09-23

## Описание
Программа усиления кита, закрывающая ~80% списка выигрышей taffy (ADR-0013 §сравнение) ценой ~сотни строк в `layout.rs`/`kit.rs` и **нуля новых зависимостей / ~0 КБ wasm сверх замеренного лимита (≤15 КБ суммарно)**. Все пункты — **только добавление** к v1 (конвенция волны 2: существующие сигнатуры/константы/поведение не меняются; ноль визуального скачка U5-паттерна). Этапы: **A** — F-13+F-14 (ядро вёрстки), **B** — F-15+F-16 (деградации и сетки), **C** — F-17+F-18 (фокус и регресс-контур); этапы мержатся независимо, порядок — по возрастанию.

## Non-goals (фиксация)
- **taffy не подключается** — решение ADR-0013; эскалация только по триггерам T1–T4 и протоколу ADR-0013 §Решение.5.
- **Retained-дерево узлов не вводится** — immediate-пересборка кадра сохраняется (non-goal PRD-0009).
- Полная CSS-семантика (проценты, calc(), aspect-ratio, неравные треки/спаны, min/max-content во всей общности) — не скоуп; потребность = триггер T2/T4, не расширение этого FR.
- Существующие сигнатуры `Row::lay_out`/`Column::lay_out`/`Child::{fixed,spacer}`/`RowPolicy::{Fit,SqueezeTail}` не меняются; `SqueezeTail` остаётся именованной деградацией (не deprecated — семантика «хвост до нуля» специфична и нужна).

## Требуемые изменения

### F-13: measured-дети — размер от контента внутри раскладки
| Что | Где | Как |
|---|---|---|
| Тип measured-ребёнка | `canvas-ui/src/layout.rs` | `MeasuredChild { w: Option<f32>, h: Option<f32>, text: Option<MeasureKey> }`; `MeasureKey { text: &str/`трейт-слот`, family, size, max_w }` — точная форма замораживается при старте (трейт-слот, чтобы не тянуть cosmic-text в сигнатуры: G7) |
| Раскладка с измерением | `canvas-ui/src/layout.rs` | `Row::lay_out_measured(slot, items: &[MeasuredChild], m: &mut TextMeasurer, fs: &mut FontSystem) -> Vec<UiRect>` (и `Column::lay_out_measured` симметрично); ширина текстового ребёнка = `width_of`, кламп в остаток слота; отсутствующий текст → `None`-поле = фиксированный `w/h` |
| Семантика | тесты | переполнение НЕ маскируется (наследование `Fit`-политики — линт G4 видит выход за слот); ellipsis-политика — решением потребителя, как сегодня (F-6) |

Эффект: убирает ручную проводку `width_of → Child::fixed` (главный выигрыш taffy «auto-размер»); класс CR-015 защищён по построению — ширины не могут быть эвристикой, measurer в сигнатуре.

### F-14: flex-факторы — per-child grow + `MainAlign::End`
| Что | Где | Как |
|---|---|---|
| Поле grow | `canvas-ui/src/layout.rs` | `Child.grow: f32` (по умолчанию 0.0 через конструкторы; **предварительное условие**: grep `Child {` литералов вне крейта = 0, все места — через `Child::fixed/spacer` — иначе добавление поля запрещено и вводится `Child::growing(w, h, grow)`); распределение остатка слота пропорционально `grow` после раскладки фиксированных детей |
| Выравнивание | `canvas-ui/src/layout.rs` | `MainAlign::End` (дети прижаты к концу главной оси, зазор = `gap`) |
| Тесты | TDD | орбита: 0 grow → текущее поведение байт-в-байт; пропорциональность (2:1); взаимодействие с `SpaceBetween` (grow поглощает свободное место — SpaceBetween деградирует к gap, документировать); `SqueezeTail` × grow — SqueezeTail приоритетен (деградация всегда побеждает распределение) |

### F-15: `RowPolicy::Wrap { max_rows: usize }` — многострочные ряды
| Что | Где | Как |
|---|---|---|
| Вариант политики | `canvas-ui/src/layout.rs` | `RowPolicy::Wrap { max_rows }`; жадная упаковка детей по строкам слота (первая не влезшая — перенос); высота строки = max h детей строки; возврат — plained `Vec<UiRect>` (плоский, row-major; строка восстанавливаема по y) |
| Переполнение | тесты | детей больше, чем влезает в `max_rows` → последние выходят за слот (не маскируются — линт G4), либо клампятся `SqueezeTail`-семантикой в последней строке (решение вызова — вторая политика не добавляется; задокументировать в модуле) |
| Ограничение | контракт | exhaustive-матчи по `RowPolicy` вне крейта запрещены (конвенция; grep-аудит при реализации) |

Потребитель-пример: ряды чипов галереи/шаблонов (исторический break-кламп CR-015).

### F-16: `grid_cells` — 2D-сетка равных треков
| Что | Где | Как |
|---|---|---|
| Функция | `canvas-ui/src/layout.rs` | `grid_cells(slot, cols: &[f32], row_h: f32, gap: UiVec2) -> Vec<UiRect>` — row-major ячейки по явным ширинам колонок (ширины — из F-13/RowGuides FR-061 D-3); кламп переполнения — как F-15 (линт) |
| Не делаем | — | спаны, авто-треки, fr-единицы (таффи-территория, ADR-0013 T2) |

Потребитель-пример: calc_panel (обе колонки уже на list_rows — сетка опциональна), tabular stage FR-061 этап E.

### F-17: фокус-связка FocusRing × WidgetState (кит)
| Что | Где | Как |

| Витрина | `canvas-app` (kit_gallery) | Tab-навигация по секции кнопок/свитчей витрины — живой образец (i18n RU/EN) |

### F-18: геометрические golden-снапшоты кит-компонентов
| Что | Где | Как |
|---|---|---|

## Риски
- R-a: добавление поля `Child.grow` ломает литералы (если есть вне крейта) — предварительный grep обязателен; fallback — `Child::growing`.
- R-b: «самописный flexbox растёт» — каждый пункт снабжён тестами и непревышением бюджета; выход за рамки F-13…F-18 — новый FR/триггеры ADR-0013, не «доработка на месте».
- R-c: `lay_out_measured` требует `FontSystem` аргументом (владение рендера — конвенция F-6); consumers создают measurer на кадр — цена уже оплачена практикой FR-053.
