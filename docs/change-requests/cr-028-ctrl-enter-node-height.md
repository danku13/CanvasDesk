# CR-028: Ctrl+Enter не расширяет высоту ноды — строки уходят за клип

- **Тип:** CR

- **Связанные задачи:** FR-072 (заголовок в подписи), CR-018 (зона правки тела, `session_area_offset`), FR-100 (шорткаты редактора), `docs/interface-objects/node.md` §редактор

## Описание (What)

В редакторе ноды Ctrl+Enter (вставка новой строки/подтверждение роста высоты карточки) больше не увеличивает высоту ноды: набранные после него строки рендерятся за пределами карточки и обрезаются clipping'ом тела. Раньше высота ноды следовала за числом строк («перестал» — регрессия между сессиями).

## Влияние (Impact)

| Объект | Что меняется |
|---|---|
| Редактор ноды | Ctrl+Enter должен расширять `Node.height` (или зону клипа тела) под новую строку |
| Рендер тела | Строки за пределами высоты карточки не должны пропадать под клипом при активном редактировании |

## Анализ (Root Cause) — кандидаты, требует локализации

- Обработка Ctrl+Enter в редакторе: `crates/canvas-app/src/app.rs` / `app/input.rs` (маршрутизация key, ветки `ctrl`+`Enter`; рост высоты — автораскладка тела от кэша строк `text.rs`).
- Клип тела: `canvas-render` (зона тела/`session_area_offset` — CR-018 v1.1: origin смещается на стационарные зоны, высота ужимается; взаимодействие с ростом высоты — проверить).
- Регрессийный окно: изменения после 2026-10-04 (CR-018/FR-072 волнa) — git bisect по жалобе.

## Следующие шаги

1. Воспроизвести: редактор ноды, многострочный текст, Ctrl+Enter — замерить `node.height` до/после.
2. `git log --oneline` по `canvas-app/src/app/input.rs`, `canvas-render/src/edit.rs` с 2026-10-04; bisect при необходимости.
3. Решение владельца о волне реализации (кандидат: W2/W3).
