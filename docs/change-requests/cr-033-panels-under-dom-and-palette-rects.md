# CR-033: Ctrl+P/Ctrl+I под DOM-хромом; конвенция rect'ов дока палитры (UR-004)

- **Статус:** реализовано (S1–S4: код+тесты; ожидает приёмки владельца)
- **Тип:** change request (дефекты вёрстки/слоёв web-поверхностей)
- **Приоритет:** высокий (агент-панель нельзя было закрыть мышью; вставка
  шаблона кликом не работала — функциональные потери, не только визуал)
- **Источник:** UR-004 (сообщение владельца 2026-10-09)
- **Связанные:** FR-018/FR-024/FR-025, FR-040 v2, FR-052, FR-054 (F-11),
  FR-055, FR-087, FR-095, FR-097, PRD-0010 F-4, T13-B
- **Создан:** 2026-10-09

## Проблема

1. **Слои.** `#author-bar`/`#w6-toolbar` — DOM (z-index: 10) над GPU-канвасом
   (без z-index). Ctrl+P (левый док 340px во всю высоту) и Ctrl+I (агент-панель
   388px во всю высоту) перекрывались углами DOM-хрома; у агент-панели была
   накрыта кнопка ✕ — закрытие мышью невозможно.
2. **Конвенция rect'ов.** Потребители `PanelLayout` (xywh-контракт) применяли
   `rect_xywh` (конвертер xyxy→xywh из search_ui): квады строк/поля/кнопки «‹»
   вырождались (w/h→0) — подложек карточек не видно, иконки всплывали над
   строками на ~19px (`tile_y = y + (0−28)/2`), футер/поле сжаты; хит-тесты
   кликов/ховера по строкам/чипам/поиску/сворачиванию всегда false —
   WYSIWYG нарушен (клик по видимой строке ничего не делает).
3. **Замер чипов.** `panel_layout` мерил чипы категорий по raw-токенам
   реестра, а рендерил локализованные подписи (кириллица шире) — текст
   резался `TextBounds` без эллипсиса («Продуктовая ана»).
4. **Миникарта поверх агент-панели.** minimap-pass — после screen-оверлеев:
   полупрозрачная панель и белый viewport-индикатор налезали на cost-строку
   и поле ввода агент-панели.

## Решения (S1–S4)

- **S1 (слои):** platform-нейтрально `App::html_panel_overlap() -> (bool, bool)`
  (левый док / агент-панель открыты); web-мост по паттерну FR-095:
  `TourAwareApp::drain_and_emit` → `toolbar::set_panel_overlap` → body-классы
  `cd-panel-left`/`cd-panel-right`. CSS (index.html): `#author-bar` уезжает
  за правый край дока (`translateX(min(352px, 100vw−172px))`), `#w6-toolbar` —
  влево от панели (`translateX(−396px)`), `#tour-menu` — `right: 396px`
  (последние два — только ≥1200px: ниже тулбар в левом нижнем углу, FR-099);
  transition 150ms. feature `web-sys/DomTokenList`.
- **S2 (конвенция):** потребители `PanelLayout` берут rect'ы КАК ЕСТЬ
  (overlays.rs: panel/collapse/input/chips/rows/footer; input.rs:
  `click_template_panel` — panel_hit/collapse/input/chips/rows/глотание,
  wheel-скролл). Комментарий-предохранитель на месте конвертации + UR-004
  с механикой поломки. `rect_xywh` остаётся только у xyxy-поверхностей
  (search_ui).
- **S3 (замер чипов + токены):** `panel_layout(..., chip_labels: &[String])` —
  параллельный список локализованных подписей (замер + ширина чипа);
  `category_rects` несут raw-токен (state-биндинг фильтра не менялся).
  Все 6 вызовов обновлены. Радиусы чипов/поля/«‹»/карточек строк —
  `RADIUS_CHIP` (кит-паритет, прежний литерал 6 был равен токену, 11 у чипов
  дока — расходился с полосой и китом); паддинг текста чипа — `CHIP_PAD_H`.
- **S4 (миникарта):** `Renderer::set_minimap_visible(bool)` (+ поле
  `minimap_visible`, гейт квада/draw, `minimap_rect_logical` → None);
  `handler.rs` выставляет `agent_panel_rect().is_none()` покадрово до рендера
  (idемпотентно; текстура не сбрасывается — при закрытии панели кадр
  возвращается без перерастеризации; hit-rect'ы миникарты исчезают вместе с ней).

## Приёмка

- Тест `panel_chips_measured_by_display_labels`: ширина чипа = замер
  display-подписи + 2·CHIP_PAD_H; `category_rects` несут raw.
- Вся существующая матрица (2751 тестов) зелёная — регрессий нет.
- Живой прогон (trunk release, 1600×900): автор-бар/тулбар уезжают из-под
  углов панелей; шапка «Шаблоны» и «‹» видны; чипы не обрезаны; иконки
  центрированы в карточках строк; hover/selection/клик-вставка работают;
  ✕ агент-панели кликабельна; миникарта скрыта при открытой панели и
  возвращается после закрытия.
