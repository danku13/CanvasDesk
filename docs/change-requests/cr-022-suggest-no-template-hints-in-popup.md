## Решения владельца (Q&A)

**Вопрос Q5 (сессия 2026-10-08): «Как ограничить предложение "заменить ноду шаблоном" при вводе в Numi-строках?»**

| Вариант | Суть |
|---|---|
| Гейт Numi-строк | Не показывать на Numi-вычисляемых строках, показывать на прозе |
| Только по кнопке | Из попапа убрать вовсе; шаблоны — только карточками по явному триггеру |
| Оставить снизу | Отдельная приглушённая секция под попапом |

**Ответ владельца:** выбран «Гейт Numi-строк» **с примечанием: «UR-06 — вообще не надо триггерить»**. Трактовка (зафиксирована как решение): ИИ-предложения шаблонов не триггерятся при редактировании ноды **вообще** — ни на Numi-строках, ни на прозе. Попап при редактировании содержит только L0-подсказки (переменные/входы/функции/единицы). C3-карточки «следующие ноды» (после instantiate шаблона) остаются без изменений — они не в попапе.

---

## Описание (What)

При вводе значений в Numi-строки (пример владельца: `price = 100 rub`) попап подсказок показывает ИИ-строки «✦ <имя шаблона> · заменит ноду шаблоном», что ломает пользовательский флоу ввода. Требуется: убрать ИИ-предложения шаблонов из попапа редактирования ноды полностью.

## Влияние (Impact)

| Объект | Что меняется | Где в документации |
|---|---|---|
| Попап подсказок FR-021 | Секция ИИ-строк (`HintKind::Ai`) удаляется; попап — только L0 | FR-021 |
| Триггер C1 (SuggestWorker) | Перестаёт взводиться из `update_hints`; воркер/гейты/лог сохраняются для будущих поверхностей | FR-079 (план §4.2) |
| C3-карточки | Без изменений | FR-079 (C3) |
| Настройки `[suggest]` | Тумблер остаётся (управляет C3 и будущими поверхностями); формулировка уточняется | FR-026/FR-039 |

## Анализ (Root Cause)

Полный разбор — UR-001-06. C1-триггер реализован по плану: любой ввод вне фенсов (`overlays.rs:2099-2115`) → дебаунс 300 мс → домен-гейт → show-гейт (`canvas-suggest/src/gate.rs:16-19`) → топ-3 шаблона вмердживаются в попап (`hints_ui.rs:243-258` `merge_ai_items`; `app.rs:5940-5946` `suggest_remerge`). Гейта «строка каретки — Numi-значение» нет; Numi-гейт закрывает только L0-строки. План FR-079 сознательно описал C1 как «любой ввод, включая прозу» и сам назвал навязчивость «продуктовым риском №1» (§9). Движок по умолчанию OFF (`settings.rs:250`) — у владельца включён.

**Происхождение:** согласованное решение плана FR-079 (S3 реализована до выкатки S5), пересматриваемое владельцем по опыту использования.

2. `overlays.rs:2168-2169` + `app.rs:5940-5946` — `suggest_remerge` не добавляет ИИ-строки в попап.

4. `crates/canvas-core/src/settings.rs:220-256` + `settings_ui.rs` — уточнить формулировку тумблера («ИИ-подсказки шаблонов» → «ИИ-карточки шаблонов (после создания ноды)» или эквивалент), i18n RU/EN.
5. План FR-079 §4.2 — пометить C1 «снят решением владельца (CR-022, 2026-10-08)»; S4/S5 не затронуты.
