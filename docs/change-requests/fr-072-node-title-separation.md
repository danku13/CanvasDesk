# FR-072: Разделение заголовка ноды и текста тела

- **Статус:** выполнено
- **Тип:** FR
- **Приоритет:** важно
- **Владелец:** агент (Super Z, сессия 2026-09-25), запрос владельца
- **Источник:** запрос владельца 2026-09-25: «нужно разделить заголовок ноды и текст внутри ноды, чтобы не получалось так, что первая строка ноды может стат заголовком ноды — это кажется плохим UX. Сделай свои предложения по улучшению структуры ноды»
- **Связанные задачи:** FR-023 (заголовок шаблонной ноды — частный случай «явного имени»), CR-010 (вёрстка шапки), FR-009 (палитра/«Переименовать»), FR-006 (undo), ADR-0011 (wasm-гейт), глоссарий `CONTEXT.md` («Заголовок ноды»)
- **Создан:** 2026-09-25
- **Обновлён:** 2026-09-25

## Описание

Заголовок карточки-заметки выводится из первой строки текста ноды
(`title_for`: `text.lines().next()`). Следствия:

1. Первая строка дублируется на карточке — в шапке и в теле одновременно
   (см. `docs/assets/cr-009-editor.png`: «Смета на инфраструктуру» ×2).
2. «Переименовать» (FR-009) открывает правку всего тела — переименование
   неотделимо от правки текста.
3. Случайная правка первой строки тела меняет заголовок — заголовок не
   является полем ноды, у него нет собственной семантики.
4. У шаблонных нод (FR-023) «явное имя» уже есть (снимок манифеста), у
   обычных заметок — нет.

Требуется: явный заголовок ноды как отдельное поле `.canvas`, отдельная
UX-схема правки заголовка и тела, миграция legacy-нод без потери данных.

## Анализ

- Формат `.canvas` (JSON Canvas 1.0) не расширяется чужими ключами верхнего
  уровня: `canvasdesk.title` живёт в типизированном расширении `canvasdesk`
  рядом с `desc`/`data`/`template` — сериализуется только при наличии,
  старые файлы байт-в-байт.
- Три состояния заголовка: `None` — поле не задано (legacy: заголовок —
  первая строка текста, поведение всех существующих файлов не меняется);
  `Some("")` — задан, но пуст (плейсхолдер «Заголовок» приглушённым тоном,
  утечки первой строки нет); `Some(s)` — заголовок s.
- Однострочность: `Shift/Ctrl+Enter` в теле создаёт строку, в заголовке —
  всегда коммит; markdown-маркеры в заголовке не интерпретируются
  (`text()`/`changed()` без parse/emit).
- Тело не гасится при правке заголовка: `frame.editing` остаётся `None`
  (кэш тела живёт), буфер заголовка рисуется отдельной веткой в шапке.

## Решение

1. **Модель** (`canvas-core/src/model.rs`): `CanvasdeskExt.title`,
   `Node::title()/set_title()` (паттерн `desc`), `Node::remove_first_line()`
   для миграции, `sigma_row_name` с приоритетом явного заголовка.
2. **Рендер** (`canvas-render/src/cards.rs`, `text.rs`, `edit.rs`,
   `renderer.rs`): приоритет в `title_for`; плейсхолдер; зона правки
   `title_edit_area` (строка TITLE_LINE_HEIGHT по центру шапки, x — как у
   клипа заголовка с учётом иконки); каретка/выделение на z-позиции ноды.
3. **Приложение** (`canvas-app`): двойной клик по шапке → правка заголовка,
   по телу → правка текста (`begin_edit_node`); «Переименовать» — заголовок
   (у групп — label); создание заметки = заголовок → Enter → тело
   (`title_then_body`); коммит заголовка legacy-ноды переносит первую строку
   в title, если она проза (не Numi-формула по `expr::line_kind`, не
   шаблонная нода) — один undo-шаг (FR-006).
4. **MCP** (`canvas-scene/src/mcp.rs`, `canvas-mcp/src/lib.rs`): `title`
   в `node_create_note`/`node_edit`/сводках, поиск по заголовку; skills/
   обновлены в том же коммите (`canvasdesk-model-build` v2, tools.md,
   CHANGELOG v4, README v4).

## Ограничения

- Legacy-фолбэк не удаляется: тысячи существующих заметок идентифицируются
  первой строкой; миграция — осознанное действие пользователя (правка
  заголовка) или агента (`node_edit` title).
- Файловые ноды: заголовок — имя файла; правка заголовка им не назначается
  (переименование файла — отдельная задача, вне скоупа).
- `Some("")` сериализуется осознанно: `set_title(None)` удаляет поле
  (возврат к legacy), `Some("")` — состояние «заголовка нет, утечки нет».

## Приёмка

- Round-trip: `title_round_trip_and_reset` (Some(\"\") сохраняется, None
  удаляет поле целиком), `title_reads_external_file_and_preserves_siblings`
  (чужой файл, соседние типизированные поля живы).
- Приоритет: `explicit_title_precedence` (текст/шаблон/пустота/legacy),
  `sigma_row_name_prefers_explicit_title`.
- Редактор: `session_area_title_target`, `title_session_plain_text`
  (маркеры не канонизируются), `title_adapt_command` (Enter — коммит,
  Shift+Enter — коммит, маркеры заглушены, тело не задето).
- MCP: `mcp_node_create_note_with_title`, `mcp_node_edit_title_field`
  (строка/null/неверный тип), `mcp_nodes_search_by_title`.
- Гейты: cargo test (core/render/scene/mcp/app), clippy -D warnings, fmt,
  wasm-гейт `scripts/wasm_gate.sh --check`.
