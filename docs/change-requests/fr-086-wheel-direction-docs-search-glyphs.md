# FR-086: Направление зума/скролла поверхностей, поиск по встроенной документации в Ctrl+F, покрытие глифов UI

- **Статус:** реализовано
- **Тип:** FR (батч исправлений + новая функция поиска)
- **Приоритет:** важно (ежедневный UX поверх окон проверки/доков/поиска)
- **Владелец:** агент-сессия (Super Z), по запросу владельца
- **Источник:** запрос владельца 2026-10-02: «проверь как сейчас работает
  масштабирование мышкой на поверхности Окно проверки цепочки, оно
  инвертировано, так же проверь прокрутку в документации… в общий поиск
  ctrl+f добавь поиск по встроенной документации и каким-то образом его
  пометь… проверь вывод всех глифов и иконок, сейчас точно есть проблема
  с иконками в меню "драг" и "подсказки", так же в контекстном меню по
  пкм "узкие места"»
- **Связанные задачи:** FR-085 (зум окна проверки — знак/шаг фактора),
  CR-017 (шаг ±5 %), FR-048 (окно проверки), FR-027/031 (доки),
  FR-014/T14 (панель поиска), FR-072/073/079 (табы настроек),
  FR-ICONS (атлас), FR-016/CP5 (пункт меню «Узкие места»)
- **Создан:** 2026-10-02
- **Обновлён:** 2026-10-02

## Описание

Четыре дефекта/пробела, найденных проверкой поверхностей:

1. **Зум окна проверки инвертирован и шаг бился в кламп.** После CR-017
   фактор считался `1.05^(−dy)`, где `dy = y·PAN_PX_PER_LINE` (40 на
   щелчок): колесо вверх зумило OUT (инверсия знака) с фактором
   `1.05^±40 ≈ ×7.4` за щелчок — удар в `SCALE_MIN`/`ZOOM_MAX` одним
   щелчком.
2. **Прокрутка документации инвертирована.** В `on_mouse_wheel` ветка
   доков не инвертировала дельту (`y·PAN` вместо `−y·PAN`) — колесо «от
   себя» листало содержимое вверх, против конвенции всех остальных
   списков (автосвязь, карта проливаний, витрина, админпанель).
3. **Ctrl+F ищет только по нодам** — встроенная документация (FR-027,
   9 страниц `user-docs/`) недоступна из глобального поиска; ответы на
   «как это работает» приходится искать через меню «?» вручную.
4. **Тофу-глифы UI.** Аудит шрифтов (fontTools, 2026-10-02): встроенные
   Noto Sans Display/Mono НЕ содержат `✓ ✥ ✦ ⇄ ⚙ ⚠ ✎ ✕ ✗ ❄ ↻ ⋯ ⌕`.
   В wasm (системного фолбэка нет) рисовался `.notdef`: галочка
   «✓ Узкие места (Ctrl+B)» в ПКМ-меню канваса, глифы табов настроек
   «Драг» (`✥`) и «Подсказки» (`✦`); кроме того эти два таба не были
   смаплены на SVG-атлас FR-ICONS (`_ => ""` в settings_overlay) — в
   Glyph-режиме (дефолт) табы всегда рисовали сырые глифы.

## Решение

### Часть 1 — знак и шаг зума (окно проверки)

Чистая функция `explain_ui::wheel_zoom_factor(WheelInput)` (модуль без
winit-типов): `Line(y)` → `ZOOM_STEP_PER_NOTCH^y` (1.05, колесо вверх =
зум IN, паритет с канвасом CR-017), `Pixel(y)` → `exp(y·0.00125)` (тачпад,
паритет с канвасом). Вертикальная дельта больше не умножается на
`PAN_PX_PER_LINE`; горизонтальный пан (наклон/Shift+колесо) — прежний.

### Часть 2 — знак прокрутки документации

`dy = −y·PAN_PX_PER_LINE` (LineDelta) и `−pos.y/scale` (PixelDelta) —
конвенция списков: колесо «от себя» (y<0) увеличивает offset.

### Часть 3 — поиск по документации в Ctrl+F

- `docs_ui::search_pages(query, language)` — чистая функция: подстрока
  без учёта регистра по локализованной метке страницы, id и markdown-телу
  (front matter срезан); одна страница — максимум одна строка, порядок =
  `DOCS_PAGES`; сниппет — первая строка тела с совпадением (обрезка 44
  символа по границе `char_indices`, хвост «…»).
- `SearchRow` (canvas-render::search_ui) получил `kind: SearchRowKind`
  (`Node` — дефолт, `Docs`) + конструкторы `node()`/`docs()`.
- `apply_search_hits`: строки-доки appended после нод,
  `search_doc_pages` — параллельный вектор индексов страниц.
- Пометка результатов: бейдж «?» слева строки (SVG-иконка `question`
  из атласа; в Glyph-наборе — текстовый «?»), текст сдвинут на зону
  бейджа, подзаголовок «Документация · {сниппет}» (ключ i18n
  `search.docs_section`, RU/EN).
- Enter на строке-доке: панель закрывается, страница открывается в
  просмотрщике доков (`open_docs_page`); строки-ноды работают как прежде,
  F3 циклит по всем строкам.

### Часть 4 — глифы и иконки

- **Новые SVG-иконки табов**: `tab_drag` (move: lucide/feather — stroke,
  material open_with — fill, bootstrap arrows-move) и `tab_suggest`
  (sparkles/zap/stars/auto_awesome) в 4 UI-наборах; генератор
  `scripts/rasterize_icons.py` дополнен именами и переведён на
  sparse-политику (отсутствующий файл = прозрачная ячейка с WARNING, как
  у `roles`; ошибка — только если имя не растеризовано ни в одном наборе).
  Регенерирован `icon_data.rs` (37→39 имён, 185→195 ячеек).
- **Смаплены табы**: `settings_overlay` — `TAB_DRAG => "tab_drag"`,
  `TAB_SUGGEST => "tab_suggest"`; `kit_ui` glyph-фолбэк дополнен.
- **Вшит сабсет «CanvasDesk Symbols»** (assets/fonts, OFL, имя без RFN —
  прецедент CanvasDeskMonoOblique): 21 символ из Noto Sans Symbols 2 /
  Symbols / Math (✓ ✥ ✦ ⚙ ⚠ ✎ ✕ ✗ ❄ ▦ ▴ ▸ ▾ ▲ ▼ ◎ ◐ ⌕ ↻ ⇄ ⋯), 10 КБ.
  Вшит в `FONT_DATA` — fallback-слой для ВСЕХ UI-строк на всех
  платформах, включая wasm.

## Тесты

- `explain_ui::wheel_zoom_factor_line_notch_direction_and_step` — колесо
  вверх = IN ровно +5 %, вниз = −5 %; y=0 — фактор 1 (пан, не зум).
- `explain_ui::wheel_zoom_factor_pixel_smooth_and_signed` — тачпад-канал:
  знак совпадает, фактор плавный.
- `docs_ui::search_pages_matches_label_and_id` / `..._body_match_yields_
  snippet` / `..._order_stable_one_row_per_page` — метка/id/тело, сниппет,
  порядок и дедуп, пустой запрос.
- `icon_pipeline::atlas_size_matches_repositories` — синхронность реестров,
  факт 5×39 = 195, UV последней ячейки в пределах атласа.
- `icon_pipeline::new_tab_icons_rasterized_in_all_ui_sets` — растр
  tab_drag/tab_suggest во всех четырёх UI-наборах.
- `text::ui_symbol_glyphs_covered_by_embedded_fonts` — шейпинг каждого
  символа инвентаря на FontSystem БЕЗ системных лиц (wasm-достоверно):
  глиф ≠ 0 (не .notdef) для всего набора.

## Инварианты

- **Знак колеса = конвенция канваса**: колесо вверх — зум IN (окно
  проверки) и контент вверх (все списки, включая доки).
- **Поиск-доки всегда помечены**: `kind: Docs` + бейдж + префикс
  подзаголовка — владелец видит, что это не ноды.
- **Ни один UI-символ не рисует тофу** на платформах без системных
  шрифтов — регресс-тест на wasm-подобной среде.
- Генератор атласа `rasterize_icons.py` — тотальный (sparse-пропуск с
  валидацией «имя покрыто хотя бы одним набором»).
