# CR-018: волна «numi-table v2» — редизайн не-редакционного рендера Numi-строк

Статус: **реализовано (этапы 1–3), приёмка на wasm ✓** · Решения владельца от 2026-10-04 · Сессия web-94a160de

## 1. Постановка

Владелец: «фактически не вижу ни Leaders ни Zebra… не хватает не ярких column separators,
hover-row подсветки и inline errors». Верификация на wasm показала корневую причину: хром
таблицы (зебра/лидеры/пилюли) препендится **под** непрозрачный per-line CodeBg
(`gfm_code_fill α=1.0`, text.rs) — гарантированно невидим на всех numi-нодах.
Сопутствующие: гейт зебры run≥4 (типичная нода с 2–3 формулами зебры не имела вовсе),
альфа зебры 0.04/0.03 (невидимая), гамма-буст quad-заливок (raw sRGB в Bgra8UnormSrgb).

## 2. Решения владельца (зафиксированы в чате)

- Q1 CodeBg → **вариант C**: убрать с numi-строк вовсе (как в прототипе); GFM-блоки кода сохраняют фон.
- Q2 зебра: каждая 2-я строка данных (0-based i%2==1), активация от 2 строк, α 0.08.
- Q3 hover-row: подсветка ряда **и правка по клику**.
- Q4/Q5: вариант (а) с возможностью отката (поэтапные коммиты; Settings-тумблер — см. §5).
- Q6 Σ-значение, Q7 доки/приёмка — да.

## 3. Реализация (коммиты, независимо revertable)

| Коммит | Содержое |
|---|---|
| `62fbc6e` | Этап 1: CodeBg только у GFM-кода (`!header && !sigma && !oblique && source_line.is_none()`); зебра `row_grid::zebra_flags_v2` (i%2 от 2 строк, хром вне нумерации); α 0.08 (dark/light/пресеты); лидеры видимы автоматически |
| `b967a68` | Этап 2a: column separators — вертикали 1px слева от колонок «значение»/«юнит» (x = направляющая − GUIDE_GAP/2), новый слот `col_sep_fill` α 0.05 |
| `165c66a` | Этап 2b/3: hover-row (hit-зоны `RowHit`, инстанс link×0.07 поверх хрома под текстом, состояние между кадрами — паттерн expr_error_hits, глушится в правке/драге/ресайзе); правка по клику (клик по строке с `source_line` → `EditingSession` + каретка в точке клика через `session.click`); inline errors (`CachedRow.error_cell` — красный текст ошибки в зоне значение/юнит, усечение «…» через `fit_cell_text`; «!»-пилюля и тултип остаются) |
