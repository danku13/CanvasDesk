## Описание (What)

Третий раунд фидбэка владельца по поверхности «Проверка цепочки расчёта»
после FR-084:

1. **Иконка редактирования строки не отображается.** Глиф `✎` (U+270E)
   отсутствует в вшитом шрифте — в зоне иконки пустой квадрат. Решение
   владельца: «нужно svg иконку» — настоящая иконка через пайплайн
   FR-ICONS.
2. **Масштаб не прокручивается.** Колесо в теле окна панорамирует
   (FR-083), потолок fit-масштаба 1.0 не даёт рассмотреть мелкое дерево
   крупнее — «нельзя прокрутить масштаб».
3. **Поле подмены не у ноды.** Inline-поле what-if рисуется в правом
   нижнем углу тела окна (`field_rect(body)`) — при редактировании строки
   карточки в левой части окна курсор уводит от контекста; ожидание
   владельца: «рядом с нодой как тултип».

| `scripts/rasterize_icons.py` | имя `edit` в списке генерации | FR-ICONS |

## Анализ (Root Cause)

- **Глиф.** Рендер текста идёт вшитым шрифтом (Noto pair, FR-009):
  U+270E в нём нет — текстовая зона рисует пустой глиф. Пайплайн
  FR-ICONS (`IconInstance`, screen-space, tint в шейдере) — штатный
  механизм монохромных SVG-иконок; карандаша в атласе не было.
- **Масштаб.** `fit_scale` — потолок 1.0 (только сжатие), колесо
  (FR-083) — пан. Механизма зума в `ExplainState` нет.
- **Поле.** `field_rect(body)` привязана к телу окна, не к редактируемой
  карточке; контекст строки теряется.

## Требуемые изменения

### AC-1 — SVG-иконка редактирования (согласовано владельцем 2026-10-02)

- В атлас FR-ICONS добавляется иконка `edit` (lucide pencil, 24×24
  stroke — стиль набора): `assets/icons/lucide/edit.svg`, имя в
  `ICON_NAMES` генератора и в сгенерированном `icon_data.rs` (растеризация
  выполняется генератором; на машинах без cairo DLL допустим эквивалентный
  байт-в-байт результат через resvg + утилитарный скрипт).
- Рендер строки таблицы: вместо текстового глифа — `IconInstance`
  (квадратная вписка в `row_edit_rect`, физ. px, tint `palette.body`,
  при hover — белый на `palette.accent`). Если пара (set, `edit`)
  отсутствует в атласе (пользовательский набор без иконки) — фолбэк на
  текстовый глиф (мягкая деградация, паттерн `KitDraw::icon`).

### AC-2 — зум колесом (согласовано владельцем 2026-10-02)

- `ExplainState.zoom: f32` (дефолт 1.0); эффективный масштаб кадра =
  `base_scale(bounds, body, defense) · zoom`, где `base_scale` — прежний
  fit (пол `SCALE_MIN`, потолок 1.0; в защите — `defense_fit_scale`).
  Диапазон зума: эффективный масштаб ∈ [`SCALE_MIN`, `ZOOM_MAX=2.5`].
- Колесо над телом окна — зум к точке под курсором (чистая функция
  `zoom_adjust_pan`: контентная точка под курсором сохраняется, пан
  пересчитывается и клампится `pan_clamp`). Shift+колесо — горизонтальный
  пан (прежний X-канал); вертикальный пан — драг фона (FR-083).
- Сброс зума — вместе с паном при смене вида/защиты/направления/
  открытии (`reset_pan` расширяется). hit=render — обе стороны используют
  эффективный масштаб из `explain_view`.

### AC-3 — поле подмены у ноды, как тултип (согласовано владельцем 2026-10-02)

- Новая чистая функция `edit_anchor_rect(layout, leaf_idx, scale, body,
  origin) -> Option<[f32;4]>`: экранный прямоугольник якоря — строки
  таблицы (или карточки для не-табличных листьев).
- `field_rect(body, anchor)`: поле шириной 260 px под якорем (+6 px);
  если снизу не влезает — над якорем; X клампится в тело. Рендер и
  hit-тест поля используют одну функцию (детерминизм).

### Не делаем

- Ширина `CARD_W`, Ltr/Rtl-зеркало, группировка FR-084, парити-тесты
  окна FR-083 — не трогаются. Формат `.canvas` и модель `LineageTree` —
  без изменений. Персист зума в настройки — нет (сессионное состояние
  вида, сбрасывается навигацией). Атлас пересобирается генератором
  (ручные правки `icon_data.rs` — только эквивалентные байты растеризации).

## Проверка

- Юнит-тесты: `zoom_adjust_pan` (идентичность при равных масштабах,
  фиксация точки под курсором), `base_scale` (обычный/защита), `field_rect`
  (под якорем / флип над якорем у нижнего края / кламп X), `edit_anchor_rect`
  (строка таблицы / не-табличная карточка), `reset_pan` сбрасывает зум.
- Гейты: `cargo test -p canvas-app -p canvas-core`, clippy `-D warnings`,
  fmt, wasm-check canvas-core.
- Ручная приёмка владельца: иконка-карандаш видна в строках и красится
  темой; колесо приближает/отдаляет дерево к курсору (до 2.5×, фокус —
  под курсором), Shift+колесо — пан по горизонтали; поле подмены
  открывается непосредственно под строкой карточки (над — если снизу
  не влезает), клик мимо — коммит; Esc/крошки/защита — без изменений.
