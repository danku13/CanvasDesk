## Описание (What)

Пользователь запросил новый объект **mindmap**. По уточнению владельца это
**расширенный режим ноды**: от выделенной ноды по `Tab` создаётся **связанная
дочерняя нода** (новая text-нода + ребро), по `Enter` — **нода на одном
уровне** (сиблинг: та же родительская нода), ветку можно **сворачивать и
разворачивать**. Ветвление живёт на канвасе обычными нодами и рёбрами —
остаются доступны все механики (drag, выделение, undo, поиск). Зафиксированы
оба варианта интерпретации: (a) mindmap-режим над нодами канваса — выбранный
пользователем механизм; (b) рендер mindmap внутри одной ноды — открытый
вопрос последующих версий.

## Анализ (Root Cause)

В текущей реализации mindmap-механики нет; перечислено, на чём строить:

- **Тип ноды не требуется:** `NodeKind` (`model.rs:22-34`) — `File`, `Text`,
  `Link`, `Group`, `Widget`, `Unknown`. Ветви mindmap — существующий тип
  `text` + `edge`; структура дерева выводится из рёбер (корень — нода без
  входящих рёбер поддерева).
- **Создание ноды** — `create_note_at` (`main.rs:3753`); **создание связи** —
  drag от порта (`EdgeDrag::New`, `main.rs:3720-3743`, drop на `Released` →
  `add_edge`, `main.rs:3864+`). `Tab` собирает обе операции атомарно:
  новая text-нода рядом + ребро от текущей + `begin_editing` на новой ноде.
- **Сиблинг (`Enter`)**: найти родителя текущей ноды (единственное входящее
  ребро поддерева) и выполнить ту же операцию от него.
- **Состояния «свернута» нет:** у `Node` нет поля collapse. Хранить в
  расширении `.canvas` по образцу `CanvasdeskExt` (виджет-ноды,
  `model.rs:22-34` комментарий, SPEC §5.1) — сторонние редакторы сохраняют
  неизвестное поле без потерь (round-trip, `json_canvas_io.rs`).
- **Скрытие свернутого поддерева** затрагивает: рендер (`cards.rs` —
  фильтрация инстансов), hit-test (`SpatialIndex`/`selective_hit`,
  `main.rs:1514-1520`), рёбра поддерева, миникарту и поиск. Образец обхода
  поддерева — `focus_set` (`focus.rs:56-97`).
- **Конфликт хоткеев:** `Enter` в редакторе текста — перевод строки/commit
  (`NamedKey::Enter`, `main.rs:1927`); канвас-хоткеи приглушаются при
  редактировании/поиске/диалоге (`main.rs:3243`, `3265-3272`) — mindmap-хоткеи
  действуют только при выделенной ноде вне этих режимов.
- **Позиция новой ветви** — по правилам раскладки FR-010 (по умолчанию
  tree-режим выбранной схемы), иначе рядом со смещением.

## Требуемые изменения (Changes)

1. `canvas-core` (`model.rs`): расширение ноды `canvasdesk.collapsed: bool`
   (или аналогичное поле расширения) — сериализация в `.canvas`, round-trip
   без потерь; чистая функция `subtree_ids(canvas, root) -> Vec<usize>` по
   рёбрам (образец `focus_set`).
2. `canvas-app`, ввод (`on_key`, `main.rs:3243+`): при выделенной ноде вне
   редактора/поиска/диалога —
   - `Tab`: `push_undo` → создать text-ноду (позиция по раскладке FR-010) +
     ребро родитель→новая + `begin_editing` новой ноды; один undo-шаг;
   - `Enter`: найти родителя, `push_undo` → создать text-ноду-сиблинга +
     ребро от родителя + `begin_editing`; один undo-шаг;
   - `Ctrl/кнопка сворачивания` (например, `Ctrl+←/→` или пункт меню
     FR-009): тогл `collapsed` на ноде.
3. Скрытие свернутого поддерева: фильтр `subtree_ids` в рендере
   (`card_instances`), hit-test (spatial-запросы), рёбра поддерева,
   миникарта; заголовок свернутой ноды — индикатор «+N» (число скрытых).
4. Раскладка ветвей — вызов плана FR-010; при отсутствии FR-010 —
   смещение по часовой стрелке от родителя (временный упрощённый вариант).
5. Меню ноды (FR-009): «Добавить дочернюю (Tab)», «Добавить сиблинга
   (Enter)», «Свернуть/развернуть ветку».
6. MCP (опционально, FR-005): инструменты `mindmap_child_add` /
   `mindmap_toggle` — вне v1, зафиксировано как расширение.

## Открытые вопросы дизайна

- Способ сворачивания: только хоткеи или also клик по индикатору в шапке?
- Поведение рёбер к внешним нодам (не из поддерева) при сворачивании —
  предлагается: такие рёбра не скрывать.
- Вариант (b) — рендер mindmap внутри одной ноды — отложен; переоценка
  после v1 (данные ветвления те же).

## Проверка (Verification)

- `Tab` на выделенной text-ноде → новая нода рядом, ребро от текущей,
  каретка в редактировании новой ноды; `Ctrl+Z` возвращает всё одним шагом.
- `Enter` на ноде с родителем → сиблинг того же уровня (одно и то же
  входящее ребро); у корня канваса `Enter` — как сейчас (пустое место →
  заметка) либо no-op — зафиксировать реализацией.
- Сворачивание скрывает всё поддерево (ноды + рёбра + мини-карту);
  индикатор «+N» на ноде; разворачивание возвращает позиции.
- Свернутое состояние переживает автосейв/перезапуск и round-trip через
  Obsidian Canvas (неизвестное поле сохраняется).
- Хоткеи не срабатывают в редакторе текста/поиске/диалоге (приглушение).
- Юнит-тесты: `subtree_ids` (ветвление, циклы — защита), сериализация
  `collapsed`, undo-шаг Tab.
