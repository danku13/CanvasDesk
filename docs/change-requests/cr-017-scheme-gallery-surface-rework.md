# CR-017: Переработка поверхности «Шаблоны схем» (галерея схем)

- **Статус:** выявлено (бэклог)
- **Тип:** CR
- **Приоритет:** важно
- **Владелец:** не назначен
- **Источник:** запрос владельца 2026-09-26 — «в этот же бэклог возьми переработку поверхности меню "screen templates"»
- **Связанные задачи:** FR-049 (галерея v1 + контент v2), FR-024 (miro-style панель шаблонов нод), PRD-0008 §5 (галерея), PRD-0008 §7.2.1 (контент v2)
- **Создан:** 2026-09-26
- **Обновлён:** 2026-09-26

## 1. Описание (What)

Поверхность выбора готовых схем («Шаблоны схем», открывается из empty-state, меню «?», шага 7 онбординга и `Ctrl+T`) реализована как модальный список текстовых строк: название, описание, «ноды: N, связи: M». Владелец запросил переработку этой поверхности — экран выбора шаблонов («screen templates») должен стать витриной, по которой пользователь выбирает отправную точку работы, а не читает список.

Выявил: владелец (запрос в сессии шаблона A/B-расчёта). Подтверждающие наблюдения агента за текущим состоянием перечислены в §3.

## 2. Влияние (Impact)

| Объект | Что затрагивается | Где в документации |
|---|---|---|
| Галерея схем | Вся поверхность: раскладка, навигация, выбор | `docs/interface-objects/scheme-gallery.md` |
| Empty-state | Кнопка «Открыть галерею» ведёт на переработанную поверхность | `docs/interface-objects/scheme-gallery.md` §2 |
| Онбординг (шаг 7) | CTA «Попробовать» открывает галерею | `docs/interface-objects/onboarding.md` |
| Витрина шаблонов нод (палитра) | Сопряжённая поверхность — решения о превью/плотности переносятся | `docs/change-requests/fr-024` |

## 3. Наблюдения над текущим состоянием (Root Cause)

Состояние v1 (FR-049, `crates/canvas-app/src/scheme_gallery_ui.rs` — `SchemeGalleryState`, `rows`, `layout`; рендер/ввод — `crates/canvas-app/src/app/overlays.rs::scheme_gallery_overlay`):

1. **Нет превью.** Строка показывает только текст; пользователь не видит ни структуру графа, ни форму нод — выбор делается по названию и описанию вслепую. Тот же граф уже умеет рисоваться без GPU-контекста: `crates/canvas-render/src/thumbs.rs` (тамбнейлы файлов) — в галерее не используется.
2. **Плотность строк.** Каждая схема — одна строка с полным описанием; каталог 6 → 10 (FR-049.13) уже прокручивается на 1280×800 (`clamp_scroll`), 11-я схема (ab-test, FR-049.14) усугубляет. Сравнивать схемы скроллом неудобно.
3. **Потолок категорий.** Чипы «Все» + N категорий раскладываются в один ряд при ширине чипа 108 (тест `chips_all_categories_fit`, панель 560, inner 536 — максимум 5 чипов). Шестая категория потребует либо второй ряд, либо иную навигацию — поверхность к этому не готова.
4. **Описание = единственный носитель смысла.** Длинные RU/EN описания обрезаются в строке; сценарий «найди схему под мою задачу» работает только через подстрочный фильтр.

Ограничения, которые нужно сохранить (инварианты FR-049): вставка схемы — один undo-шаг, zoom-to-fit, тост; ремап id без коллизий; 0 I/O в hot path (реестр `OnceLock`, ассеты в бинарнике); кламп панели к вьюпорту (инвариант 320×240); клавиатурный путь ↑/↓/Enter/Esc; web `?template=<id>`.

## 4. Требуемые изменения (Changes) — направления на анализ

Направления фиксируются как кандидаты; конкретный дизайн — после решения владельца:

| # | Кандидат | Суть | Где |
|---|---|---|---|
| C1 | Карточки с превью | Сетка карточек вместо строк; превью графа схемы рендерится упрощённым проходом (bbox нод + линии рёбер поверх `thumbs`-пайплайна `canvas-render`) из `content.nodes/edges` реестра — без инстансирования сцены | `scheme_gallery_ui.rs`, `canvas-render/src/thumbs.rs` |
| C2 | Двухколоночная поверхность | Левая колонка — список/категории с плотными строками, правая — крупное превью и полное описание выбранной схемы (мастер-деталь; клавиатура сохраняется) | `scheme_gallery_ui.rs::layout` |
| C3 | Навигация категорий, масштабируемая за 5 | Секции-заголовки вместо чипов, либо чипы в два ряда с явным расчётом (не молчаливый срез — D2-урок FR-049.11) | `scheme_gallery_ui.rs` |
| C4 | Плотность списка | Сворачивание описания до 1–2 строк с полным текстом в превью/тултипе | `scheme_gallery_ui.rs::row_labels` |
| C5 | Сопряжение с палитрой нод | Общие решения о превью/плотности для палитры шаблонов (FR-024) — один визуальный язык выбора «готового» | `template_ui.rs` |

## 6. Проверка (Verification)

- Юнит-тесты раскладки `scheme_gallery_ui` (кламп к вьюпорту 320×240, окна видимости, клавиатурная навигация) обновлены под новую поверхность.
- CJM-инварианты: вставка из новой поверхности — один undo-шаг (G3), вставка на занятый канвас без коллизий (US-3), web `?template` без регрессий.
- Чипы/навигация категорий не срезаются молча (тест в духе `chips_all_categories_fit` для нового механизма).
- Производительность: открытие галереи ≤ кадр на каталоге ≥ 20 схем с превью (кэш превью, 0 I/O в hot path).
- Ручная приёмка: `docs/ACCEPTANCE.md` — новая строка FR-049.x / отдельный FR на переработку.
