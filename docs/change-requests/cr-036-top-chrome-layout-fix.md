- **Тип:** CR

## 1. Описание (What)

После CR-035 (единый UI-слой) владелец наблюдал на деплое регрессию вёрстки: (1) кластер ⚙/☼/RU-EN/? «улетел» от угла — кнопки висели на y=48..84 вместо кромки y=12..48; (2) чип активного канваса оставался в левом верхнем углу — по директиве должен быть прижат вправо, слева от «?»; (3) «Об авторе» стал текстовым чипом внизу-слева — должен визуально повторять удалённый DOM `#author-bar` (ряд из 5 иконок топ-лево). Дополнительно — user-docs описывали удалённую «панель хранилища».

## 3. Анализ (Root Cause — ответ на вопрос владельца «почему вёрстка не была починена»)

CR-035 переносил элементы в GPU «как есть», но не пересчитал компенсации, накопленные wasm-слоем для сосуществования с DOM-хромом:

1. **Компенсационный инсет пережил свой предмет.** `WEB_TOOLBAR_INSET = 36` существовал, чтобы GPU-кнопки не резались DOM-тулбаром W6 (правый верхний угол, полоса 8..36). CR-035 удалил тулбар, но не константу — кнопки «уехали» вниз на пустое место. Комментарий константы всё ещё ссылался на удалённый DOM — некому было «закрыть хвост».
2. **Гейты не видели позицию.** G4-линт проверяет пересечения интерактивных rect'ов и выход за вьюпорт — но не «кто в каком углу живёт». Ассерт `button_rect(TopRight).y == SETTINGS_MARGIN` существовал, но гонялся на нативе, где `#[cfg(wasm32)]`-инсет = 0: платформенно-зависимая константа была невидима тестам.
3. **Аудит легализовал регрессию.** `wasm_audit.mjs` зашил НОВУЮ (сбитую) позицию кластера как эталон (HELP [x,66]); более того — метка HELP фактически указывала на кнопку языка (клик переключал RU↔EN, скриншоты «help_menu» снимали не меню). Эталон без позиционного контракта закрепляет любое состояние, включая сломанное.
4. **Чек-лист верификации CR-035 был функциональным, не позиционным.** «DOM-хрома нет / чип виден / About и Тур работают / 0 pageerror» — всё про наличие и кликабельность, ничего про геометрию. Удаление DOM-слоя должно было тянуть пересчёт всех зависимых позиций (инсет кластера, flowmap PANEL_TOP, положение чипа) — этого в критериях приёмки не было.

**Лекарство (этот CR):** контракт-тест верхнего хрома `top_chrome_contract_corners_and_rows` — позиционные ассерты «кто где живёт» (кластер у кромки, чип прижат к «?» и в ряду кластера, flowmap ниже ряда, author-bar топ-лево), плюс `chip_left_bound` — единая функция гарантированного края чипа для клампов соседних панелей.
