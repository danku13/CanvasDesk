## Описание (What)

Wheel-меню шаблонов (Shift+клик) после правки FR-018 уже не налезает
(радиусы вычисляются от размера плашек, зазор гарантирован AABB-тестом).
Этот FR адаптирует **отраслевые бест-практики радиальных меню**
(pie/radial menu) для случая «много пунктов»: поведенческие элементы,
которых не хватает текущей реализации — центральный хаб как явная кнопка
«назад/закрыть», затемнение подложки под меню и индикатор глубины
(хлебные крошки выбранной категории).

## Исследование бест-практик (Research)

Источники:

- Wikipedia «Pie menu»: выбор направлением; равные угловые секторы;
  быстрая работа «мышечной памяти» при фиксированных позициях пунктов
  (https://en.wikipedia.org/wiki/Pie_menu).
- G. Kurtenbach, W. Buxton, «User Learning and Performance with Marking
  Menus» (CHI '94): иерархические радиальные меню — на каждом уровне
  **немного направлений** (≤ 8), глубина вместо длины кольца; центр —
  отмена/уровень вверх.
- L. Morris, «Putting the 'Rad' Back in 'Radial Menus'» (Prototypr,
  2018): рекомендации практиков — ограничивать число пунктов кольца,
  группировать в категории с подменю, визуально выделять пункт под
  курсором, предусматривать явный выход в центре.
- J. Nielsen / Big Medium, «Touch Means a New Chance for Radial Menus»
  (2012): радиальные меню эффективны для частых действий; крупные цели,
  гарантированные зазоры между секторами.
- Практика модальных пикеров в canvas-инструментах (Miro Template
  picker, help.miro.com): панель выбора шаблона открывается поверх доски
  с **затемнением фона** — фокус на выборе, случайные клики по канвасу
  исключены.

Сводка применимого к CanvasDesk:

| Бест-практика | Статус до | Решение |
|---|---|---|
| Равные угловые секторы, старт с 12 часов | есть (`sector_center_angle`) | — |
| Кольцо ≤ ~6–8 пунктов; переполнение — глубина/под-кольца | есть (`wheel_ring_plan`, под-кольца) | — |
| Зазор между пунктами, цели крупнее минимума | есть (правка FR-018) | — |
| Hover-подсветка пункта под курсором | есть (`wheel_overlay`) | — |
| **Центр = «назад/закрыть»** (Kurtenbach/Buxton, Prototypr) | хаб глотает клик, без аффорданса | хаб-кнопка: клик — назад (есть категория) / закрыть |
| **Затемнение фона** под модальным пикером (Miro) | нет | полупрозрачный подложечный квад на весь viewport |
| **Индикатор глубины** (где я: категория) | текст-подсказка в хабе | крошки в хабе: «← категория» |
| Клавиатурный выход | есть (Esc закрывает) | — |

## Эталон-референс: circular-menu (npm)

Указание владельца (2026-09-16): за пример circular-меню взять
https://www.npmjs.com/package/circular-menu (автор yandongCoder,
GitHub: https://github.com/yandongCoder/circular-menu). Это
DOM/CSS-реализация колесного меню; переносим механику (визуальные и
поведенческие приёмы), не код. Свойства конфига пакета: `totalAngle`
(полный круг 360°), `spaceDeg` (зазор между секторами), `start`
(стартовый угол), `diameter` (диаметр меню), `position` (раскрытие
стороной к якорю), `horizontal` (иконка и подпись в ряд),
`background`/`backgroundHover` (фон пункта и под курсором),
`hideAfterClick` (скрытие после выбора), `menus` (конфиг-массив пунктов:
иконка, подпись, клик, подменю); методы `show([x, y])` — открытие в
точке курсора, `hide()`.

Сверка эталона с текущей реализацией CanvasDesk:

| Приём circular-menu | У нас | Решение |
|---|---|---|
| Полный круг 360° (`totalAngle`) | есть (кольцо вокруг хаба) | — |
| Зазор между секторами (`spaceDeg`) | есть (`WHEEL_GAP`, AABB-тест FR-018) | — |
| Пункт = иконка + подпись горизонтально (`horizontal`) | есть (квад-иконка + имя плашки) | — |
| Смена фона пункта под курсором (`backgroundHover`) | есть (hover-подсветка `wheel_overlay`) | при желании — подложка пункта меняет фон целиком (сейчас рамка/акцент) |
| Открытие в точке курсора (`show([x, y])`) | есть (меню открывается в точке Shift+клика) | — |
| Скрытие после выбора (`hideAfterClick`) | есть (выбор пункта закрывает меню) | — |
| Стартовый угол (`start`) | есть (`sector_center_angle`, старт с 12 часов) | — |
| Конфиг-массив пунктов с подменю (`menus`) | есть (реестр категорий/шаблонов → кольца/под-кольца) | — |
| Раскрытие стороной к якорю (`position`) | н/п (меню не привязано к краю экрана; есть кламп `WHEEL_SCREEN_MARGIN`) | — |

Вывод: реализация FR-022 по механике соответствует эталону; расхождение —
только в детали hover-подсветки (фон пункта vs рамка), что косметика и может
быть перенято при полировке вёрстки.

## Влияние (Impact)

| Объект | Что меняется |
|---|---|
| `template_ui.rs` | `WheelGeometry.hub` — прямоугольник хаба (квад под круг); `WheelGeometry::hub_hit` — тест попадания в хаб; подложечный квад — зона рендера (вне чистой геометрии) |
| `main.rs` wheel_overlay | подложка-затемнение, круг-хаб (CardInstance с радиусом = половина стороны), текст хаба: «закрыть» / «← {категория}» |
| `main.rs` клики | клик по хабу: категория выбрана → сброс категории («назад»), иначе — закрытие меню |
| Доки | `docs/interface-objects/template-wheel.md` (если есть), юзер-доки `interface.md` — поведение хаба |

## Требуемые изменения (Changes)

1. **`crates/canvas-app/src/template_ui.rs`**
   - `pub const WHEEL_HUB_D: f32 = 48.0` — диаметр кнопки-хаба (крупная
     цель ≥ 44 px — гайдлайн сенсорных целей, Big Medium);
   - `WheelGeometry { hub: [f32; 4], ... }` — квадрат вокруг центра
     (`hub_d × hub_d`), заполняется в `wheel_geometry`;
   - `pub fn hub_hit(&self, cursor: Vec2) -> bool` — попадание в квадрат
     хаба (визуальный круг = вписанный в квадрат, углы простительны —
     Fitts);
   - инвариант-тест: ни одна плашка не пересекает квадрат хаба
     (усиление существующего «не заходит в WHEEL_HUB_R»).

2. **`crates/canvas-app/src/main.rs`**
   - `wheel_overlay`: первый квад кадра — затемнение viewport
     (fill `[0,0,0,0.35]`, без радиуса/рамки); круг-хаб (радиус скругления
     = половина стороны); текст хаба: без категории — «закрыть», с
     категорией — «← {имя категории}» (крошки-индикатор глубины);
   - обработчик клика: `geo.hub_hit(cursor)` → если `menu.category`
       есть — сброс в `None` («назад» к кольцу категорий), иначе
       `wheel_menu = None` («закрыть»); клик глотается.

3. **Проверка**: юнит-тесты `template_ui` (хаб не пересекается с
   плашками, `hub_hit` по центру true / на кольце false); ручная
   приёмка — Shift+клик → затемнение, клик по хабу возвращает кольцо
   категорий, повторный — закрывает.

## Архитектура тестируемости (инварианты)

1. Хаб — часть чистой геометрии (`wheel_geometry`), рендер и hit-test
   используют один и тот же прямоугольник (инвариант WYSIWYG FR-018).
2. Кнопка-хаб ≥ 44×44 логических px (сенсорный минимум).
3. Налезание плашек на хаб невозможно по построению (тест).
4. Поведение «назад/закрыть» детерминировано: хаб с выбранной категорией
   всегда возвращает на уровень категорий (не закрывает меню).

## История изменений (Changelog)

- `2026-09-16` — агент: **donut-рестайл wheel по скриншоту пользователя**
  (форма по https://www.npmjs.com/package/circular-menu — код свой, пакет
  JS). Прямоугольные плашки на кольцах заменены donut-секторами с
  центральным отверстием: в каждом секторе иконка + короткая подпись,
  между секторами угловые зазоры. Новый instanced SDF-проход
  `canvas-render/src/sectors.rs` + `shaders/sectors.wgsl`
  (`SectorInstance`: center/r0/r1/a0/a1/fill — 10 floats, annular-wedge
  SDF со smoothstep-AA, bbox сектора считается в vertex-шейдере).
  Геометрия wheel (`template_ui.rs`): кольца фиксированной толщины
  `WHEEL_RING_THICKNESS=68` + `WHEEL_RING_GAP=8`, вместимость кольца из
  минимальной дуги сектора 60 px (`ring_capacity`, кольцо 0 вмещает 5),
  переполнение — концентрические под-кольца (`wheel_ring_plan`), угловой
  зазор `WHEEL_SECTOR_GAP` ≈ 2.5°. Hit-test стал полярным
  (`WheelGeometry::hit` через `sectors::angle_gap` — Rust-зеркало WGSL,
  инвариант WYSIWYG: что нарисовано SDF, по тому и клик). Затемнение фона
  — первый инстанс секторного прохода (диск-полный-круг). Цвета wheel
  вынесены в именованные константы `wheel_overlay` (полноценный
  ThemeColors — открытый вопрос). Тесты: `sector_smoke.rs` (headless GPU:
  дуга/дырка/зазоры/AA), юнит-геометрия секторов, wheel-тесты переписаны
  под donut (радиусы колец, угловые зазоры с wrap-around 0/2π, полярный
  hit, вместимость, сквозные индексы).
- `2026-09-16` — агент: по указанию владельца добавлен эталон-референс
  circular-menu (npm, yandongCoder) — сводная таблица приёмов пакета против
  текущей реализации; расхождений по механике нет, зафиксирована косметическая
  разница hover-подсветки.
- `2026-09-16` — агент: документ создан по итогам исследования
  бест-практик радиальных меню (Wikipedia, Kurtenbach/Buxton, Prototypr,
  Big Medium, паттерн Miro Template picker). Реализуемая часть v1: хаб-

  размера плашек и под-кольца — уже в main с правки FR-018 (8a935ca).
