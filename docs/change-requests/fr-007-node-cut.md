## Описание (What)

Буфер FR-003 поддерживает только копирование (`Ctrl+C`) — переместить набор
нод на другое место канваса можно лишь вручную (drag) или комбинацией
«скопировать → удалить → вставить». Требуется `Ctrl+X` — вырезать выделенные
ноды в буфер с последующей вставкой через `Ctrl+V` (в т.ч. после перезапуска
буфера другими операциями не требуется — буфер внутренний, живёт в сессии).

## Анализ (Root Cause)

- `copy_selection` (`main.rs:1104`) уже собирает выделенные ноды в
  `node_clipboard` без мутации сцены.
- `delete_selected` (`main.rs:1157`) уже удаляет набор с каскадом связей,
  сбросом кэшей и (после FR-006) undo-снапшотом.
- Вырезание = композиция двух существующих операций, новая доменная логика
  не требуется; несуществующая функция — точка входа хоткея и связка.

## Требуемые изменения (Changes)

1. `App::cut_selection()`: `copy_selection()` → `delete_selected()`; лог
   `tracing::debug` с количеством. Пустое выделение — no-op.
2. `on_key`, блок Ctrl (паттерн FR-003): `"x" | "ч"` → `cut_selection()`;
   срабатывает вне редактора/поиска (в редакторе Ctrl+X — вырезание текста,
   существующее поведение не трогаем).
3. `HOTKEYS` (lib.rs): строка `("Ctrl+X", "вырезать ноды")`.

## Проверка (Verification)

- `Ctrl+X` на выделенной ноде/наборе → ноды исчезли, автосейв сработал.
- `Ctrl+V` → вставка копий (новые id, центром на курсор — правила FR-003).
- `Ctrl+Z` → вырезанные ноды возвращены (связи каскадно восстановлены).
- Кириллическая раскладка («ч») — работает.
- Внутри текстового редактора `Ctrl+X` — прежнее поведение (вырезание текста).
