# CR-014: Веб-оболочка canvas-web не адаптивна — текст панели уходит за край экрана

- **Статус:** выполнено
- **Тип:** CR
- **Приоритет:** важно
- **Владелец:** агент (трек B, сессия 2026-09-20)
- **Источник:** сообщение пользователя (сессия 2026-09-20: «Проверь всю вёрстку и поправь её так, чтобы текст не вылетал за края (проверь адаптивность)»); браузерный аудит Playwright (6 вьюпортов, скрипт `scripts/layout_audit.py` локальной сессии)
- **Связанные задачи:** wasm-port §4.2 (W6 DOM-панель), §6 W12 («W12 отполирует стиль» — комментарий в index.html); search_ui.rs (панель поиска топ-центр); minimap_pass.rs (миникарта правый низ); template_ui.rs (палитра левый край)
- **Создан:** 2026-09-20
- **Обновлён:** 2026-09-20

## Описание

DOM-панель хранилища web-сборки (`#w6-toolbar`, 3 кнопки поверх GPU-канваса) не имеет
никакой адаптивности: без `flex-wrap`/`max-width`/`text-overflow` панель растёт
внутренним содержимым и при длинной подписи «Недавние: <имя файла>» упирается в левый
край экрана (текст обрезается окном). Панель фиксирована в правом верхнем углу и на
окнах ≤ ~1196 px наезжает на зону панели поиска (топ-центр, `PANEL_WIDTH=460`); на
телефонах (375–390 px) три кнопки занимают почти всю ширину окна и перекрывают зону HUD
(топ-лево). Канвас растянут `100vh` без `dvh`-фолбэка — на мобильных браузерах нижняя
часть уходит под адресную строку. Тач-цели кнопок ~27 px — ниже минимальных 44 px
(Apple HIG / Material). Выявил пользователь + браузерный аудит агента.

## Анализ

- `crates/canvas-web/index.html:114-131` — `#w6-toolbar`: `display: flex; gap: 6px;`
  без `flex-wrap`, без `max-width`; кнопки без `min-width: 0`, `max-width`,
  `text-overflow: ellipsis` — flex-строка растётся контентом, панель (якорь `right: 8px`)
  выезжает левым краем за viewport, `body { overflow: hidden }` маскирует скролл —
  кнопка «Открыть с диска…» просто срезается.
- `crates/canvas-web/src/toolbar.rs:73-85` — `set_recent_label` пишет
  `Недавние: {name}` в `textContent` кнопки без ограничения длины и без `title`
  (полное имя теряется при эллипсизации CSS).
- `crates/canvas-web/index.html:104-110` — `body > canvas { height: 100vh; }` без
  `100dvh`-фолбэка (динамический viewport мобильных браузеров).
- Геометрия GPU-панелей (зоны конфликтов, все — screen-space):
  поиск `crates/canvas-render/src/search_ui.rs:16-26` (топ-центр, 460 px, кламп к окну);
  HUD `text.rs:1862-1892` (топ-лево, `HUD_PADDING`); миникарта
  `crates/canvas-render/src/minimap_pass.rs:51-63` (право-низ, 220×140 + 16, от 252×172
  окна); палитра `crates/canvas-app/src/template_ui.rs:416-430, 663-673` (левый край,
  высота почти во всё окно).
- GPU-текст карточек/панелей переполнений не даёт: тело — `Wrap::WordOrGlyph`
  (`text.rs:678`), заголовок/строки-результаты/HUD/оверлеи — однострочные буферы,
  обрезаемые `TextBounds` в `TextArea` (`text.rs:2102-2115, 2158-2171, 2475-2488,
  2527-2540`) — за пределы окна текст физически не рисуется (viewport wgpu). Дефект
  только в DOM-оболочке.
- Сайт Pages: `pages-web.yml` собирает Jekyll из `./docs`; в `docs/` нет `index.md` —
  корень сайта 404 (проверено curl: `/` → 404, `SPEC.html` → 200).
- Аудит до фикса (Playwright, HEADLESS, локальный trunk-build, вьюпорты
  375/390/768/1024/1280/1920): пересечение тулбара с зоной поиска на 375/390/768/1024;
  при длинном имени тулбар 690 px шириной, на 375 px — x=0 (упор в край, дальше —
  за экраном).

## Требуемые изменения

| Что | Где | Как |
|---|---|---|
| Панель никогда не покидает экран | `crates/canvas-web/index.html` (CSS `#w6-toolbar`) | `flex-wrap: wrap; max-width: calc(100vw − 16px)`; кнопкам `min-width: 0; max-width: 100%; overflow: hidden; text-overflow: ellipsis; white-space: nowrap` |
| Подпись «Недавние: <имя>» ограничена | там же | `#btn-recent { max-width: min(40vw, 240px) }` — детерминированный px-кап (ch/vw зависят от системного шрифта: на fallback-шрифтах headless «0» = 7.64px против ~6.6px Segoe UI — кап плывёт) + полный текст в `title` |
| Полное имя в тултипе | `crates/canvas-web/src/toolbar.rs` (`set_recent_label`) | `set_attribute("title", «Переоткрыть: <имя>»)` рядом с `set_text_content` |
| Узкие окна/планшеты/телефоны (<1200 px) | там же (CSS `@media (max-width: 1199px)`) | тулбар → левый нижний угол — единственная всегда-пустая зона (топ-центр — поиск до vw≈1196 даже с коротким именем, топ-лево — HUD, право-низ — миникарта, левый край — палитра); `max-width: max(120px, 100vw − 264px)` — не залезает в колонку миникарты |

| Тач-цели ≥44 px | там же (`@media (pointer: coarse)`) | `font: 13px`, `padding: 12px 16px` |
| Клавиатурный фокус видим | там же | `:focus-visible { outline: 2px solid … }` |
| Выделение текста кнопок | там же | `user-select: none` (+ `-webkit-`) |
| Лендинг сайта (корень 404) | `docs/index.md` (новый) | компактный индекс: что такое CanvasDesk, ссылки на SPEC/README/user-docs/приложение `/app` |

## Известные ограничения (принято)

- **≥1200px, длинное имя + открытый поиск**: тулбар (топ-право, 27px высотой)
  может перекрыть правый край ПОЛЯ ВВОДА поиска (ряды результатов ниже,
  y≥64, не затронуты); ввод — клавиатурный, левая часть поля кликабельна.
  Геометрический предел: свободная зона справа от панели = `vw/2−238px`;
  фиксированные кнопки ~250–280px (зависят от системного шрифта) — кап имени,
  не задевающий панель на 1200–1400px, уменьшал бы его до ~4–8 символов.
  Компромисс: кап 240px + WARN в аудите (не FAIL) с этим обоснованием.
- **Телефоны <400px**: тулбар в стопку шириной 120px с жёстким эллипсисом
  («Открыть…»). Продукт — десктоп (клавиатурные хоткеи, WebGPU); телефонный
  режим — best effort: инвариант только «не за экран».
- **Палитра шаблонов открыта (Ctrl+P)**: тулбар внизу слева перекрывает её
  футер-подсказку (декоративный текст, CR-011); строки списка и свернутый
  persistent-стрип (центр левого края) не затронуты.
