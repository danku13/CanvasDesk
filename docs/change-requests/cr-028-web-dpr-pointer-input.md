# CR-028: Web (wasm) при devicePixelRatio ≠ 1 — указательный ввод смещён, dblclick не создаёт заметку

- **Статус:** выявлено (воспроизведено headless-chromium, DPR 1.5)
- **Тип:** CR (дефект платформы)
- **Приоритет:** высокий (Windows 125–150% — типовая конфигурация; блокирует редактирование)
- **Владелец:** danku13, агент (обнаружено при расследовании CR-027)
- **Источник:** наблюдение 2026-10-08, скрипты `scripts/fit_dpr2_repro.mjs`, `scripts/fit_dpr3_repro.mjs`
- **Связанные:** FR-100 (web-слой, W4), UR-001-02 (модификаторы winit-web), FR-095 (web-шим)
- **Создан:** 2026-10-08

---

## Симптом (What)

На web-сборке при deviceScaleFactor = 1.5 (headless-chromium, экран 1280×800 CSS):

1. Двойной клик по пустому холсту НЕ создаёт заметку (редактирование не стартует; 0 пикселей синей рамки выделения во всём кадре). На DPR 1 тот же сценарий создаёт заметку детерминированно.
2. Клики по кнопкам тур-карточки («Пропустить», «Пустой холст») частично не срабатывают: тур не продвигается по клику в геометрический центр кнопки, измеренный по кадру.
3. Тур-карточка рендерится в иной CSS-геометрии, чем при DPR 1 (доля кадра отличается — UI-слой и hit-слой расходятся).

## Анализ (Root Cause — гипотеза)

Расхождение систем координат указателя и рендера при scale_factor ≠ 1: события курсора приходят в CSS-px, рендер/хит-тест оперируют физическими/логическими px с множителем scale_factor. При DPR 1 системы совпадают (дефект не виден). Требуется трассировка `cursor_world`/`viewport_logical`/`scale_factor` в web-пути (canvas-web + `App::zoom_px`, `renderer.rs:1235`), включая `window.scale_factor()` winit-web.

Напоминание контекста: целевая платформа продукта — web (решение владельца, UR-001 Q&A); desktop-мониторы Windows по умолчанию 125–150%.

## Влияние (Impact)

| Объект | Что ломается |
|---|---|
| Создание заметки | dblclick по холсту не работает (основной сценарий входа) |
| Онбординг/тур | Кнопки шагов частично некликабельны — новый пользователь на HiDPI не проходит тур |
| Всё канвас-U_I | Любые hit-зоны (порты, меню, панели) под подозрением на смещение |

## Предлагаемый объём фикса

Слой canvas-web/App (без вмешательства в winit): единая точка конверсии указателя (CSS → world) с учётом scale_factor; смоук web-указателя (puppeteer/playwright-скрипт из `scripts/fit_dpr3_repro.mjs` — готовая основа) в гейты W4 (FR-100 D1(б)).

## Проверка (Verification)

- DPR 1.5: dblclick создаёт заметку; тур проходится кликами; порты/меню кликабельны по видимым позициям.
- DPR 1.25 (Windows-дефолт): то же.
- DPR 1: без регрессий.
