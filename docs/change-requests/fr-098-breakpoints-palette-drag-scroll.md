# FR-098: Точки MODAL_BP_COMPACT/MOBILE оживают + drag-скролл палитры

- **Статус:** выполнено
- **Тип:** FR (мобильная компоновка → W-e остаток ui-kit аудита)
- **Приоритет:** важно
- **Владелец:** агент (сессия 2026-10-03)
- **Источник:** аудит мобильной адаптации 2026-10-03; `MODAL_BP_COMPACT = 1280` / `MODAL_BP_MOBILE = 768` объявлены и не реализованы («поведение ниже точки в v1 не реализуется», settings_ui.rs) — `docs/dev-researches/ui-kit-adoption-audit.md` §W-e «реализовать или удалить»; плюс W-e «пагинация template-строк → ScrollState»
- **Связанные задачи:** FR-039 (модаль настроек), FR-082 (колесо палитры), FR-092/097 (тач-ввод/тач-цели), W-a (скролл настроек)

## Описание

**1. Breakpoints модали настроек** (`settings_ui.rs::modal_size`):

- `< MODAL_BP_MOBILE (768)` — телефон: модаль занимает окно целиком
  (с полями `SETTINGS_MARGIN`) — стандарт мобильной модали; навигация
  остаётся колонкой (инвариант различимости навигации — тест клампа
  320×240 сохранён), скролл контента — W-a.
- `< MODAL_BP_COMPACT (1280)` — планшет/узкий десктоп: доля высоты
  0.6 → 0.75 (больше контента без скролла); ширина — прежняя.
- `≥ BP_COMPACT` — прежняя ветка бит-в-бит (тест-пин 1920×1080 и
  граница 1280 не изменились).

Панель поиска (`search_ui.rs::PANEL_WIDTH` — кламп к окну) и палитра
(`template_ui.rs:872` — `PANEL_WIDTH.min(window_w − 2·MARGIN)`) уже клампились
на узких окнах (FR-088/FR-025) — продублированы в FR-098 только документально.

**2. Drag-скролл списка палитры** (`canvas-app/src/app/input.rs`): на таче
колеса нет — длинный список шаблонов (62+) был недоступен ниже видимого окна.
Теперь нажатие на пустом месте дока (ветка «глотается» в
`click_template_panel`) запускает drag-скролл: вертикальный драг пальцем
крутит список, шаг — линия колеса 40 лог. px (тот же, что в
`on_mouse_wheel`), знак — touch-конвенция (палец вниз — контент вниз).
Приоритет: `template_drag` (драг строки-кандидат) и `long-press` не
пересекаются — скролл активен только пока флаг не сброшен
(Released/Cancel/Released кнопки мыши). Побочно тот же жест работает и
мышью (драг по пустому месту дока — скролл; прежде — ничего).

## Приёмка

- Тест `modal_size_breakpoints_mobile_and_compact`: телефон 390×844 —
  модаль ровно окно минус поля; компакт 1024×768 — высота 576 (0.75);
  граница 1280 — прежняя ветка (432).
- Полный прогон settings-тестов (16) и app/lib (495) — зелёные.
- Гейты: fmt, clippy -D warnings (натив + wasm32), test --workspace,
  wasm_gate --check.
- Ручной сценарий (телефон): Настройки на весь экран; палитра — драг
  пальцем по пустому месту крутит список; драг строки по-прежнему тянет
  шаблон на канвас.
