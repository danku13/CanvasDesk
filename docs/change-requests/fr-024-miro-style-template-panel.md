## Описание (What)

Панель шаблонов (Ctrl+P) функциональна (поиск, чипы категорий, строки,
клавиатура), но визуально — «плоская»: строки без собственных подложек
сливаются с фоном панели, панель висит у правого края на содержимой
высоте, нет шапки и секций по категориям. Требуется привести панель к
паттерну **Miro Template picker**: левый док во всю высоту окна, шапка,
поле поиска, чипы категорий, **секции по категориям** с заголовками,
строки-карточки с индивидуальной подложкой (иконка на плитке, имя,
описание), hover/выбранное состояние и футер-подсказка.

## Исследование бест-практик (Research)

Источники:

- Miro Help Center, «Templates»: Template picker открывается боковой
  панелью у левого края доски; шаблоны сгруппированы по категориям с
  заголовками секций; поиск сверху
  (https://help.miro.com — Templates / Template picker).
- Miro/Miroverse: карточка шаблона = плитка с превью/иконкой + имя +
  короткое описание; hover подсвечивает карточку (elevation).
- Общие паттерны левых доков canvas-инструментов (Figma/Miro): панель
  во всю высоту с шапкой; содержимое скроллится; фильтры-чипы под
  поиском; фон панели — плотная подложка с рамкой, отделяющая док от
  канваса; действия панели — в футере/шапке.

Применимое к CanvasDesk:

| Паттерн Miro | Статус до | Решение FR-024 |
|---|---|---|
| Док у левого края, во всю высоту | панель у правого края, высота по контенту | левый край, высота = окно − поля |
| Секции по категориям с заголовками | плоский список + чипы | `PanelRow::Section` + группировка реестра |
| Карточка шаблона с подложкой и плиткой иконки | строка без подложки | подложка-квад (radius 6) + плитка 28×28 под квад-иконкой |
| Hover/выбранное состояние | hover только на строках | подложка подсвечивается, выбранная — акцент |
| Шапка панели с названием | нет | «Шаблоны» + счётчик |
| Подсказка действий | нет | футер «Enter — вставить · Esc — закрыть» |
| Поиск сверху | есть | + placeholder «Поиск шаблонов…» |

## Влияние (Impact)

| Объект | Что меняется |
|---|---|
| `template_ui.rs` | `PanelRow` (Section/Template), группировка `panel_rows`, `row_of_ordinal`, `move_selection` по строкам с секциями, `panel_layout` — левый док во всю высоту, шапка, секции, плитки; константы |
| `main.rs` | `template_panel_overlay` — подложки/шапка/секции/карточки/футер; клавиатура и клики — через `PanelRow` |
| Доки | `user-docs/interface.md` / `templates.md` — панель слева, секции |

## Требуемые изменения (Changes)

1. **`crates/canvas-app/src/template_ui.rs`**
   - `pub enum PanelRow { Section(String), Template(usize) }`;
   - `panel_rows(registry, panel) -> Vec<PanelRow>`: при пустом фильтре
     и без чипа — группировка по категориям (порядок реестра), иначе
     плоский список совпадений;
   - `template_row_count(rows)`, `row_of_ordinal(rows, ordinal)` —
     выделение (клавиатура) нумерует ТОЛЬКО строки-шаблоны, секции —
     не цели;
   - `TemplatePanel::move_selection(delta, rows)` — окно прокрутки
     `SCROLL_WINDOW`, заголовок секции показывается над её первой
     строкой;
   - `panel_layout` — левый край (`PANEL_MARGIN`), высота
     `window_h − 2·PANEL_TOP_MARGIN`, `header_rect`, видимость строк по
     высоте панели и `MAX_VISIBLE_ROWS`;
   - `PanelLayout { header_rect, rows, … }` — параллельные
     `row_rects`/`rows`.
2. **`crates/canvas-app/src/main.rs`**
   - рендер: подложка панели (плотная, рамка, radius 8), шапка,
     поиск с placeholder, чипы (как было), секции-заголовки,
     карточки строк (подложка + плитка + иконка + имя + описание),
     футер-подсказка;
   - клики/клавиатура — сопоставление с `PanelRow`; клик по секции —
     no-op (глотается).
3. **Проверка**: юнит-тесты группировки, ординалов, прокрутки с
   секциями, геометрии левого дока; ручная приёмка — Ctrl+P: панель
   слева во всю высоту, секции, hover, Enter вставляет шаблон.

## Архитектура тестируемости (инварианты)

1. Группировка детерминирована порядком реестра; фильтр/чип отключают
   секции (плоский список).
2. Клавиатурное выделение никогда не стоит на секции (только шаблоны).
3. Все нарисованные строки лежат внутри панели (кламп по высоте).
4. WYSIWYG: клик-тест и рендер используют одни `row_rects`.
