# FR-097: Тач-цели canvas-UI ≥ 44 лог. px — hit-only расширение на coarse-указателе

- **Статус:** выполнено
- **Тип:** FR (дефект мобильного юзабилити → эргономика попадания)
- **Приоритет:** важно
- **Владелец:** агент (сессия 2026-10-03)
- **Источник:** аудит мобильной адаптации 2026-10-03; палитра/флайаут/онбординг свёрстаны под мышь (строки-карточки ~28–32 лог. px) — палец промахивается; у DOM-тулбара цели 44 px есть (CR-014), у GPU-UI не было
- **Связанные задачи:** CR-014 (тач-цели DOM ≥44px), FR-092 (глушение жестов над UI), FR-095 (`POINTER_COARSE` — общий мост)

## Описание

GPU-панели рисуются и хит-тестируются одними и теми же прямоугольниками
(hit == draw); попадание пальцем в строку-карточку высотой ~28–32 лог. px —
лотерея (Apple HIG / Material: минимум 44 pt).

Решение — **hit-only расширение**: визуалы не меняются, на coarse-указателе
hit-прямоугольник дотягивается до `MIN_TOUCH_TARGET = 44` лог. px по обеим
осям центрированно, с клампом в контейнер (прямоугольник панели/полосы) —
расширенная зона не выходит за панель и не перекрывает канвас. На точном
указателе (мышь/тачпад) расширения нет — поведение десктопа бит-в-бит прежнее.

Источник флага — `canvas_core::web_bridge::POINTER_COARSE`
(`matchMedia("(pointer: coarse)")` + листенер `change` в
`canvas-web/src/touch_platform.rs`; режим ввода может смениться —
отстегнулась мышь планшета).

Покрытые зоны hit-тестов (`canvas-app/src/app/input.rs`, `onboarding_ui.rs`):

| Зона | Элементы |
|---|---|
| Развёрнутый док палитры | строки-карточки, чипы категорий, поле фильтра, кнопка сворачивания (кламп в `panel_rect`) |
| Свёрнутая полоса + flyout | строки flyout (кламп в `fly.rect`), чипы категорий полосы (кламп в `strip.rect`) |
| Онбординг | кнопки «Далее»/«Назад»/«Пропустить» (кламп в карточку) |

Панель поиска — клавиатурная (строки не кликабельны: выбор — Enter/стрелки),
touch-хитов не имеет; кнопки-иконки витрины кита — демо-стенд, не продуктовый
UI. Вне скопа: hit-зоны шапок нод на канвасе (canvas-render cards) — отдельная
волна, если ручная приёмка покажет промахи.

## Влияние

| Объект | Что сломано | Где |
|---|---|---|
| canvas-app | попадание пальцем в строки/кнопки панелей — лотерея | `touch_targets.rs` (новое), `app/input.rs`, `onboarding_ui.rs` |
| canvas-web | признак coarse-указателя не детектился | `touch_platform.rs` |

## Приёмка

- Юнит-тесты `touch_targets.rs`: центрированное расширение xywh/xyxy (короткая
  сторона → 44, длинная без изменений), согласованность форматов, пересечение
  с контейнером (кламп у края, пустое пересечение → нули).
- Гейты: fmt, clippy -D warnings (натив + wasm32), test --workspace,
  wasm_gate --check.
- Ручной сценарий (телефон): попадание в строки палитры/флайаута и кнопки
  онбординга без прицеливания; на десктопе зоны клика не изменились
  (визуальный дифф нулевой — рисование не тронуто).

## Точки входа

- `crates/canvas-app/src/touch_targets.rs` — хелперы + тесты.
- `crates/canvas-app/src/app/input.rs` — хит-тесты палитры/полосы/flyout.
- `crates/canvas-app/src/onboarding_ui.rs` — `button_at`.
- `crates/canvas-web/src/touch_platform.rs` — детект pointer:coarse.
