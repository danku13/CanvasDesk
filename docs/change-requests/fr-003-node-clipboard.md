## Описание (What)

Нет операций дублирования и копирования-вставки нод: заметку/файловую карточку
нельзя размножить — каждую пересоздают вручную. Требуется: `Ctrl+D` — дубликат
выделенных нод рядом с оригиналами; `Ctrl+C`/`Ctrl+V` — копирование в буфер и
вставка в позицию курсора с сохранением взаимного расположения. Выявлено
пользователем.

## Влияние (Impact)

|---|---|---|
| `node` | Новые взаимодействия: Ctrl+C/V/D (латиница и кириллица), вставка на курсор | `docs/interface-objects/node.md` §4 |

| `hotkeys` (FR-004) | Новые хоткеи попадают в оверлей горячих клавиш | `docs/change-requests/fr-004-hotkeys-overlay.md` |

## Анализ (Root Cause)

- `App` (`crates/canvas-app/src/main.rs:330-469`) — поля буфера нод нет;
  `clipboard: Clipboard` (`main.rs:358`) — системный текстовый буфер для
  редактора заметок, для нод не подходит (модель `Node` не текст).
- `on_key` (`main.rs:2899`): ветки `Ctrl+C/V/D` вне редактирования отсутствуют
  (внутри `EditingSession` — `KeyCommand::Copy/Cut/Paste` над текстом, не нодами).
- Генерация id есть: `next_free_id(canvas, prefix)` (`canvas-app/src/lib.rs:304`) —
  переиспользуется для новых id вставленных нод.
- Паттерн вставки в модель есть: `create_note_at` (`main.rs:1090`) и
  `insert_group` (`main.rs:1123`) — push + `spatial.insert` + выделение + dirty.

## Требуемые изменения (Changes)

1. `canvas-app/src/lib.rs` (ui): чистые функции —
   `node_prefix(node)` (тип → префикс id), `reassign_ids(canvas, nodes)` (новые
   уникальные id), `paste_nodes(canvas, spatial, clipboard, place)` — вставка со
   сдвигом: `place::AtCursor { center, keep_offsets }` / `Offset(dx,dy)`;
   возвращает индексы вставленных.
2. `main.rs`: поле `node_clipboard: Vec<Node>`; `Ctrl+C` (лат. `c`/кир. `с`) —
   собрать выделенные ноды (CR-001: `selected_nodes` ∪ primary) в буфер;
   `Ctrl+V` (`v`/`м`) — вставка на `cursor_world()`, выборка = новые ноды;
   `Ctrl+D` (`d`/`в`) — дубликат со сдвигом `+32/+32` world-px, выборка = копии.
3. Вставка: `sync_watch_dirs()` для файловых нод (T10), `mark_dirty`, выборка
   вставленных (мульти-выделение CR-001).
4. Кириллические клавиши обязательны (паттерн `Ctrl+F`/`а`, `main.rs:2977`).

## Проверка (Verification)

- Выделить заметку → `Ctrl+D`: копия рядом (+32/+32), новый id, текст совпадает,
  оригинал не тронут, автосейв сработал.
- `Ctrl+C` на 2+ нодах → `Ctrl+V` на пустом месте: вставка центром bbox на
  курсор, взаимное расположение сохранено, id все новые.
- `Ctrl+V` без буфера — ничего не происходит (не падает).
- Дубликат группы: копируется рамка группы (дети — только если они в выделении;
  семантика v1 фиксируется в edge/node docs).
- Unit-тесты: `reassign_ids` (уникальность, префиксы), `paste_nodes`
  (смещения, spatial, грязь), кириллический маппинг клавиш.
