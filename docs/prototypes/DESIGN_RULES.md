# DESIGN_RULES.md — дизайн-правила интерфейса CanvasDesk

> Собрано в ходе создания интерактивного web-прототипа (mock-поверхности, без
> логики). Цель — зафиксировать приёмы и правила, чтобы использовать их при
> доработках самого проекта. Источники: `design/tokens/{colors,dimensions,motion}.json`,
> `crates/canvas-render/src/theme.rs`, `docs/ui-kit.md`, `docs/interface-objects/*`,
> реальные метрики модулей (`whatif_ui.rs`, `template_ui.rs`, `minimap.rs`).
> Прототип: токены перенесены в CSS-переменные (`--cd-*`) — см. §9.

---

## 1. Принципы верхнего уровня

1. **Один источник геометрии.** Размеры нод измеряются один раз (в прототипе —
   ResizeObserver + реестр `geometry.ts`); связи и hit-зоны читают те же числа.
   Правило перенесено из контракта реестра поверхностей: «ввод = тому, что видно».
2. **Ни одного цветового литерала в компонентах.** Только слоты `--cd-*`.
   Тема (тёмная/светлая) подменяет слоты, компоненты не меняются.
3. **Шкалы, а не произвольные числа.** Отступы — из spacing-scale, радиусы —
   из radius-scale, длительности — из motion-набора (см. §3–4). Новое значение
   добавляется в шкалу, а не в компонент.
4. **Прототип не считает — он показывает.** Любая интерактивность либо
   навигационная (пан/зум/перелёты камеры/открытие поверхностей), либо
   state-driven подмена (сценарии what-if меняют мок-значения).

## 2. Модель поверхностей

Экран — набор поверхностей; каждая живёт в своём слое и имеет capture-политику.

**Слои (снизу вверх):** World → WorldOverlay → Widgets → Panels → Popups →
Modals → (Drag) → Toasts → Debug.

| Слой | Что живёт | Примеры прототипа |
|---|---|---|
| World | сцена: карточки, связи, сетка, HUD | `Scene` |
| WorldOverlay | геометрия поверх мира | кольцевое меню `wheel` |
| Panels | полосы и панели по краям | палитра шаблонов, what-if бар, поиск, миникарта, панель прототипа |
| Popups | меню у курсора, боковые вьюеры | контекстное меню, docs-viewer |
| Modals | центрированные окна над затемнением | настройки, explain, stage, галерея, онбординг, дизайн-правила |
| Toasts | пассивные, не ловят ввод | тосты низ-центр |

**Правила:**
- **Esc-лестница.** Esc закрывает самую верхнюю открытую поверхность.
  Поверхности закрываются в порядке, обратном открытию (стек). Реализовано в
  `store.ts: esc()`.
- **Backdrop-контракт.** Клик по затемнению у Block-модали закрывает её;
  клики по панели «глотаются». Панели (Panels) клики мимо себя пропускают в мир.
- **Одна точка входа на поверхность.** Каждая поверхность открывается из
  ровно одного «пульта» (в прототипе — панель поверхностей) + свой нативный
  вход (хоткей/клик). Это правило резко упрощает QA.
- **Деградация вместо вырожденной геометрии.** Что-if бар прячется ниже
  900×600 (HideBelow из реестра); на узких экранах панели сужаются, а не ломаются.

## 3. Шкалы фундамента

### Spacing (5 значений, `dimensions.json`)

| Токен | Значение | Где используется |
|---|---|---|
| `s` | 6px | зазор чипов/строк, базовый gap |
| `sm` | 8px | поля таблиц, минимальная ширина лидера |
| `md` | 10px | внутренние поля баров, паддинги строк |
| `lg` | 12px | поля панелей, маржи от вьюпорта, горизонтальные поля чипов |
| `xl` | 24px | крупные поля модалей, отступ онбординг-карточки от контента |

Правило: **межэлементный зазор — `s`, внутренний паддинг — `md`/`lg`,
отступ поверхности от края вьюпорта — `lg`**. Крупнее `lg` внутри компонента —
только `xl`.

### Radius (4 значения)

| Токен | Значение | Область |
|---|---|---|
| `chip` | 6px | кнопки, чипы what-if, строки меню, свотчи |
| `card` | 8px | карточки канваса (ноды, файлы) |
| `panel` | 10px | панели и модали |
| `pill` | 12px | пилюли (сценарии, категории, метки групп, тумблеры) |

Правило: **радиус растёт вместе с площадью элемента**: чип < карточка < панель.

### Типографика (world px; 6 пар кегль/интерлиньяж)

| Роль | Кегль/строка | Применение |
|---|---|---|
| title | 16/22 | заголовок карточки (полоса 34px) |
| body | 14/20 | тело заметки, описания |
| edge label | 12/16 | подписи связей и портов |
| result | 12/16 | значения строк расчёта, футер шаблона |
| chip | 13 | подписи чипов/кнопок what-if бара |
| badge | 10/12 | бейджи (ρ, ×N, Δ), CAPS-заголовки секций |

Правило: **значения — моно/tabular-nums, выражения — пропорциональный**.
Числам всегда `font-variant-numeric: tabular-nums` (класс `.cd-mono`) —
колонки не «пляшут» при пересчёте.

### Motion (5 значений + единая кривая)

| Токен | Мс | Смысл |
|---|---|---|
| fast | 150 | hover/fade/появление поверхностей |
| flight | 300 | перелёт камеры (ease-out) |
| wave-edge | 600 | пульс ребра волны пересчёта |
| wave-step | 200 | шаг волны между рёбрами |
| pulse | 1200 | пульс результата/узкого места |

Кривая: `cubic-bezier(0.22, 0.61, 0.36, 1)`. Правило: **движение либо
функционально (волна = порядок пересчёта), либо ≤150 мс (обратная связь)**.

## 4. Цветовая система

### Семантические слоты (тёмная тема)

| Слот | # | Смысл |
|---|---|---|
| `bg` | #1e1e22 | фон канваса |
| `card` | #26262c | карточка |
| `panel` | rgba(24,27,35,.93) | панели поверхностей (blur 6px) |
| `menu` | rgba(28,28,33,.97) | меню/попапы |
| `accent` | #659cf8 | выделение, фокус, каретка, рамка диалога |
| `edge` | #8494a8 | нейтральная связь |
| `flow` | #21a88c | value-связь (бирюзовый) |
| `link` | #6cb6ff | пролитое значение, ссылки |
| `warn/danger/critical` | #f5a623 / #e5484d / #ff4530 | ρ>70% / ρ>90% / перегрузка |
| `whatif-badge` | #dfa63e | дельта-бейдж сценариев |
| `ok` | #7fd18b | успешный результат |
| `error` | #e55c5c | ошибка вычисления |
| `toast-text` | #f0e6c2 | текст тостов |

Светлая тема — не инверсия, а **свой набор слотов** (bg #f5f5f7, акцент
#3f7fe0, severity затемняются для контраста). Тема — атрибут корня
(`.cd-dark` / `.cd-light`), компоненты едины.

### Пресеты карточек 1–6

red / orange / yellow / green / cyan / purple. Тёмная тема — приглушённые
тона (текст светлый), светлая — пастели (текст тёмный): **чернила подбираются
автоматически для контраста ≥ 4.5:1** (правило CR-007). Пресет заливает карточку
целиком, рамка — полупрозрачная белая 10%.

### Акцент — один на всё

Выделение ноды, рамка диалога, каретка, чип «включено», порты, рамка группы —
всё `accent`. Дифференциация — прозрачностью (α-ступени 0.08/0.14/0.35…),
а не новыми цветами.

## 5. Сцена (канвас)

- **Сетка:** точки, мелкий шаг 24px world / крупный 120px; цвет —
  `grid-minor`/`grid-major` (белый 5%/9% на тёмном). Рисуется фоном контейнера
  (`background-size/position` = пан/зум) — бесконечность без большой DOM-ноды.
- **Камера:** пан (drag по пустому / средняя кнопка), зум к курсору
  Ctrl+колесо, диапазон 0.2×–2.5×. Перелёты (миникарта, поиск) — 300 мс ease-out.
- **LOD по зуму:** <0.45 силуэт (заголовок) → 0.45–0.7 компакт (+футер) →
  ≥0.7 полное тело → ≥0.95 порты с лейблами при hover. Смена LOD — мгновенная,
  без анимации (иначе «плывёт» при зуме).
- **Анатомия ноды:** хедер 34px (иконка 22px у шаблонов + title 16) →
  контекст-строка курсивом (≤3 строк, обрезается) → тело (строки расчёта /
  параметры) → футер результата (шаблоны). Ширина ноды задана сценой, высота —
  по контенту (репортится в реестр геометрии).
- **Строка расчёта:** `выражение ····· значение юнит`. Лидер — точечная
  линия цвета subtext, значение — mono. What-if строка: заливка
  `whatif-fill` + бейдж Δ; пролитая строка: курсив + иконка связи + `link`.
- **Связи:** plain 2px `edge`; flow 2.4px `flow` + пилюля значения
  (фон tooltip, mono 11) + анимированная точка-импульс; пучок — толщина
  3.5/4.6/5.6px по числу связей + бейдж ×N (круг 13px, акцентная рамка).
  Клик по flow-пилюле → explain; по пучку → main stage.
- **Порты:** 10px круги на рёбрах карточки; видны при hover/выделении ноды
  (opacity 0→1, 150 мс); тип порта — цветом И формой: value — сплошной
  бирюзовый, control — сплошной янтарный, unbound — пунктирный серый.
  Лейбл порта — по hover, со смещением от стороны («from:», «out:», «to:»).
- **Узкие места:** рамка карточки цветом severity + бейдж-пилюля над верхним
  краем (`ρ N%` / `OVERLOAD N%` + `Q`), критический — пульс 1.6с. Вкл/выкл —
  глобальный тумблер (Ctrl+B).
- **Группа:** пунктирная рамка `accent` 45%, заливка `accent` 8%, радиус
  `pill`, метка-пилюля на верхней кромке слева.
- **Миникарта:** 220×140, право-низ; фон полупрозрачный, ноды — цветом типа
  (текст жёлтый #e4c460, файл синий #6094e4, группа серый, битая красный),
  вьюпорт — белая рамка. Клик/drag — перелёт/панорамирование. Поднимается,
  если открыт what-if бар (bottom: 68px).

## 6. Компоненты поверхностей

- **Кнопки:** Primary (заливка `btn-primary`) / Secondary (`btn-secondary` +
  рамка `btn-border`) / Ghost (текст, hover — подложка) / Disabled (текст
  `disabled-text`, без заливки). Высота 26px, паддинг X `lg`, радиус `chip`,
  кегль 13. Hover — 150 мс.
- **Чипы:** пилюля 24px (радиус `pill`) для категорий/сценариев; выбранное
  состояние — `accent`-рамка + `accent`-текст + мягкая заливка.
- **Тумблер (pill):** 36×20, бегунок 14px, включён — заливка `btn-primary`.
- **Строки списков:** высота 24–46px (шаблоны — 46, подмены — 24); hover —
  `hover-fill`; выбранное — `selected-fill` + инсет-рамка акцента.
- **Поля ввода:** высота 32px, фон `input`, рамка `menu-border`, радиус
  `chip`; иконка поиска слева, счётчик справа.
- **Модали:** фон `dialog-fill`, рамка 1px `dialog-border` (акцент), радиус
  `panel`, тень 0 12px 40px; scrim — `stage-dim` (0.6 тёмная / 0.5 светлая).
  Появление — pop 150 мс (translateY 6px + scale 0.985 → 1).
- **Боковые панели (docs):** пристыкованы к краю, скругление только с
  внешней стороны, выезд 220 мс.
- **Тосты:** низ-центр (выше what-if бара), пилюля на tooltip-фоне, текст
  `toast-text`, TTL ~3.2с, клик — закрыть. Максимум информации — одна строка.
- **Тултипы:** фон `tooltip-bg`, рамка `tooltip-border`, кегль 10–11,
  без стрелки, по месту (лейблы портов, авто-строки, бейджи).

## 7. Паттерны взаимодействия

- **Hover-раскрытие.** Порты и лейблы появляются по hover ноды; ничего не
  «моргает» само. Время появления = `fast`.
- **Клик по цифре = проверка.** Любое вычисленное значение кликабельно и
  открывает explain-окно (в прототипе — пилюли значений на связях).
- **Каскадные подсказки состояния:** выделение → рамка+ореол; hover → рамка
  +тень; фокус-режим → остальное гаснет до 0.3 (150 мс).
- **ПКМ-дихотомия:** по ноде — контекстное меню объекта (Цвет/Раскладка/
  Действия/Ветвление), по пустому месту — кольцевое меню вставки. Меню
  открываются в точке клика, зажимаются во вьюпорт.
- **Мок-тосты вместо тумблеров логики.** Любое действие, требующее движка
  (добавить шаблон, применить сценарий), отвечает тостом «…(mock)» —
  интерфейс обещает поведение, не реализуя его.

8. Обе темы: проверить слоты на светлой — контраст текста ≥ 4.5:1.

## 9. Маппинг токенов → CSS

Токены лежат в `src/app/globals.css` (блок `.cd` / `.cd-dark` / `.cd-light`),
потребляются как `var(--cd-*)`. Ключевые семейства:

- spacing: `--cd-space-s|sm|md|lg|xl`
- radius: `--cd-radius-chip|card|panel|pill`
- typography: `--cd-font-{title,body,edge,result,hud,badge,chip}` + `--cd-line-*`
- motion: `--cd-t-fast|flight|wave-edge|wave-step|pulse`, `--cd-ease`
- цвет: `--cd-bg|card|panel|menu|input|accent|edge|flow|link|warn|danger|
  critical|whatif-badge|whatif-fill|error|ok|toast-text|…` + пресеты
  `--cd-preset-1..6`
- метрики: `--cd-card-header: 34px`, `--cd-minimap-w/h: 220/140px`

## 11. Объединённый прототип `prototype-unified.html` (слияние docs/prototypes)

> Сессия 2: все 7 прототипов `docs/prototypes` слиты в один автономный
> HTML-файл (офлайн, vanilla JS + Canvas 2D, ~3200 строк). Приоритет —
> тело ноды Н-3 «Адаптивная» (источник истины FR-069). Раздел фиксирует
> правила, по которым происходило слияние — они же правила переноса в продукт.

### 11.1 Канон, выбранный при конфликте источников

При слиянии 7 файлов их системы расходились; зафиксирован единый канон:

| Аспект | Расхождение в источниках | Канон объединённого прототипа |
|---|---|---|
| Цвет value-связи | бирюза `#31b8a6` (edge-redesign, body-fill) vs синий `#5aa2ff` (mainstage) | **бирюза** — семантика новейших прототипов и FR-050 |
| Цвет control-связи | серый `#8b8b96` vs оранжевый `#f2a44a` | **серый** |
| Unmapped | янтарь в текстах, фактически control-оранж в mainstage | **янтарь `#d9a13c`, пунктир [5,4]** — расхождение исходника устранено |
| Selection | фиолетовый `#8f7bff` (mainstage) vs синий accent | **фиолетовый** (отличим от what-if-синего) |
| Акцент what-if | синий `#4da3ff` | синий (what-if ≠ selection) |

| Якорь скрытого ряда | — | свёрнут блок → ребро якорится к **blk-hdr**, иначе к хедеру (прецедент edge-redesign) |

### 11.2 Правило переноса DOM-вёрстки на канвас

Табличная концепция тела (FR-069) перенесена с DOM на Canvas 2D по
трёхпроходной схеме продукта: **TextMeasurer → направляющие → раскладка**:

1. **Замер** (`ctx.measureText` тем же font-string, что и отрисовка):
   `valW` = max ширина значений (включая what-if «3▸ 4»), `unitW` = max
   юнитов, `bdgW` = max пилюль бейджей. Направляющие считаются **на ноду**,
   не на блок и не на сцену.
2. **Лестница деградации** (только при переполнении): текстовые бейджи →
   иконки `⇄/▸/!` (полный текст в tooltip) → ellipsis формулы. **Числа и
   юниты не деградируют никогда**; имя не усекается никогда.
3. **Раскладка**: колонки от правого края — `[бейджи][юнит][число]` с
   gap 7; лидер — пунктир от формулы до левого края числовой колонки,
   min 14px.

Правило координат (урок слияния): направляющие хранятся **относительно
левого края ноды**, а рисуются — в мировых координатах; каждый draw-сайт
обязан добавлять `n.x`. Смешение систем — источник невидимых значений.

### 11.3 Esc-лестница объединённого прототипа (7 ступеней)

```
choice-меню → drag (отмена) → ревью-диалог → защита → окно цепочки →
main stage → выделение → (ничего)
```

Правило: каждая новая поверхность встраивается В ЛЕСТНИЦУ, а не рядом;
«один оверлей одновременно» (F-10) обеспечивается взаимными close в точках
входа (`openStage` закрывает chain/review и наоборот).

### 11.4 Правила жизненного цикла рендера

- **rAF планируется в НАЧАЛЕ кадра** — исключение в любом draw не убивает
  цикл (урок: одна опечатка `s2sy` вместо `s2wy` замораживала канвас).
- Раскладка нод кэшируется по ключу состояния (`[id, w, вариант, T, fill,
  whatif, компакт, flow, blkOpen, descOpen, dataVersion]`); пан/зум кэш
  не инвалидирует.
- Мутации данных (DAU-слайдер, ±связь, Del) поднимают `dataVersion` —
  это единственный триггер пересчёта направляющих.
