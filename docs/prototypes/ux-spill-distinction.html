Почему наклонная производная

У Noto Sans Mono нет italic-начертания (Google не выпускает). Варианты: чужой курсивный моно-шрифт (чужая метрика/дизайн, 26 МБ Sarasa) — отклонён; GPU-скос глифов (glyphon не даёт per-area трансформ) — отклонён; oblique-производная fontTools (11°, авансы сохранены, имя без RFN «Noto», OFL) — выбрано: та же моно-колонка, то же выравнивание бейджей, различие читается мгновенно.
Соответствие FR-050: авто-строка приёмника — «Трафик.peak_rps = 1388.89 rps» вверху тела (зона «Переменные · входящие значения», строка-проекция Н10-а); строка параметра шаблонной ноды — rps ← Трафик · peak_rps (маркер проливания, значение — в бейдже строки); подпись у истока ребра — значение, у приёмника — короткий адрес «→ rps» (Н7); unmapped — янтарный пунктир + тултип «проблема + решение» (Р-3); what-if — янтарная подмена поверх (Р-1).
