Прототип «проверка цепочки поверх канваса» (У9 v4)

Фидбэк владельца (2026-09-22): «зачем делить экран на две стороны — канвас должен идти как в prototype-mainstage-anatomy, поверх него может открываться main stage и/или проверка цепочки расчёта цифры». Ниже — решения прототипа и открытые вопросы.

А. Решения, принятые прототипом

  1. База — движок prototype-mainstage-anatomy.html без изменений: полноэкранный канвас, камера (пан/зум), LOD, пучки, main stage, тема.
  2. Проверка цепочки = плавающее окно поверх канваса (паттерн main stage: затемнение + окно), не боковая панель — боковых панелей больше нет.
  3. Вход: клик по цифре в полосе результата ноды (У1 — фолбэк-триггер) или кнопка в панели управления — одним действием (AC-6.1).
  4. Дерево в окне — граф нод с ветками (то же представление, что и в обычном режиме); авто-раскрытие 3 уровня (FR-039), уровень 4 — источники — по бейджу/клику.
  5. Режим защиты — состояние того же окна: тумблер в шапке (AC-6.1) → ×1.5 с вписыванием в окно (AC-6.2), проза скрыта, пошаговое раскрытие уровней (AC-6.3).
  6. Esc — выход из защиты в окно; повторный Esc / ✕ / клик по фону — закрытие окна; канвас остаётся без следов (AC-6.4).
  7. Демо-данные цепочки: «Стоимость.Итог 4 687 200 ₽» → выручка (Количество · Средний_чек · Сезон) и план USD (выручка / Курсы.USD); источники — уровень 4. Для остальных нод дерево строится из их trace-строк.
  8. Взаимоисключимость: открытое окно проверки закрывает main stage (реестр модальностей, F-10).
  9. Контекст ноды (курсивные строки) на канвасе остаётся как в референсе; в дерево окна он не входит — в защите проза скрыта полностью (AC-6.2).

Б. Открытые вопросы (неоднозначно в концепции)

  1. Размер окна проверки: 70% экрана как main stage — или крупнее (сейчас 88vw/86vh)?
  2. Нужны ли зум/пан содержимого внутри окна дерева (сейчас — вписывание целиком + скролл)?
  3. Подсветка соответствующих нод на канвасе под затемнением окна — нужна (сейчас канвас просто затемнён)?
  4. Вход в проверку цифры прямо из main stage (панель «Как считается»)?
  5. Нужны ли в окне крошки и действия листов (источник/автор) — сейчас только дерево и строки источников?
  6. Проза в обычном виде окна: показывать курсивом (сейчас) или скрывать сразу?
  7. Поведение «Раскрыть всё» в защите: до уровня 4 включительно (сейчас) или только авто-лимит 3?
