Слитые решения (по прототипам)

Сцена/движок — канвас как в mainstage-anatomy (решение владельца 2026-09-22): полноэкранный канвас, оверлеи поверх, один оверлей одновременно (F-10).

Тело ноды — Н-3 «Адаптивная» рекомендовано node-tabular-body-analysis; табличная концепция 2026-09-23: направляющие невидимы, выравнивание читается по правым краям цифр и юнитов; бейджи каскада — отдельной колонкой, лестница деградации: текст → иконки (⇄/▸/!) → ellipsis формулы; числа/юниты не деградируют никогда.

Р-2 — наклонная производная моно 11° (fontTools, OFL); в прототипе — синтез браузерного italic. Маркер «←» не наклоняется.

Связи — В-C «Кромки-зона» рекомендовано node-edge-redesign-analysis: в покое портов нет; тип задаётся кромкой старта; скольжение вдоль кромки выбирает точку (между рядами — узловой уровень); drop на тело — choice-меню (Н2).

Ревью автосвязей — У8: массовые действия обратимы до закрытия («Вернуть все»); создание — одним undo-батом (AC-5.3).

Проверка цепочки — У9 v4: окно поверх канваса, граф узлов-карточек, авто-раскрытие 3 уровня (FR-039), уровень 4 — по клику; защита ×1.5 (AC-6.2), проза скрыта, пошагово (AC-6.3).

Подсказки (FR-079) — UX-канон по книгам владельца: попап не ждёт ИИ (Doherty 400 мс — skeleton занимает ожидание, таймаут 800 мс — тихий откат, Zeigarnik закрыт); максимум 3 ИИ-строки, сортировка и знакомые имена каталога (Хик); причина у каждой строки, принятое всегда редактируемо + undo одним шагом (Podmajersky); карточки C3 у свежей ноды, цепочка ≤ 2 подряд (goal gradient без навязчивости); частота ≤ 6/мин, подавление на framework-канвасах, opt-out телеметрия (Schüll/Cababa); уверенность числом не показываем (Duke) — источник и причина вместо процента.

Открытые вопросы к владельцу

1. Подсветка нод канваса под окном проверки цепочки (сейчас — без изменений, AC-6.4).

2. Текст пилюль бейджей — sans 9.5px (перенос замера на sans; FR-069, отклонение v1).

3. Ужимание высоты нод (шаг 4b) — после решения по I-6 и защите ручного ресайза (T7).

4. Семантика «закрыл ревью с отклонёнными» — вернутся через фоновую перепроверку (AC-5.5).

5. Принятие ИИ-строки заменяет редактируемую ноду (прецедент палитры) — подтвердить для текстовых нот с входящими рёбрами.

6. Карточки C3: показывать ли после принятия карточки следующую тройку (цепочка) — сейчас ≤ 2 подряд.

Выберите режим AI

CanvasDesk работает с любым режимом — поменять можно позже в настройках (9-й таб «AI and Models»).
Что отправляется. Только контекст редактируемой ноды и её соседей; числа маскируются явным маркером (price=<redacted> руб — единица сохраняется, Q1). Сами канвасы, файлы и ключи — не отправляются никогда.

Где живут ключи. BYOK-ключи — в OS keychain (desktop) / OPFS encrypted (web); OAuth-токены ChatGPT — тоже локально, бэкенд не участвует.

Телеметрия. Отключена по умолчанию; включается только явным opt-in в настройках.
