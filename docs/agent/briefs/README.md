# Brief Library

Accepted briefs as few-shot examples (plan v2.1 stage 5). The library rule:
**a brief from the library reproduces the result** — if it does not, the
brief is stale and must be fixed or retired, not ignored.

- A brief is added here after the task it produced is **accepted** (verified,
  merged), not when it is written.
- Copy the brief into the new task, adjust paths/line ranges to the current
  base commit, and keep the structure identical.
- Template — [../BRIEF-TEMPLATE.md](../BRIEF-TEMPLATE.md).
