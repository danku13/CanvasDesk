## Сводка

| # | Симптом (слова владельца, сокращённо) | Корневая причина | Документ |
|---|---|---|---|
| 1 | На этапе «шаблоны нод» только кнопка «Попробовать», дальше пройти нельзя; по кнопке открываются шаблоны схем, а не нод | FR-049 v1: CTA шага 7 (`GALLERY_TRY`) завершал тур досрочно и открывал галерею схем; до финала пользователь не доходил | CR-031 (S1) |
| 2 | Финальной стадией должно быть предложение открыть шаблонную схему или начать собирать самому | Финального выбора не было — шаг 8 рассказывал про «?» и F1, шаг 9 (UI-консоль) перегружал новичка служебным экраном | CR-031 (S1) |
| 3 | Вёрстка панели «шаблоны схем» выглядит не на ui-kit / с кривыми настройками | Оверлей галереи красит панель/чипы/строки закрывающими слотами (`menu_fill`/`palette_border`) и жёсткими радиусами 6/8/12 вместо стилей кита (`modal_style`, `RADIUS_CHIP`, `RADIUS_PANEL`) | CR-031 (S5) |
| 4 | Вёрстка онбординга: слева картинка/гифка, справа текст и кнопки — 50/50 | Карточка одноколонная 460px, иллюстраций нет вовсе (в приложении нет растровых ассетов — только шрифты и иконочные атласы) | CR-031 (S2) |
| 5 | Первое сообщение онбординга — value выбранной роли (или универсальное без роли) | `ONBOARDING_STEPS` — const с единственным телом шага 1; роль (FR-087) влияет только на фильтры категорий | CR-031 (S3) |
| 6 | Фон канваса для нового пользователя — точки средней плотности, сетка рябит | `GridStyle::#[default] Lines` (settings.rs) — дефолт эпохи v1 | CR-031 (S6) |
| 7 | Ревизия текстов: «заметки» — лишнее про текст/Ctrl+Enter/Esc; «связи» — нет двух типов связей (logical / data) | Тексты v1 писались «один шаг = одна мысль», но обросли горячими клавишами; типы связей не упомянуты вовсе | CR-031 (S4) |

## Решения (по формулировкам владельца)

- Поток: «вместо "попробовать" оставить продолжить и вести пользователя дальше по онбордингу до финальной стадии».
- Финал: «предложение открыть шаблонную схему или начать собирать схему самому, чтобы не перегружать пользователя».
- Вёрстка: «50% картинка, 50% текстовый блок с кнопками».
- Приветствие: «value для конкретной роли… либо универсальное описание value для входа без роли».
- Фон: «точки со средней плотностью».
