# UR-005 — Ревизия агент-панели (Ctrl+I): активное поле ввода, иконки, вёрстка

- **Статус:** реализовано (ожидает приёмки владельца)
- **Дата:** 2026-10-09
- **Источник:** сообщение владельца (скриншот панели Ctrl+I)
- **Реализация:** CR-034 (этапы S1–S4), коммит — см. worklog

## Формулировка владельца

> «проверь ui-kit На пример активного поля ввода, сейчас на ctrl+i оно всегда
> выглядит как неактивное, так же не отображается иконка отправки запроса, так
> же как и не отображаются иконки на панели статуса AI. на панели ctrl+i есть
> проблемы с вёрсткой (на скриншоте). сделай полную ревизию поверхности с
> учётом дизайн-концепции из design\rules и ui-kit. В поле ввода отсутствуют
> пробелы и выделение текста.»

## Диагноз (корни)

1. **Иконки ➤ ⚡ ⏸ ▶ — тофу в wasm.** Дефолт `IconStyle::Glyph`; встроенный
   сабсет `CanvasDeskSymbols-Regular.ttf` (21 символ, 2026-10-02) эти глифы не
   покрывал; в SVG-атласе имена `send`/`zap`/`pause`/`play` отсутствовали.
   Системного фолбэка в wasm нет — рисовался `.notdef`.
2. **Поле ввода всегда «неактивное».** Стиль был захардкожен
   `control_style_of(panel_fill, panel_border, …)` + `let _ = input_state` —
   ни фокус-рамки, ни каретки; трекинга фокуса не существовало.
3. **Пробелы не вводились.** winit отдаёт Space как
   `Key::Named(NamedKey::Space)`; ветка символов матчила только
   `Key::Character`. Тот же дефект — в поле поиска (T14).
4. **Выделения не было.** Каретка хранилась в байтах (`input.len()` — ломалась
   бы на кириллице), `sel`/стрелки/Home/End/Ctrl+A/C/V/X отсутствовали.
5. **Вёрстка:** empty-state — одна строка `label_left` с молчаливой обрезкой
   (скриншот: «…агент вызовет M»); чип провайдера — полное имя
   «BYOK (свой ключ)» в фикс. 100px (клип); высоты вне шкалы кита
   (поле 36, send 36×36, ✕ 22, чипы 18 против 30/26/26/24); hit-тест
   дублировал геометрию draw (класс CR-033).

## Реализация

- **S1a (атлас):** +16 SVG (`send`/`zap`/`pause`/`play` × lucide/feather/
  material/bootstrap; официальные пути, пермиссивные лицензии библиотек);
  `rasterize_icons.py` — ROOT из `__file__` (прежний захардкоженный путь
  сломался при переносе чекаута), ICON_NAMES 39→43; `icon_data.rs`
  перегенерирован (атлас 1376×160).
- **S1b (шрифт):** `scripts/extend_symbol_font.py` — 4 оригинальных
  геометрических силуэта (▶ ⏸ ⚡ ➤) в стиле соседних глифов сабсета
  (▲: 805×697 @ 907); идемпотентный запуск; лицензия файла не меняется (OFL,
  заимствований контуров нет).
- **S1c (дрейн иконок):** `agent_panel_overlay`/`ai_status_panel` возвращают
  `(quads, texts, icons)`; handler расширяет `icon_instances` (прежде иконки
  KitDraw терялись — дрейнился только `search_overlay`).
- **S2 (агент-панель):**
  - `AgentState.field: TextFieldModel` (FR-058: caret/sel в СИМВОЛАХ) +
    `input_focused`; `Ctrl+I` фокусирует поле, клик по канвасу мимо панели —
    снимает фокус, клик по Input — возвращает;
  - клавиатура: Space, стрелки/Shift, Home/End, Backspace/Delete,
    Ctrl+A/C/X/V (латиница/кириллица/control-коды), Enter/Esc; без фокуса
    панель клавиши не глотает (канвас-хоткеи работают при открытой панели);
  - рендер поля: kit `text_field()` (ellipsis, text_area, caret_x), фокус —
    рамка accent + params.y=1 (паттерн пилота TextField, design/rules 04 A4),
    выделение — подложка accent α0.25, каретка 1.5px accent;
  - `AgentPanelLayout::build` — единая геометрия draw==hit; высоты —
    константы кита (TEXT_FIELD_HEIGHT/ICON_BUTTON_SIZE/CHIP_HEIGHT), паддинги
    — SPACING_LG/SM/S (design/rules 03 S1–S3);
  - empty-state — `TextMeasurer::wrap` (перенос по реальной ширине);
  - чипы: короткая подпись провайдера (`ai_status_prov_label`, pub(super)),
    ширины по замеру (П6), context-chip с ellipsis;
  - иконки: `zap` (шапка), `close` (✕), `send` (кнопка) через `d.icon`.
- **S3 (статус-панель AI):** pause/play/gear через `d.icon` (SVG + глиф-фолбэк);
  дрейн иконок.
- **S4 (поиск):** Space в поле поиска (та же регрессия Named(Space)).
- **Бонус (находка верификации):** viewport-рамка минимапы рисовалась ПОВЕРХ
  AI-статус-панели (панель встаёт над минимапой, но minimap-pass — позже
  screen-оверлеев; тот же класс, что CR-033 №4, но для статус-панели).
  Гейт UR-003 расширен: минимапа скрывается и при видимой статус-панели.

## Верификация (headless Chromium, release-бандл trunk 0.21.14)

- ввод «cac ltv» — пробел вставляется; фокус-рамка accent + каретка видны;
- Shift+← ×3 — выделение «ltv» подложкой; ввод «z» замещает выделение;
- Enter — отправка (ответ «Провайдер Off» — черновик сохранён, legacy-поведение);
- клик по канвасу мимо панели — blur (рамка обычная, каретки нет);
- статус-панель: ⏸/⚙/чипы читаемы; белый тофу-бокс исчез после гейта минимапы;
- гейты: fmt/check/test (2756)/clippy -D warnings/wasm_gate — зелёные.
