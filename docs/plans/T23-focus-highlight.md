# T23. Динамическая подсветка связей (brainstorm-focus)

Статус: план к реализации в одной сессии (= один feat-коммит).
Источники: запрос владельца «T23 — динамическая подсветка связей
(brainstorm-focus)»; `docs/SPEC.md` §6.1/§8; `docs/TASKS.md` (T8 связи,
T14 анимации); AGENTS.md (правила качества); CONTEXT.md (глоссарий).
Базовый коммит плана: 4eaf7d7 (T8–T17 + группы/GFM/MCP влиты; T11/T12 и
T18+ вне скоупа).

Задача новая — за пределами исходной дорожной карты T0–T22 (после M5).
Регистрируется как T23 в TASKS.md (раздел «Пост-v1 расширения»).

## 1. Цель и критерии приёмки

Режим фокусировки для брейншторма: на плотном графе идей пользователь
наводит курсор на ноду — её связи и ноды-соседи подсвечиваются, остальная
сцена притемняется; контекст выбранной идеи читается мгновенно, без
поиска глазами. Переходы анимированы, подсветка «дышит» один цикл при
установлении фокуса — отклик живой, не статичный.

Критерии (формула приёмки):
- режим включается хоткеем `F` (русская раскладка — «А»), пунктом
  ПКМ-меню канваса «Фокус на связях» и строкой панели настроек
  «Фокус на связях» (сохраняется в config.toml);
- при включённом режиме hover ноды → все инцидентные связи подсвечены
  акцентным цветом и утолщены, ноды-соседи — обычной яркости, прочие
  ноды/связи/текст притемнены до ~35% яркости; переход плавный, 150 мс;
- клик по ноде (выделение) удерживает фокус после ухода курсора;
  перетаскивание ноды сохраняет подсветку её связей;
- выделенная связь (клик/ПКМ по линии) фокусирует её саму + обе ноды;
- при установлении фокуса подсвеченные связи пульсируют один цикл
  ~1.6 с (утолщение/яркость), затем — статичная подсветка;
- выключение режима (повторное F/меню/панель) плавно снимает затемнение;
- окно с 5000 нод: включённый режим фокуса не просаживает fps
  (пересчёт окрестности O(V+E) ~0.3–0.5 мс, HUD cpu_ms стабилен);
- режим работает в оконном и `--desktop` (фича платформенно-нейтральна);
- формат `.canvas` не меняется, ничего не сохраняется при переключениях.

## 2. Что уже есть (инвентарь)

| Что | Где | Значение для T23 |
|---|---|---|
| Инцидентность рёбер | `canvas-core::Canvas::edges_of(node_id)` | ядро расчёта окрестности; O(E) |
| Связи: цвет/стиль/толщина | `Edge.color/style/thickness`, `cards.rs build_edge_instances` | подсветка ложится поверх существующих дефолтов: цвет по умолчанию, толщина base_d |
| Выделенная связь | `build_edge_instances(selected)` — SELECTION_BORDER, +1 world-px | фокус не должен глушить выделение: выделение приоритетнее фокуса |
| Hover нод | `App.hovered: Option<usize>`, `on_cursor_moved` → `selective_hit` | готовый источник seed'а; перерисовка уже только при смене |
| Выделение | `App.scene.selected: Option<Selection>` (Node/Edge) | второй источник seed'а |
| Анимации-паттерн | `animate.rs` (Flight, pulse_alpha), `App.pulse`, about_to_wait держит кадры | тот же жизненный цикл: `Option<(ключ, Instant)>` + request_redraw до завершения |
| Затухание альфы | T14 пульс: overlay-квад border.a |cards.wgsl уже уважает fill.a/border.a (после фикса T14) — dim инстансов сработает сразу |
| Цвет текста | `TextArea.default_color: Color` (glyphon, u8 alpha) | затемнение текста — умножение альфы default_color |
| Контекстное меню канваса | `CANVAS_MENU_ITEMS`, `canvas_menu_label` | место пункта «Фокус на связях» с ✓ |
| Панель настроек | `SETTINGS_ROWS`, `SettingsRow`, `settings.rs` (serde default) | место строки-переключателя; старые конфиги грузятся |
| Темы | `ThemeColors` dark/light | акцент [0.396, 0.612, 0.969] един для тем — цвет подсветки тоже един |
| Тесты-паттерн | cards.rs: `edge_instances_*` (цепочки/стрелки/стили) | расширяем теми же константами |

## 3. Архитектура

Четыре зоны; все правки платформенно-нейтральны (Linux-гейты покрывают
код целиком, cfg(windows)-веток нет — CI windows подтверждает).

### Зона A — `canvas-core/src/focus.rs` (новый, чистая функция + тесты)

```rust
pub struct FocusSet {
    pub nodes: Vec<usize>,   // seed + соседи (индексы canvas.nodes)
    pub edges: Vec<usize>,   // инцидентные seed рёбра (индексы canvas.edges)
}
pub enum FocusSeed { Node(usize), Edge(usize) }
pub fn focus_set(canvas: &Canvas, seed: FocusSeed) -> FocusSet;
```

- Node: seed + все `edges_of(id)` + их противоположные концы (по id →
  индекс). Висячие рёбра (нет противоположной ноды) в набор нод не
  попадают, но само ребро подсвечивается.
- Edge: ребро + обе его ноды.
- Пустой/невалидный seed → пустой FocusSet.
- Сортировка выходных индексов — детерминизм тестов.

### Зона B — `canvas-render/src/animate.rs` (расширение, чистая математика)

```rust
pub const FOCUS_FADE_MS: u32 = 150;   // fade in/out затемнения
pub const FOCUS_PULSE_MS: u32 = 1600; // «дыхание» подсвеченных рёбер, 1 цикл
pub fn focus_fade(elapsed_ms: u32) -> f32;      // 0→1, ease-out
pub fn focus_pulse(elapsed_ms: u32) -> f32;     // sin-волна 0→1→0
```

### Зона C — `canvas-render` (cards.rs + renderer.rs + text.rs)

`SceneView` расширяется полем `focus: FocusView` (новый тип в cards.rs):

```rust
pub struct FocusView {
    pub nodes: &[usize],  // подсвеченные ноды (seed+соседи)
    pub edges: &[usize],  // подсвеченные рёбра
    pub dim: f32,         // 0 — выключено; 1 — полное затемнение прочего
    pub pulse: f32,       // фаза дыхания 0..1 (0 — нет)
}
impl Default/EMPTY.
```

- `build_edge_instances(canvas, selected, avoid, focus)`:
  фокусное ребро → акцент-цвет `FOCUS_EDGE_COLOR`, толщина
  `base_d + 1.2 + pulse * 0.8`; прочие при dim>0 → альфа ×
  `(1.0 - dim * 0.65)`; выделенное ребро рисуется как раньше
  (SELECTION_BORDER приоритетнее фокуса).
- Рендерер (z-проход карточек): нода вне `focus.nodes` при dim>0 →
  `card_instance` пост-обработка: fill.a/border.a × `(1.0 - dim * 0.65)`
  (функция `dim_instance`).
- Текст (`prepare_titles`/`TitleFrame.focus`): title/icon/body
  TextArea.default_color → альфа × тот же множитель (`dim_color`).
- Порты, резиновая линия, лейблы, миникарта — БЕЗ изменений: миникарта
  обзорная, затемнение там не нужно (зафиксировано в §8).
- `FocusView` — ссылки, владелец данных — App (per-frame пересчёт).

### Зона D — `canvas-app` (main.rs + lib.rs ui + settings.rs)

- `Settings.focus_mode: bool` (serde default false) + `SettingsRow::FocusMode`
  («Фокус на связях: вкл/выкл»), SETTINGS_ROWS 6→7.
- `CanvasMenuItem::FocusMode` (✓-галочка по состоянию), CANVAS_MENU_ITEMS
  1→2, `canvas_menu_label(item, focus_on)`.
- App: `focus_mode: bool` (из Settings при старте), `focus_dim: f32`
  (анимируемый 0..1), `focus_fade: Option<Instant>` (направление — по
  target), `focus_pulse: Option<(FocusSeedKey, Instant)>` (рестарт при
  смене seed; ключ — seed). Seed-политика: `hovered` → `Selection::Node`
  → `Selection::Edge` (чистая функция `focus_seed_of` в ui — тесты
  приоритета). Seed нет → dim плавно к 0.
- Кадр (RedrawRequested): если focus_mode — пересчитать `focus_set`
  (O(V+E), ~0.5 мс на 5k) → FocusView { dim: focus_dim, pulse: фаза };
  кэш не нужен: кадры вне изменений не генерируются.
- about_to_wait: анимации фокуса держат кадры (`focus_fade` не завершён
  или `focus_pulse` активен и seed жив) — как flight/pulse T14.
- Хоткей `F`/`а`: в on_key после search-блока (не в editing — там return
  раньше), toggle + log info.
- Переключения (F/меню/панель): `focus_fade = Some(Instant::now())`,
  target dim 0↔1; при включении — пульс-рестарт если seed уже есть.
- Драг/события, меняющие hover/selection — фокус подхватывается сам
  (per-frame), отдельной инвалидации не нужно.

## 6. Тесты

- core `focus.rs`: изолированная нода (только она), хаб 3 рёбер (все
  соседи), цепочка (1-hop, транзитные НЕ включаются), Edge-seed (ребро +
  оба конца), висячее ребро (ребро подсвечено, ноды нет), невалидный
  seed (пусто), дубли пары (дедуп индексов).
- render `animate.rs`: fade монотонен 0→1, кламп за границей; пульс 0 в
  t=0 и t=FOCUS_PULSE_MS, максимум в середине, 0 после.
- render `cards.rs`: `edge_instances_focus_*` — цвет фокусного ребра =
  FOCUS_EDGE_COLOR, толщина > base; не-фокусное при dim=1 — альфа ×0.35;
  выделенное не затронуто фокусом; dim_instance — альфа fill/border.
- app `lib.rs` (ui): `focus_seed_of` — приоритет hover > selected node >
  selected edge > None; `canvas_menu_label(FocusMode, true/false)` — ✓/без;
  `SettingsRow::FocusMode` label вкл/выкл; round-trip Settings с/без поля
  (старый конфиг без `focus_mode` грузится как false).
- Интеграционные в main.rs (#[cfg(test)]): после toggle + hover —
  кадр содержит FocusView с ожидаемым dim (там, где тестируемый каркас
  позволяет; минимум — seed-логика и настройки).

## 7. Риски и митигации

| Риск | Митигация |
|---|---|
| Per-frame пересчёт O(V+E) на 5k нод | ~0.3–0.5 мс CPU (3% кадра); кадры идут только при изменениях/анимации; мониторится HUD cpu_ms; кэш по seed+rev — если понадобится (запасной план, не в v1) |
| Бесконечный пульс гонял бы кадры вечно | пульс ровно 1 цикл 1600 мс, затем статика — паттерн T14 |
| Затемнение текста — glyphon alpha | default_color уже u8-alpha; умножение ≤ 255, кламп |
| Фокус глушит выделение | порядок приоритета: выделенное ребро/рамка рисуются по-прежнему; dim не применяется к выделенной ноде |
| Меню канваса в --desktop (T17 системное меню) | пункт добавляется в canvas-меню CanvasDesk (не системное), конфликтов нет |
| Мигание при быстром движении курсора | fade 150 мс симметричный; per-frame пересчёт — без кэшей рассинхрона |
| Старые config.toml без поля | serde `#[serde(default)]` — грузится false |

## 8. Отступления (зафиксированы решениями)

1. Миникарта не затемняется — обзорный инструмент; затемнение там
   скрывает навигационную картину (в SPEC миникарта — «обзор сцены»).
2. Пульс — один цикл, не вечная анимация: живой отклик при установлении
   фокуса без постоянного redraw (энергосбережение — задача T18).
3. Подсветка не расширяется на 2-hop: 1-hop достаточно для чтения
   контекста, 2-hop на хабах взрывает набор (транзитивный шум).
   Многошаговость достигается наведением на соседа.
4. Фокус не сохраняется в `.canvas` — рантайм-состояние просмотра,
   не данные (SPEC: раскладка — только геометрия/связи).
5. Цвет подсветки один на обе темы (акцент) — согласован с группами,
   дропом и рамкой выделения.

## 9. Ручная приёмка (Win11, обе темы)

1. F (и «А» в рус. раскладке) — включить режим: лог «фокус-режим вкл»;
   повторно — выключить, затемнение плавно уходит.
2. Hover изолированной ноды без связей — подсвечена только она, фон
   притемнён; hover хаба — все его связи акцентом, соседи читаемы.
3. Клик по ноде, увести курсор — фокус держится; протащить ноду —
   связи следуют за ней подсвеченными.
4. Клик по линии связи — линия + оба конца подсвечены, остальное
   притемнено; ПКМ по связи — меню стиля по-прежнему доступно.
5. ПКМ по пустому месту → «✓ Фокус на связях» — toggle; галочка
   отражает состояние режима.
6. Панель настроек (Ctrl+,) → «Фокус на связях: вкл» — после
   перезапуска приложения режим включён (config.toml).
7. При установлении фокуса рёбра «дышат» ~1.6 с, затем статика.
8. `--stress 5000` + F3: включить фокус, водить курсором — fps не
   просел, cpu_ms без скачка (> +1 мс к базе — дефект).
9. `--desktop`: сценарии 2–4 повторяются во встроенном канвасе.
10. Ctrl+F при включённом фокусе — поиск работает, панель читаема
    (screen-space оверлеи не затемняются).
