# Architecture Decision Records (ADR)

Каталог архитектурных решений CanvasDesk. Формат и правила ведения —
`docs/adr/adr-template.md`. Один файл = одно решение; нумерация сквозная;
отмена решения — новым ADR (заменяемому ставится статус `заменено`).

## Как читать по задаче «агентная композиция с проливанием значений»

1. Концепция и требования владельца — `docs/change-requests/cr-013-agent-architecture-composition.md`.
2. Почему композиция = поток значений (и что отвергли) — ADR-0002.
3. Как адресуются порты (имена vs индексы) — ADR-0003.
4. Каким набором MCP-инструментов агент собирает и проверяет граф — ADR-0004.
5. На чём принимается готовность (состав, связи, эталонные числа) — ADR-0005
   (Instagram MVP) и ADR-0006 (пять эталонов: system design, защита бюджета,
   P&L, value chain, unit economics).
6. Первый реализуемый шаг — `docs/change-requests/fr-029-value-ports.md`.
