# Поповер (Popover)

> **Контракт поведения компонента.** Нормативный документ контура `design/`:
> человек (владелец) читает его, чтобы понимать гарантии компонента; агент
> приводит реализацию к контракту. Расхождение кода с контрактом — задача
> на рефакторинг, а не правка контракта «под код». Источник истины по фактам:
> `crates/canvas-ui/src/component/popover.rs`. Актуализировано: 2026-10-10
> (волны T/C/L, issue #47).

## 1. Назначение
Всплывающая панель со стрелкой-указателем на якорь: раскрытие деталей контрола
без модалки (легенда цвета, мини-форма, подробности строки). Отличия от
соседей: dropdown (`crates/canvas-ui/src/component/dropdown.rs`) — выбор из
пунктов; тултип (`../use-cases/tooltip.md`) — пассивная подсказка по задержке
500 мс; поповер — интерактивное содержимое с close-on-outside-click. Спека
Wave C (`docs/dev-researches/ui-kit-deep-review-2026-10.md` §5.3.13):
«anchored_stack есть, но как отдельный компонент с arrow, state,
close-on-outside-click — отсутствует».

## 2. Анатомия и размеры
| Параметр | Значение |
|---|---|
| Контент | rect по `content_size` потребителя, x = anchor.x |
| Preferred Below | y = anchor.bottom() + 12 (стрелка 8 + зазор 4) |
| Preferred Above | y = anchor.y − 12 − content_h |
| Стрелка (arrow) | 8×6: Below — y = anchor.bottom() + 2; Above — y = anchor.y − 8 |
| Right/Left | контент вплотную к якорю (+4), стрелки нет |
| Стиль | геометрию возвращает модуль; подложка/тень — потребителем (Elevation::Sm — «default modal/popover») |

## 3. Токены (слоты KitPalette)
Модуль — чистая геометрия (`PopoverLayout`: content/arrow/arrow_side/flipped),
цвета не выбирает. Подложка и рамка — слоты панельной пары panel_fill /
panel_border из K2 (`../rules/10-components.md` §K2); alpha-варианты — только
`tint()` (K2.2); тень — Elevation::Sm. Локальные цветные литералы запрещены (П4).

## 4. Состояния
Состояний в модуле нет: open/closed — поверхность потребителя; содержимое —
контролы с матрицей ST1 (`../rules/08-states.md`). Спека §5.3.13: «State:
open/closed + close-on-outside-click handled by SurfaceRegistry (Block capture
policy)». Анимация показа — на потребителе: компонент себя не анимирует (M3.5,
`../rules/06-motion.md`).

## 5. Взаимодействие
- Открытие — контрол потребителя; раскладка — `popover()` с preferred_side;
  флип кодируется флагом `flipped` (направление стрелки рисует потребитель).
- Клик мимо поповера: поверхность Block перехватывает фон и закрывается
  (L2 `../rules/05-layering.md`: Block — «intercepts everything»).
- **Esc**: Block-поверхность участвует в Esc-стеке (L4) — верхняя модальность
  закрывается первой.
- **Клавиатура**: Tab-кольцо FocusRing по контентным rect'ам поверхности (L4).
- Клик по самому поповеру — по его контролам (ST3: press внутри + release
  внутри); фон не проводит клики ниже.

## 6. Граничные случаи
- Не помещается снизу → флип вверх; не помещается и сверху → прижатие к нижнему
  краю вьюпорта, стрелка удаляется (`UiRect::default()`), flipped = true.
- Preferred Above без места сверху → флип вниз БЕЗ повторной проверки вьюпорта
  (асимметрия веток — контракт по факту кода).
- Горизонтального клампа нет (x = anchor.x): выход за правый край — зона
  ответственности потребителя (G4: 0 выходов интерактивных rect'ов за вьюпорт).
- `show_arrow=false` → стрелка 0×0, зазор остаётся 12.
- Контент выше вьюпорта по вертикали у нижнего якоря → ветка «не помещается
  нигде», позиция прижата, размер сохраняется (не маскируется).

## 7. Где в коде
`crates/canvas-ui/src/component/popover.rs` — `popover()`, `PopoverLayout`;
тесты флипа/стрелки — в модуле (`#[cfg(test)]`). `AnchoredSide` —
`crates/canvas-ui/src/component/dropdown.rs` (121–130). Фасад —
`crates/canvas-ui/src/kit.rs` (106). Потребителей в `crates/canvas-app` нет;
секции витрины в `crates/canvas-app/src/kit_ui.rs` нет (константы `SECTION_*`
её не содержат), в реестре K1 компонента нет — долг K1.1/K4.

## 8. Что меняется при правке файла
- Логика флипа/зазоров → модуль + его юнит-тесты; G4-линт поверхностей.
- Расхождение кода: модуль ветвится по `AnchoredSide::Below/Above`, а enum в
  `dropdown.rs` определяет Right/Left/Bottom/Top — сборка `canvas-ui` сломана,
  задача рефакторинга (не правка контракта «под код»).
- Док-комментарий модуля ссылается на «Wave C §5.3.11», в спеке
  (`docs/dev-researches/ui-kit-deep-review-2026-10.md`) поповеру принадлежит
  §5.3.13 — исправление комментария в коде, задача рефакторинга.
- Capture/Esc-семантика → правка `../rules/05-layering.md`, не кода.
