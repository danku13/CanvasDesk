# Панель поиска (Search, Ctrl+F)

> **Контракт поведения компонента.** Нормативный документ контура `design/`:
> человек (владелец) читает его, чтобы понимать гарантии компонента; агент
> приводит реализацию к контракту. Расхождение кода с контрактом — задача
> на рефакторинг, а не правка контракта «под код». Источник истины по фактам:
> `crates/canvas-app/src/search_ui.rs`, `crates/canvas-app/src/app.rs`,
> `crates/canvas-app/src/app/ui_registry.rs`. Актуализировано: 2026-10-10
> (волны T/C/L, issue #47).

## 1. Назначение
Быстрый поиск по нодам/файлам канваса (FTS5): переход к ноде, подсветка
совпадений.

## 2. Анатомия и размеры (screen px)
| Параметр | Значение |
|---|---|
| Ширина панели | PANEL_WIDTH 460 (клампится к окну − 2·PANEL_SIDE_MARGIN) |
| Отступ от края | 12 (SPACING_LG, сверху-слева) |
| Высота поля | INPUT_HEIGHT = kit::TEXT_FIELD_HEIGHT 30 (LAY-W7; было 36) |
| Высота строки результата | по контенту: row_height = пад + заголовок 17 + (зазор 2 + подзаголовок 15 × строки) — замер TextMeasurer, не константа (FR-088) |
| Видимых строк максимум | MAX_VISIBLE_ROWS 8 |
| Паддинг панели | 8 (SPACING_SM) |
| Лимит результатов | SEARCH_RESULTS_LIMIT 16 |
| Дебаунс запроса | SEARCH_DEBOUNCE 200 мс |
| Слой | Panels (L3), capture = Block (мимо — закрыть и глотнуть) |

## 3. Токены
Фон панели menu_fill, поле search_input_fill + рамка palette_border (фокус —
accent), строки search_row_fill, hover — control_hover_fill, совпадение в
тексте — state.highlight (жёлтая заливка), muted-метки — DIALOG_TEXT_MUTED.

## 4. Состояния
Скрыта / открыта с пустым запросом / с результатами / без результатов
(empty-строка «ничего не найдено»).

## 5. Взаимодействие
- **Открытие**: Ctrl+F — фокус сразу в поле; повторный Ctrl+F/F3-семантика
  не дублируется; Esc — закрытие (Esc-стек).
- **Ввод**: живой поиск с дебаунсом 200 мс; результаты ≤ 16; видимых строк ≤ 8
  (скроллбар 4 px, кноб ≥ 20).
- **Переход**: клик по строке — камера летит к ноде (300 мс) + подсветка
  выделением; Enter — первый результат; ↑/↓ — навигация по списку.
- **Клик мимо панели** — закрывает и глотается (Block; backdrop-контракт).
- Смена выбора (стрелки) — превью-подсветка без перелёта; перелёт по
  Enter/клику; F3/Shift+F3 — цикл по результатам с прыжком.

## 6. Граничные случаи
- Длинный текст ноды: строка = заголовок + сниппет с подсветкой совпадения;
  ellipsis по измеренной ширине строки (панель 460 − пад).
- Найдено > 16: показываются первые 16 + метка «и ещё N» (muted).
- Панель не перекрывает угловой кластер ⚙/? (позиция сверху-слева; проверка
  G4 на пересечения с фиксированными поверхностями).

## 7. Где в коде
`crates/canvas-app/src/search_ui.rs` (28–73 константы, row_height 74),
дебаунс/лимит — `crates/canvas-app/src/app.rs` (276–278), клавиатура —
app.rs (on_search_key 5779), FTS5 — протокол `crates/canvas-core/src/search.rs`,
нативный индекс — `crates/canvas-shell/src/search.rs`, surface —
`crates/canvas-app/src/app/ui_registry.rs` (SEARCH: Panels/Block).

## 8. Что меняется при правке файла
Размеры → search_ui.rs. Лимиты/дебаунс → app.rs. Поведение Enter/Esc —
контракты клавиатуры поверхности (keyboard-scope).
