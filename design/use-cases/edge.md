# Связи (Edge)

## 1. Назначение
Связи между нодами: обычные (структурные) и value-связи (проливание
значений DAG-движком). Рисуются цепочками кружков (beads) вдоль кривой.

## 2. Анатомия и размеры (world px)
| Параметр | Значение |
|---|---|
| Сегментов на кривую | EDGE_RENDER_SEGMENTS 48 |
| Диаметр бусины | EDGE_DOT 2.5; выделенная 3.5 |
| Порт | точка 10 (PORT_DOT), максимум 26 (PORT_DOT_MAX); line-порт 7 |
| Стрелка | длина 10, угол 30°, 4 бусины на ус |
| Пунктир | период 8·диаметр, duty 0.6 |
| Стиль «точки» | шаг 3·диаметр |
| Hit-допуск | 6 screen px (или полтолщины + 2) |
| Focus-буст | +1.2 px, дыхание ±0.8 px |
| Волна проливания | бамп +1.0 px |

## 3. Токены
| Тип | Цвет |
|---|---|
| default | EDGE_DEFAULT [0.52,0.58,0.66,1] |
| value-flow | EDGE_FLOW [0.13,0.66,0.55,1] (teal) |
| draft (резина) | EDGE_DRAFT = accent α0.70 |
| broken/unmapped | BROKEN_BORDER #737373 / amber severity[0] |
| focus | ACCENT (альфа пульсирует) |
| dimmed | floor FOCUS_DIM_FLOOR 0.35 |

Зона порта: пресеты [10,14,20,28,40] screen px, кламп [10,40] (настройка).

## 4. Состояния
default / flow / draft / selected (толще 3.5) / focus (accent + breath
1600 мс) / dimmed (в режиме фокуса T23) / unmapped (amber). Приоритет
перекраски: focus > broken/amber > flow > default.

## 5. Взаимодействие
- **Создание**: drag от порта → резиновая линия к курсору; drop на порт
  другой ноды — связь; drop на пусто — отмена (или меню-выбор ноды).
- **Выбор**: клик по телу (допуск 6 px) — выделение; рамка/бусины 3.5.
- **Контекст**: правый клик — меню связи (удалить, перекрасить).
- **«Показать источник»** (FR-050 Н9-3): 2500 мс — подсветка истока/связи/
  приёмника с затемнением остального.
- **Каскад проливаний** (FR-050 Н9-1): волна по топологическим порядкам —
  ребро пульсирует 600 мс, шаг волны 200 мс.
- **Режим фокуса** (T23): не-фокусные элементы затухают до 0.35 за 150 мс,
  фокусная связь «дышит» (1600 мс).
- **Сгруппированное ребро (пучок N ≥ 2, агрегация вкл. FR-042)**:
  ВАЖНО: пучок — это N рёбер между одной упорядоченной парой нод
  `(from, to)`; агрегированная линия кодирует вес толщиной и бейджем `×N`,
  но НЕ объединяет рёбра в один объект — они остаются независимыми в
  `.canvas` и редактируются по отдельности.

  | Жест | Поведение |
  |---|---|
  | ЛКМ по пучку | Открывает main stage (AC-3.1, FR-042) — детализация: обе ноды + все рёбра веером с подписями и значениями. Внутри stage клик по ребру среза = выделение живой связи (AC-3.2). |
  | **ПКМ по пучку** | Открывает палитру связи (как для одиночного ребра): Стиль / Толщина / Цвет / Поток / Порты + доп. группа «Пучок» с действиями «Открыть main stage» (явный вход) и «Удалить ребро». Палитра таргетит конкретное ребро, возвращённое `edge_at` (ближайшее в допуске). |
  | **Alt + ЛКМ по пучку** | Байпас main stage: выделяет конкретное ребро (`Selection::Edge(edge_index)`) БЕЗ открытия stage — для drag-rebind (CR-002), удаления через Del, прямой правки. |
  | Двойной клик по пучку | Открывает main stage (лейбл-редактор у пучка неопределён — подписи отдельных рёбер видны в stage). |
  | Del после выделения (ЛКМ в stage, Alt+ЛКМ, или одиночное ребро) | Удаляет конкретное ребро из `.canvas`; undo-шаг (FR-006); downstream теряет вход (FR-014). Пучок пересчитывает вес/толщину/бейдж (AC-3.3). |
  | Esc при открытом stage | Закрывает stage; выделение ребра сохраняется (AC-3.2). |

  Правка FR-042 (сессия 2026-09-24): ранее ПКМ по пучку также открывал
  main stage, что блокировало доступ к палитре связи (стиль/толщина/цвет/
  поток/порты/удаление) — пользователь не мог редактировать сгруппированное
  ребро. Теперь ПКМ открывает палитру всегда, а stage открывается явно
  через кнопку в группе «Пучок» (или ЛКМ / двойной клик). AC-3.1 «единый
  вход» переосмыслен: входов два, но оба осознанные — ЛКМ для детализации,
  ПКМ для правки. Исходный AC-3.1 (клик = stage) сохранён для ЛКМ.

## 6. Граничные случаи
- Подпись ребра: quad-подложка [6,3] пад, кегль 12/16, edge_label_fill;
  рисуется при читаемом зуме.
- Пересечения рёбер: бусины не «сливаются» — толщина дисциплинирует
  (макс. 3.5 + бусты).
- Самопетли/циклы: отклоняются валидатором DAG (связь не создаётся).
- Зона порта мала (10): порты соседних нод не пересекаются hit-зонами
  (проверка G4 канонических сцен).

## 7. Где в коде
`canvas-render/src/cards.rs` (614–670 константы, 979+ фокус/пульс),
зоны — `canvas-core/src/edgegeom.rs` (10–30), настройки зон — settings.rs
(332–336). Токены — tokens.rs EDGE_* (42–46), dimensions.json edge.*.

## 8. Что меняется при правке файла
Геометрия бусин/стрелок/пунктиров → dimensions.json edge.* + tokens.rs.
Цвета → colors.json edge/state. Зоны хитов → edgegeom.rs (пресеты).
Анимации → motion.json (150–2500 мс).
