# Контекстное меню (Context Menu)

> **Контракт поведения компонента.** Нормативный документ контура `design/`:
> человек (владелец) читает его, чтобы понимать гарантии компонента; агент
> приводит реализацию к контракту. Расхождение кода с контрактом — задача
> на рефакторинг, а не правка контракта «под код». Источник истины по фактам:
> `crates/canvas-app/src/lib.rs`, `crates/canvas-app/src/app/overlays.rs`,
> `crates/canvas-app/src/app/ui_registry.rs`. Актуализировано: 2026-10-10
> (волны T/C/L, issue #47).

## 1. Назначение
Действия над объектом под курсором: нода (дублировать/удалить/цвет/группа),
ребро (удалить/перекрасить), пустое место (wheel/создать), выделение
(групповые выравнивания от 3 объектов).

## 2. Анатомия и размеры (screen px)
| Параметр | Значение |
|---|---|
| Ширина | MENU_WIDTH 240 (FR-080 follow-up: 170 → 240 — длинные RU-пункты) |
| Высота пункта | MENU_ITEM_HEIGHT 26 |
| Паддинг меню | MENU_PADDING 6 (SPACING_S) |
| Отступ текста | CANVAS_MENU_LABEL_X 10 (SPACING_MD; общий MENU_LABEL_X 26 — для меню с колонкой ✓) |
| Радиус | 6 (панель), пункт hover — радиус 4 |
| Заголовок choice-меню | CHOICE_MENU_TITLE_H 24 |
| Фон меню | слот menu_fill (литерал MENU_FILL — v1 legacy, не используется) |
| Hover пункта | слот control_hover_fill (литерал [0.24,0.30,0.42,0.9] — v1) |
| Слой | Popups (L4), capture = Block (клик мимо — закрыть и глотнуть) |

## 3. Токены
Фон меню — слот menu_fill; hover — слот control_hover_fill (пункты —
kit::list_rows + WidgetState, FR-060); текст body 13; разделители —
palette_border 1 px; опасные пункты (удалить) — error-текст.

## 4. Состояния
Открыто/закрыто; пункт: Normal/Hovered/Disabled (недоступное действие —
control_disabled_text, не реагирует).

## 5. Взаимодействие
- **Открытие**: правый клик по объекту; меню привязывается к курсору.
- **Выбор**: клик по пункту → действие + закрытие; hover — подсветка;
  клик по поверхности меню (паддинг) — глотается, меню остаётся открытым.
- **Клавиатура**: Esc — закрытие (через Esc-стек реестра); ↑/↓/Enter/
  цифры — v1, не пересматривалось.
- **Клик мимо** — закрытие (клик не проходит дальше — Block).
- **Вложенность**: choice-меню (цвета, выравнивания) открывается как
  подменю/панель с заголовком 24 px; глубже одного уровня не вкладывается —
  заменяется выбором в заголовке.

## 6. Граничные случаи
- У края вьюпорта: кламп по горизонтали, флип вверх по вертикали
  (clamped_menu_origin; меню целиком в границах, G4).
- Длинные подписи: ellipsis по ширине 240−2·паддинг.
- Быстрый повторный правый клик: меню переоткрывается в новой точке.
- Меню поверх модалки не открывается (модалка Block).
- Пустое меню (нет действий) не показывается.

## 7. Где в коде
`crates/canvas-app/src/lib.rs` (MENU_* 193–212; ALIGN_MIN_SELECTION 1372),
меню-оверлей — `crates/canvas-app/src/app/overlays.rs` (canvas_menu_overlay
3596), choice-меню — overlays.rs (open_choice_menu 764, отрисовка 3542) +
CHOICE_MENU_TITLE_H `crates/canvas-app/src/app.rs` (273), кламп/флип —
`crates/canvas-app/src/lib.rs` (clamped_menu_origin 1280), списки —
list_rows + ScrollState.

## 8. Что меняется при правке файла
Размеры → MENU_* константы. Состав пунктов → обработчики поверхности.
Цвета → слоты (menu_fill/control_hover_fill; MENU_FILL — v1 legacy).
