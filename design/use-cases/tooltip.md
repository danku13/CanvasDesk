# Тултип (Tooltip)

> **Контракт поведения компонента.** Нормативный документ контура `design/`:
> человек (владелец) читает его, чтобы понимать гарантии компонента; агент
> приводит реализацию к контракту. Расхождение кода с контрактом — задача
> на рефакторинг, а не правка контракта «под код». Источник истины по фактам:
> `crates/canvas-ui/src/component/dropdown.rs` (кит) и
> `crates/canvas-app/src/app/tooltip.rs` (канвас-тултипы).
> Актуализировано: 2026-10-10 (волны T/C/L, issue #47).

> Правка владельца 2026-09-26: тултипы живого канваса — на НЕПРОЗРАЧНОЙ
> подложке (α 1.0) с переносом по словам — не больше 10 слов в строке
> (прежде — голый текст с жёстким клипом 380 px: терялся на фоне канваса
> и обрезался). Реализация — `crates/canvas-app/src/app/tooltip.rs`, §7.
> (W-c уточнила: перенос — по ШИРИНЕ, «≤10 слов» — v1, снято; см. §2.)

## 1. Назначение
Короткая подсказка к контролу/бейджу без перехода в docs: назначение
иконки-кнопки, текст ошибки строки таблицы, полное значение усечённой строки
дропдауна. Тултипы живого канваса (битая ссылка T10, ошибка формулы FR-013,
лейбл порта FR-045, unmapped-ребро/проливание FR-050, усечённая формула
FR-061) — тот же облик, исполнение — screen-space полоса Popups.

## 2. Анатомия и размеры
| Параметр | Значение |
|---|---|
| Задержка показа | TOOLTIP_DELAY_MS 500 |
| Смещение от курсора | TOOLTIP_OFFSET (14, 18) |
| Перенос строк | по ШИРИНЕ: жадный перенос до бюджета TOOLTIP_MAX_TEXT_W 380 px (W-c, дефект B8; прежний клип 380 снят, «≤10 слов в строке» — v1, снято); слово шире бюджета — целой строкой |
| Подложка | НЕПРОЗРАЧНАЯ: menu_fill с α 1.0, рамка palette_border (правка 2026-09-26) |
| Паддинг | 8 × 6 (слот SPACING_S/SM) |
| Радиус | RADIUS_CHIP 6 |
| Шрифт | body 13 (канвас-тултипы, TOOLTIP_FONT) / 14 (кит), line ×1.3 |

## 3. Токены
Фон menu_fill с альфой, форсированной в 1.0 — непрозрачный (правка
2026-09-26: полупрозрачный 0.97 просвечивал фон канваса), рамка
palette_border, текст body/акцент источника. Тултип — слои
**Popups (L4)**, capture = Passive-подобный (рисуется, но клики не ловит —
тултип никогда не крадёт клик).

## 4. Состояния
Показано/скрыто. («BoolAnim fade 150 мс — focus_fade_ms» — v1, не
пересматривалось: в коде появление/скрытие мгновенные.) Единственное
«состояние» — источник (element), который запросил показ.

## 5. Взаимодействие
- Наведение на контрол и удержание 500 мс — показ. Уход курсора — скрытие
  немедленно.
- Тултип не интерактивен: наведение на сам тултип ничего не делает и его не
  закрывает (курсор «под» ним кликает дальше).
- Движение курсора внутри контрола тултип не мигает (таймер держится, пока
  курсор в hit-rect).
- Показ прерывается: кликом (скрыть), открытием попапа/модалки, сменой
  поверхности.

## 6. Граничные случаи
- У края вьюпорта: по вертикали — флип НАД курсором у нижнего края, затем
  кламп в границы (G4); по горизонтали — кламп правого края по фактической
  ширине бокса (правка 2026-09-26).
- Длинный текст: перенос по ШИРИНЕ — строка набирается до бюджета 380 px;
  высота подложки растёт по числу строк (правка 2026-09-26, W-c);
  неразрывный токен (путь без пробелов) — целой строкой, клампит только
  ширина окна; для длинного текста — docs viewer.
- Два активных тултипа разом (битая ссылка на hovered-ноде + усечённая
  формула): подложки стекаются вниз с зазором 8 (TOOLTIP_STACK_GAP =
  SPACING_SM) — прежде тексты рисовались в одну точку и накладывались.
- Несколько контролов подряд: тултип перезапускается (новый таймер), лёгкое
  «перепрыгивание» допускается без fade-задержки (v1).

## 7. Где в коде
Канвас-тултипы (подложка + перенос): `crates/canvas-app/src/app/tooltip.rs` —
wrap_width/layout_tooltips, константы TOOLTIP_* (TOOLTIP_FONT 13,
TOOLTIP_MAX_TEXT_W 380, паддинги SPACING_S/SM, стек-зазор SPACING_SM);
потребитель — `crates/canvas-app/src/app/handler.rs` (полоса Popups, блок
`main_stage.is_none()`). Кит-тултип контролов:
`crates/canvas-ui/src/component/dropdown.rs` — tooltip (82–120),
tooltip_rect_anchored (FR-UI-TOOLTIP-RECT, якорь-rect); константы
TOOLTIP_DELAY_MS/TOOLTIP_OFFSET — `crates/canvas-ui/src/component/mod.rs`
(436–438); потребители: бейджи ошибок (text.rs hover-пад +10), иконки
углового кластера, кнопки настроек.

## 8. Что меняется при правке файла
Задержка/смещение/паддинг/бюджет переноса → TOOLTIP_* константы
`app::tooltip` (канвас) или `component/mod.rs` (контролы). Политика флипа —
реализация `app::tooltip::layout_tooltips` / kit::tooltip в
`component/dropdown.rs`. Изменение «не крадёт клик» — нельзя (инвариант слои
L4). Замер ширины — TextMeasurer + глобальный `measure_font_system` в
коротком скоупе: locking-функции внутри скоупа запрещены (контракт
рекурсивного лока W3.2).
