# Тултип (Tooltip)

## 1. Назначение
Короткая подсказка к контролу/бейджу без перехода в docs: назначение
иконки-кнопки, текст ошибки строки таблицы, полное значение усечённой строки
дропдауна.

## 2. Анатомия и размеры
| Параметр | Значение |
|---|---|
| Задержка показа | TOOLTIP_DELAY_MS 500 |
| Смещение от курсора | TOOLTIP_OFFSET (14, 18) |
| Клип-ширина | 380 px (перенос строк при превышении) |
| Паддинг | 6–8 (слот SPACING_S/SM) |
| Радиус | RADIUS_CHIP 6 |
| Шрифт | body 14, line ×1.3 |

## 3. Токены
Фон menu_fill (α 0.97), рамка palette_border, текст body. Тултип — слои
**Popups (L4)**, capture = Passive-подобный (рисуется, но клики не ловит —
тултип никогда не крадёт клик).

## 4. Состояния
Показано/скрыто (BoolAnim fade 150 мс — focus_fade_ms). Единственное
«состояние» — источник (element), который запросил показ.

## 5. Взаимодействие
- Наведение на контрол и удержание 500 мс — показ. Уход курсора — скрытие
  немедленно.
- Тултип не интерактивен: наведение на сам тултип ничего не делает и его не
  закрывает (курсор «под» ним кликает дальше).
- Движение курсора внутри контрола тултип не мигает (таймер держится, пока
  курсор в hit-rect).
- Показ прерывается: кликом (скрыть), открытием попапа/модалки, сменой
  поверхности.

## 6. Граничные случаи
- У края вьюпорта: флип в противоположную сторону (политика тултипа), затем
  кламп в границы (G4).
- Длинный текст: перенос по 380 px, высота растёт; абзацы не поддерживаются
  (тултип = 1–3 строки, для длинного — docs viewer).
- Несколько контролов подряд: тултип перезапускается (новый таймер), лёгкое
  «перепрыгивание» допускается без fade-задержки (v1).

## 7. Где в коде
`canvas-ui/src/kit.rs` — tooltip (423–451), константы TOOLTIP_* (136–138);
потребители: бейджи ошибок (text.rs hover-пад +10), иконки углового кластера,
кнопки настроек.

## 8. Что меняется при правке файла
Задержка/смещение/клип → TOOLTIP_* константы. Политика флипа — реализация
kit::tooltip. Изменение «не крадёт клик» — нельзя (инвариант слои L4).
