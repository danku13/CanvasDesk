# Тултип (Tooltip)

> Правка владельца 2026-09-26: тултипы живого канваса — на НЕПРОЗРАЧНОЙ
> подложке (α 1.0) с переносом по словам — не больше 10 слов в строке
> (прежде — голый текст с жёстким клипом 380 px: терялся на фоне канваса
> и обрезался). Реализация — `canvas-app/src/app/tooltip.rs`, §7.

## 1. Назначение
Короткая подсказка к контролу/бейджу без перехода в docs: назначение
иконки-кнопки, текст ошибки строки таблицы, полное значение усечённой строки
дропдауна. Тултипы живого канваса (битая ссылка T10, ошибка формулы FR-013,
лейбл порта FR-045, unmapped-ребро/проливание FR-050, усечённая формула
FR-061) — тот же облик, исполнение — screen-space полоса Popups.

## 2. Анатомия и размеры
| Параметр | Значение |
|---|---|
| Задержка показа | TOOLTIP_DELAY_MS 500 |
| Смещение от курсора | TOOLTIP_OFFSET (14, 18) |
| Перенос строк | ≤ 10 слов в строке (wrap по словам, правка 2026-09-26; клип 380 px снят — бокс по измеренной ширине строки) |
| Подложка | НЕПРОЗРАЧНАЯ: menu_fill с α 1.0, рамка palette_border (правка 2026-09-26) |
| Паддинг | 8 × 6 (слот SPACING_S/SM) |
| Радиус | RADIUS_CHIP 6 |
| Шрифт | body 13 (канвас-тултипы) / 14 (кит), line ×1.3 |

## 3. Токены
Фон menu_fill с альфой, форсированной в 1.0 — непрозрачный (правка
2026-09-26: полупрозрачный 0.97 просвечивал фон канваса), рамка
palette_border, текст body/акцент источника. Тултип — слои
**Popups (L4)**, capture = Passive-подобный (рисуется, но клики не ловит —
тултип никогда не крадёт клик).

## 4. Состояния
Показано/скрыто (BoolAnim fade 150 мс — focus_fade_ms). Единственное
«состояние» — источник (element), который запросил показ.

## 5. Взаимодействие
- Наведение на контрол и удержание 500 мс — показ. Уход курсора — скрытие
  немедленно.
- Тултип не интерактивен: наведение на сам тултип ничего не делает и его не
  закрывает (курсор «под» ним кликает дальше).
- Движение курсора внутри контрола тултип не мигает (таймер держится, пока
  курсор в hit-rect).
- Показ прерывается: кликом (скрыть), открытием попапа/модалки, сменой
  поверхности.

## 6. Граничные случаи
- У края вьюпорта: по вертикали — флип НАД курсором у нижнего края, затем
  кламп в границы (G4); по горизонтали — кламп правого края по фактической
  ширине бокса (правка 2026-09-26).
- Длинный текст: перенос по словам — не больше 10 слов в строке; высота
  подложки растёт по числу строк (правка 2026-09-26, требования владельца);
  неразрывный токен (путь без пробелов) — целой строкой, клампит только
  ширина окна; для длинного текста — docs viewer.
- Два активных тултипа разом (битая ссылка на hovered-ноде + усечённая
  формула): подложки стекаются вниз с зазором 8 — прежде тексты рисовались
  в одну точку и накладывались.
- Несколько контролов подряд: тултип перезапускается (новый таймер), лёгкое
  «перепрыгивание» допускается без fade-задержки (v1).

## 7. Где в коде
Канвас-тултипы (подложка + перенос): `canvas-app/src/app/tooltip.rs` —
`wrap_words`/`layout_tooltips`, константы TOOLTIP_*; потребитель —
`canvas-app/src/app/handler.rs` (полоса Popups, блок `main_stage.is_none()`).
Кит-тултип контролов: `canvas-ui/src/kit.rs` — tooltip (423–451), константы
TOOLTIP_* (136–138); потребители: бейджи ошибок (text.rs hover-пад +10),
иконки углового кластера, кнопки настроек.

## 8. Что меняется при правке файла
Задержка/смещение/паддинг/лимит слов → TOOLTIP_* константы `app::tooltip`
(канвас) или `kit.rs` (контролы). Политика флипа — реализация
`app::tooltip::layout_tooltips` / kit::tooltip. Изменение «не крадёт клик» —
нельзя (инвариант слои L4). Замер ширины — TextMeasurer + глобальный
`measure_font_system` в коротком скоупе: locking-функции внутри скоупа
запрещены (контракт рекурсивного лока W3.2).
