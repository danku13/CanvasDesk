# Хлебные крошки (Crumbs)

> **Контракт поведения компонента.** Нормативный документ контура `design/`:
> человек (владелец) читает его, чтобы понимать гарантии компонента; агент
> приводит реализацию к контракту. Расхождение кода с контрактом — задача
> на рефакторинг, а не правка контракта «под код». Источник истины по фактам:
> `crates/canvas-ui/src/component/crumbs.rs`. Актуализировано: 2026-10-10
> (волны T/C/L, issue #47).

## 1. Назначение
Путь «Root → Child → Grandchild» в мета-строке шапки explain-окна
(FR-UI-CRUMBS, AC-2.3/X6): ряд чипов-крошек с политикой переполнения «хвост
важнее» — текущий фокус пути (правый край) сохраняется, корневые уровни
дропаются. Реестр K1 (`../rules/10-components.md`): строка Crumbs — ряд
крошек, переполнение take_while от правого края; правило K1.2 «не разводить
параллельные решения» относится и к крошкам (не чипы-фильтры, не Banner).

## 2. Анатомия и размеры
| Параметр | Значение |
|---|---|
| Высота крошки | CRUMB_H 18 (меньше CHIP_HEIGHT 24 — шапка окна плотнее; константа строки K1) |
| Зазор | CRUMB_GAP 4 (меньше SPACING_S 6; класс поверхностных зазоров S4, как DROPDOWN_GAP 4) |
| Ширина крошки | текст + 2·pad_x (pad_x передаёт потребитель; канон CHIP_PAD_H 8), кламп [CRUMB_W_MIN 48, CRUMB_W_MAX 148] |
| Шрифт | CRUMB_FONT_SIZE 11, семья CRUMB_FAMILY «Noto Sans Display» (CR-015) |
| Вертикаль | центр крошек в слоте (паритет explain_ui `y = meta[1] + (meta[3]−CRUMB_H)/2`) |
| «…»-крошка | тот же pad_x/CRUMB_H; ширина = замер «…» + 2·pad_x |

## 3. Токены (слоты KitPalette)
Кит отдаёт `Vec<(rect, label)>` — рисует потребитель: заливка/рамка
`Painter::rect`, текст по центру `Painter::label`. Стиль крошки —
`chip_style(state, palette)`: control_fill / control_hover_fill /
control_selected_fill, рамка control_border, текст text (таблица слотов —
`../use-cases/chip-badge.md`). Активная крошка — KitState::Selected.

## 4. Состояния
Каждая крошка — контрол матрицы ST1 (`../rules/08-states.md`); Selected —
последняя видимая (текущий фокус пути): `crumbs_active_index` возвращает
индекс последнего элемента вывода (None при пустом выводе). «…» — decoration,
не интерактивна (ST6: поймала клик → обязана иметь состояния; v1 клик по
«…» не назначен).

## 5. Взаимодействие
- Клик по крошке — переход на уровень пути (семантика потребителя); контракт
  клика — ST3: press внутри + release внутри, один раз.
- Hover — смена слота (`chip_style`); клавиатура — FocusRing поверхности,
  как у `../use-cases/button.md`.
- Клик по «…» не определён в v1 (раскрытие полного пути — задача потребителя).

## 6. Граничные случаи
- Переполнение — take_while от ПРАВОГО края (в отличие от Fit-полосы
  `../use-cases/chip-strip.md`): идём с конца, копим ширины + gap; что не
  влезло слева — дропается.
- Если дропнуто ≥ 1 крошки — prepend «…» и пересчёт: рядом с «…» берётся на
  одну крошку меньше (бюджет slot.w − ellipsis_w − gap); fallback — хотя бы
  одна крошка рядом с «…».
- Даже одна не поместившаяся крошка — показывается последняя, клип по правому
  краю слота (паритет explain_ui `w = width.min(meta_end − x)`).
- Пустой labels или slot.w ≤ 0 → пустой Vec (no-op).
- Длинный текст: кламп ширины [48, 148]; усечение хвоста — рендер
  (`TextMeasurer::ellipsis` — решение потребителя), кит геометрию не меняет.

## 7. Где в коде
`crates/canvas-ui/src/component/crumbs.rs` — `crumbs`, `crumbs_active_index`,
константы `CRUMB_*`; допуск влезания FIT_EPS 0.05
(`crates/canvas-ui/src/measure.rs`); re-export — `crates/canvas-ui/src/kit.rs`.
Потребитель: `crates/canvas-app/src/explain_ui.rs` (`crumb_rects`,
CRUMB_PAD_X, паритет констант). Секции Crumbs в витрине
`crates/canvas-app/src/kit_ui.rs` нет — бэклог W2 (K4).

## 8. Что меняется при правке файла
- Метрики → константы модуля + паритет explain_ui; CRUMB_H/CRUMB_GAP вне
  шкал S1/S3 — задокументированные значения строки K1 (не «почти шкала»).
- Смена политики дропа (например на Wrap) — правка этого контракта и кода
  одной волной; юнит-тесты модуля (`overflow_drops_left_and_prepends_ellipsis`,
  `single_crumb_always_shown`, `crumbs_vertically_centered_in_slot`) — замок.
- Цвета — только слоты K2 (K2.1); семейство/кегль — CR-015 (замер тем же
  лицом, что рендер).
