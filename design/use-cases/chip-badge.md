# Чипы и бейджи (Chip / Badge)

## 1. Назначение
- **Чип** — компактный интерактивный маркер-фильтр/тег: чипы категорий
  галереи схем, чипы what-if сценариев в баре, чипы фильтров палитры.
- **Бейдж** — неинтерактивный индикатор состояния: severity-бейджи строк
  таблицы тела, дельта-бейджи what-if, пилюли бейджей FR-069.

## 2. Анатомия и размеры
| Элемент | Значение |
|---|---|
| Чип высота | CHIP_HEIGHT 24 |
| Чип гориз. паддинг | CHIP_PAD_H 8 |
| Чип радиус | RADIUS_CHIP 6 (категорийные пилюли галереи — RADIUS_PILL 12) |
| Бейдж (пилюля) | высота = size·1.1 + 6; заливка ≈12 % тона, рамка ≈55 % |
| Бейдж шрифт | badge 10/12 (screen px) |
| Чип what-if | шрифт 13, паддинг 12, высота 26 (whatif-бар) |

## 3. Токены
| Случай | Слоты |
|---|---|
| Чип фильтра normal/hover/selected | control_fill / control_hover_fill / control_selected_fill; рамка control_border; текст text |
| What-if чип активный | WHATIF_CHIP [0.30,0.55,0.95,1] |
| What-if чип приглушённый | WHATIF_CHIP_DIM #242A33 |
| Дельта-бейдж | WHATIF_BADGE #DFA63E |
| Severity-бейджи | таблицы tokens.state.severity (dark/light) + text «none» [154,154,162] |
| Результат-бейджи пилюли | BadgeTone Delta/Error (kit.rs, капсула h/2) |

## 4. Состояния
Чип — контрол (полная матрица ST1). Бейдж — decoration (не пикется), кроме
бейджа ошибки строки таблицы: он имеет hover-зону (+10 px пад) с тултипом.

## 5. Взаимодействие
- Чип фильтра: клик — переключение выбора (одиночный выбор в галерее,
  множественный — в палитре); hover — слот.
- What-if чип: клик — выбор активного сценария; ✕ (иконка 28) — удаление
  сценария (через диалог confirm, danger-семантика).
- Драг what-if чипа между «сценариями» не поддерживается v1.
- Бейдж ошибки строки: hover — тултип с текстом ошибки (500 мс).

## 6. Граничные случаи
- Длинный текст чипа: ширина из TextMeasurer; переполнение ловится линтом G4
  (не маскируется); для what-if чипов — обрезка ellipsis по max-ширине бара.
- Прогон зебры таблицы: бейджи не влияют на ширину колонок — колонки задаются
  RowGuides по всем строкам ноды (max), бейдж-колонка = текст + 2·ROW_BADGE_PAD_H.
- Много чипов в баре: ряд Wrap, высота бара растёт (BAR_HEIGHT 44 базово).

## 7. Где в коде
`canvas-ui/src/kit.rs` — CHIP_HEIGHT/CHIP_PAD_H, `chip_style` (360),
RowParts/бейджи (1013–1390); what-if чипы — `whatif_ui.rs` (CHIP_*,
INDICATOR_WIDTH 78); галерейные пилюли — `scheme_gallery_ui.rs` (CHIP_W 108,
CHIP_ALL_W 56, CHIP_H 28).

## 8. Что меняется при правке файла
- Высоты/паддинги → константы соответствующих модулей (единый прогон линтов
  G4 по трём вьюпортам обязателен).
- Цвета → слоты; severity-таблицы → tokens.rs + colors.json (паритет I-5).
