# Дока палитры шаблонов (Template Palette Dock)

> **Контракт поведения компонента.** Нормативный документ контура `design/`:
> человек (владелец) читает его, чтобы понимать гарантии компонента; агент
> приводит реализацию к контракту. Расхождение кода с контрактом — задача
> на рефакторинг, а не правка контракта «под код». Источник истины по фактам:
> `crates/canvas-app/src/template_ui.rs`, `crates/canvas-app/src/palette.rs`,
> `crates/canvas-app/src/app/ui_registry.rs`. Актуализировано: 2026-10-10
> (волны T/C/L, issue #47).

## 1. Назначение
Закрепляемая боковая панель каталога шаблонов: поиск, категории, список
шаблонов; drag шаблона на канвас. Складывается в тонкую полосу-стрип.

## 3. Токены
Фон menu_fill, рамка palette_border, поле search_input_fill, чипы категорий
palette_chip_fill/palette_selected, тайлы palette_tile, hover
palette_hover_fill, текст body/edge_label. Иконки шаблонов — текстурные
(assets), 18 px.

## 4. Состояния
Свёрнут (стрип) / раскрыт (док) / flyout показан; строка: Normal/Hovered/
Selected; drag шаблона: призрак в слое Drag (L6).

## 5. Взаимодействие
- **Раскрытие**: клик по кнопке стрипа — док; повторный клик — сворачивание.
- **Flyout**: hover на кнопке стрипа 150 мс — всплывающий список (закрытие
  через 300 мс после ухода курсора).
- **Поиск**: живой фильтр по названию; категории — чипы-фильтры (множ.
  выбор).
- **Создание**: drag строки шаблона на канвас (порог 4 px) → drop = создание
  ноды; клик по строке — создание в центре видимой области.
- **Клавиатура**: ↑/↓ — по строкам, Enter — вставить, Esc — свернуть фильтр/
  закрыть flyout.

## 6. Граничные случаи
- Шаблонные ноды несут чип категории в шапке и иконку 16 px (FR-075; см.
  `card.md`).
- Длинные названия: ellipsis по ширине строки 52−пад; полное — тултип.
- Док не перекрывает what-if бар (оба снизу не сходятся: док слева, бар
  снизу-центр; пересечения ловит G4).
- Узкое окно: док скрывается по HideBelow (деградация вместо сжатия).

## 7. Где в коде
`crates/canvas-app/src/template_ui.rs` (95–134 константы дока, 614–641
стрип/flyout, задержки 843–845, drag-порог 440), элементы стрипа —
`crates/canvas-app/src/palette.rs` (59–94 PAL_*, задержки выделения
972–976), каталог — canvas-core/templates.rs, surface —
`crates/canvas-app/src/app/ui_registry.rs` (TEMPLATE_PANEL/TEMPLATE_STRIP).

## 8. Что меняется при правке файла
Размеры/задержки → template_ui.rs/palette.rs. Цвета → palette_* слоты темы.
Состав категорий — каталог шаблонов (canvas-core), не этот файл.
