# Выпадающее меню (Dropdown)

## 1. Назначение
Выбор одного значения из списка: селекты настроек (тема, плотность сетки,
зона портов), выбор сценария what-if. Открывается от кнопки-якоря.

## 2. Анатомия и размеры
| Параметр | Значение |
|---|---|
| Зазор до якоря | DROPDOWN_GAP 4 |
| Высота строки | 26 (настройки: dropdown rows 26; кнопка-якорь 170×24) |
| Паддинг меню | 6 (контекстные: MENU_PADDING 6) |
| Ширина | от якоря; минимальная ширина = ширина якоря |
| Радиус | RADIUS_PANEL 10 (панель меню), строки — без радиуса |
| Скроллбар | SCROLLBAR_WIDTH 4, кноб ≥ 20 (если строк > видимых) |

## 3. Токены
Фон меню = menu_fill (α 0.95–0.97 через слот), рамка palette_border, строка
normal = прозрачная, hover = control_hover_fill, selected = control_selected_fill,
текст = body, заголовок-метка = text_muted. Тень/обводка — palette_border
(тени-блюров в системе нет).

## 4. Состояния
Открыто/закрыто; строка: Normal/Hovered/Selected/Disabled. Меню живёт в
слое **Popups (L4)**, capture = Capture (клики по строкам ловит, мимо —
пропускает вниз, при этом клик мимо закрывает меню — контракт якоря).

## 5. Взаимодействие
- **Открытие**: клик по кнопке-якорю. Повторный клик по якорю — закрытие.
- **Выбор**: клик по строке — выбор + закрытие; hover — подсветка строки.
- **Клавиатура**: ↑/↓ — перемещение по строкам, Enter — выбор, Esc —
  закрытие без выбора (Esc-стек снимает меню первым).
- **Tab** — уходит из меню (FocusRing поверхности), меню закрывается.

## 6. Граничные случаи
- **Флип**: не хватает места снизу — меню открывается вверх (anchor+flip в
  kit::dropdown_menu). Не хватает в обе стороны — прижимается к краю
  вьюпорта (кламп, G4).
- Длинные значения: ellipsis в строке, полное значение — в тултипе.
- Много строк: видимая высота ограничена (≈8 строк), скролл с кнобом.
- Открытие под Block-поверхностью (модалка настроек): menu рисуется в своей
  полосе внутри клипа модалки; клики мимо строк глотаются модалкой.

## 7. Где в коде
`canvas-ui/src/kit.rs` — dropdown_menu (389–409), DROPDOWN_GAP (135);
потребители: `settings_ui.rs` (dropdown button 170×24, rows 26),
what-if выбор сценария (list 480, rows 24).

## 8. Что меняется при правке файла
Высота строки/зазор → константы kit.rs/settings_ui. Политика флипа/клампа —
реализация kit::dropdown_menu (поведение, не токены). Цвета — слоты.
