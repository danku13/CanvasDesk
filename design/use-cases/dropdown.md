# Выпадающее меню (Dropdown)

> **Контракт поведения компонента.** Нормативный документ контура `design/`:
> человек (владелец) читает его, чтобы понимать гарантии компонента; агент
> приводит реализацию к контракту. Расхождение кода с контрактом — задача
> на рефакторинг, а не правка контракта «под код». Источник истины по фактам:
> `crates/canvas-ui/src/component/dropdown.rs`.
> Актуализировано: 2026-10-10 (волны T/C/L, issue #47).

## 1. Назначение
Выбор одного значения из списка: селекты настроек (тема, плотность сетки,
зона портов), выбор сценария what-if. Открывается от кнопки-якоря.

## 2. Анатомия и размеры
| Параметр | Значение |
|---|---|
| Зазор до якоря | DROPDOWN_GAP 4 |
| Высота строки | 26 (настройки: DROPDOWN_ROW_H = kit::LIST_ROW_H 26; кнопка-якорь 170×24) |
| Паддинг меню | 6 (контекстные: MENU_PADDING 6 = SPACING_S) |
| Ширина | от якоря; минимальная ширина = ширина якоря |
| Радиус | RADIUS_PANEL 10 (панель меню), строки — без радиуса |
| Скроллбар | SCROLLBAR_WIDTH 4, кноб ≥ 20 (если строк > видимых) |

## 3. Токены
Фон меню = menu_fill (α 0.95–0.97 через слот panel_fill), рамка
palette_border/panel_border, строка normal = прозрачная, hover =
hover_fill, selected = selected_fill, текст = body, заголовок-метка =
text_muted. Тень/обводка — palette_border (тени-блюров в системе нет).
Кит-компонент Dropdown (Wave T) красит меню хромой панели (panel_style).

## 4. Состояния
Открыто/закрыто; строка: Normal/Hovered/Selected/Disabled. Меню живёт в
слое **Popups (L4)**, capture = Capture (клики по строкам ловит, мимо —
пропускает вниз, при этом клик мимо закрывает меню — контракт якоря).

## 5. Взаимодействие
- **Открытие**: клик по кнопке-якорю. Повторный клик по якорю — закрытие.
- **Выбор**: клик по строке — выбор + закрытие; hover — подсветка строки.
- **Клавиатура**: ↑/↓ — перемещение по строкам, Enter — выбор, Esc —
  закрытие без выбора (Esc-стек снимает меню первым).
- **Tab** — уходит из меню (FocusRing поверхности), меню закрывается.

## 6. Граничные случаи
- **Флип**: не хватает места снизу — меню открывается вверх (anchor+flip в
  kit::dropdown_menu). Не хватает в обе стороны — прижимается к нижнему
  краю вьюпорта (кламп, G4); финальная гарантия — viewport_clamp.
- Длинные значения: ellipsis в строке, полное значение — в тултипе.
- Много строк: видимая высота ограничена (≈8 строк), скролл с кнобом.
- Открытие под Block-поверхностью (модалка настроек): menu рисуется в своей
  полосе внутри клипа модалки; клики мимо строк глотаются модалкой.

## 7. Где в коде
`crates/canvas-ui/src/component/dropdown.rs` — dropdown_menu (40–69) +
Dropdown-компонент (FR-068 W3); DROPDOWN_GAP —
`crates/canvas-ui/src/component/mod.rs` (440); потребители: `settings_ui.rs`
(DROPDOWN_BTN_W 170 × DROPDOWN_BTN_H 24, строки DROPDOWN_ROW_H 26),
what-if выбор сценария (`whatif_ui.rs` — LIST_WIDTH 480, строки
kit::LIST_ROW_H 26; ранее 24).

## 8. Что меняется при правке файла
Высота строки/зазор → константы component/mod.rs/settings_ui. Политика
флипа/клампа — реализация dropdown_menu в `component/dropdown.rs`
(поведение, не токены). Цвета — слоты.
