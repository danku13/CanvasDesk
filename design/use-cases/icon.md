# Иконки (Icon)

> **Контракт поведения компонента.** Нормативный документ контура `design/`:
> человек (владелец) читает его, чтобы понимать гарантии компонента; агент
> приводит реализацию к контракту. Расхождение кода с контрактом — задача
> на рефакторинг, а не правка контракта «под код». Источник истины по фактам:
> `crates/canvas-ui/src/component/icon.rs` и
> `crates/canvas-ui/src/component/button.rs` (глифовые).
> Актуализировано: 2026-10-10 (волны T/C/L, issue #47).

## 1. Назначение
Глиф-иконки кита — текстовые символы юникода, а не спрайты: ✕, ⚙, ?, ⌕, +,
←/→, ↻ (закрыть/настройки/помощь/поиск/добавить/навигация/обновить) —
рисуются шрифтом (TextMeasurer); вторая система — векторные квад-иконки
палитры (`icon.rs`, FR-UI-ICON): IconKind → Vec<PaintItem>, слот 18×18.

## 2. Анатомия и размеры
| Параметр | Значение |
|---|---|
| Иконка-кнопка | ICON_BUTTON_SIZE 26×26 |
| Кегль глифа | 12–14 (по высоте кнопки) |
| Угловой кластер ⚙/тема/? | SETTINGS_BUTTON 36, margin 12 (SPACING_LG), gap 8 (SPACING_SM) |
| Иконка ноды | TEMPLATE_ICON_SIZE 16 (полоса категории 6) |
| Иконка дока палитры | PAL_ICON 18 |

## 3. Токены
Цвет — слот icon (темы) / text для инлайн-глифов; hover — слот контрола;
векторные — tint потребителя (слот), Swatch — заливка пресета.

## 4. Состояния
Как у кнопки (ST1); иконка без кнопки-обёртки состояний не имеет.
Кликабельная иконка = кнопка (hit-rect 26/36), некликабельная — decoration.

## 5. Взаимодействие
- Клик — контракту кнопки-обёртки; тултип обязателен для всех иконок без
  подписи (500 мс).
- ⚙ — настройки (Ctrl+,), ? — help/docs, тема — цикл dark/light/пресет, ⌕ — фокус поиска.

## 6. Граничные случаи
- Отсутствующий глиф в шрифте — не рисуется (пустая кнопка) — запрещено:
  новый глиф = проверка покрытия шрифта (маппинг icon_glyph/icon_name полон).
- Иконка в disabled-кнопке — control_disabled_text.

## 7. Где в коде
Глифовые — `crates/canvas-ui/src/component/button.rs` (enum Icon +
icon_glyph/icon_name, SVG-атлас `assets/icons/<set>/<name>.svg`); векторные —
`crates/canvas-ui/src/component/icon.rs` (IconKind → icon_composition);
угловой кластер — `crates/canvas-app/src/lib.rs` (SETTINGS_* 236–330);
иконки шаблонов — `crates/canvas-render/src/cards.rs` (TEMPLATE_ICON_SIZE),
док палитры — `crates/canvas-app/src/palette.rs` (PAL_ICON 94).

## 8. Что меняется при правке файла
Новый глиф → Icon в `component/button.rs` (+ проверка шрифта, тултип); новая
векторная иконка → IconKind в `component/icon.rs` (1:1 — I-1); размеры →
константы модулей.
