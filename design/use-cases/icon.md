# Иконки (Icon)

## 1. Назначение
Глиф-иконки кита — текстовые символы юникода, а не спрайты: ✕ (закрыть/удалить),
⚙ (настройки), ? (помощь), ⌕ (поиск), + (добавить), ←/→ (навигация), ↻
(обновить). Рисуются шрифтом (TextMeasurer), а не текстурами.

## 2. Анатомия и размеры
| Параметр | Значение |
|---|---|
| Иконка-кнопка | ICON_BUTTON_SIZE 26×26 |
| Кегль глифа | 12–14 (по высоте кнопки) |
| Угловой кластер ⚙/тема/? | SETTINGS_BUTTON 36, margin 12, gap 8 |
| Иконка ноды | TEMPLATE_ICON_SIZE 16 (полоса категории 6) |
| Иконка дока палитры | PAL_ICON 18 |

## 3. Токены
Цвет иконки — слот icon (темы) / text для инлайн-глифов; hover — слот
контрола. Кликабельная иконка = кнопка (иконка + hit-rect 26/36), некликабельная
— decoration.

## 4. Состояния
Как у кнопки (ST1). Иконка без кнопки-обёртки состояний не имеет.

## 5. Взаимодействие
- Клик — контракту кнопки-обёртки; тултип обязателен для всех иконок без
  подписи (500 мс).
- ⚙ — настройки (Ctrl+,), ? — help/docs, тема — переключение
  dark/light/пресет (цикл по клику), ⌕ — фокус в поле поиска.

## 6. Граничные случаи
- Отсутствующий глиф в шрифте — не рисуется (пустая кнопка) — запрещено:
  все глифы кита проверены в шрифтах; новый глиф = проверка покрытия шрифта.
- Иконка в disabled-кнопке — control_disabled_text.

## 7. Где в коде
`canvas-ui/src/kit.rs` — Icon глифы (939–971); угловой кластер —
`canvas-app/src/lib.rs` (163–177 SETTINGS_*); иконки шаблонов — cards.rs
(332–340).

## 8. Что меняется при правке файла
Новый глиф → kit.rs Icon + проверка шрифта + тултип-контракт. Размеры →
константы соответствующих модулей.
