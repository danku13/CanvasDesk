# Минимапа (Minimap)

## 1. Назначение
Навигационная карта канваса в углу экрана: обзор сцены, рамка видимой
области, быстрый переход.

## 2. Анатомия и размеры (screen px)
| Параметр | Значение |
|---|---|
| Размер | MINIMAP_W 220 × MINIMAP_H 140 |
| Отступ от угла | MARGIN 16 |
| Радиус | 8 (RADIUS_CARD) |
| Рамка вьюпорта | 2 px |
| Рёбра на карте | только при ≤ 500 нод |
| Слой | Panels (L3), capture = Capture |

## 3. Токены
Фон menu_fill (полупрозрачно), рамка palette_border, ноды card_fill,
выделенная — accent, вьюпорт-рамка title/body. Содержимое статично по цветам
(не тематизируется поверх тем).

## 4. Состояния
Свернута (не рисуется — v1 не имеет toggle) / видима / активный drag.

## 5. Взаимодействие
- **Клик по карте** — перелёт камеры в точку (camera_flight 300 мс, ease-out).
- **Drag** — непрерывное панорамирование (без полёта, прямое слежение).
- **Drag рамки вьюпорта** — изменение зума/области (v1: если реализовано).
- Колесо поверх минимапы — зум канваса (как над миром).

## 6. Граничные случаи
- > 500 нод: рёбра скрываются (читаемость), ноды остаются точками.
- Пустая сцена: карта пуста, рамка вьюпорта по центру.
- Малый вьюпорт: минимапа держит margin 16; при нехватке места скрывается
  (HideBelow-политика поверхности).

## 7. Где в коде
`canvas-render/src/minimap.rs` (18–30 константы); surface-декларация —
`app/ui_registry.rs` (Panels/Capture); переходы — animate.rs (полёт 300 мс).

## 8. Что меняется при правке файла
Размеры/отступы → minimap.rs. Порог 500 → константа minimap.rs. Поведение
кликов — app.rs (панорамирование), длительность полёта — motion.json.
