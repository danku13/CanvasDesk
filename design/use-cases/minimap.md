# Минимапа (Minimap)

> **Контракт поведения компонента.** Нормативный документ контура `design/`:
> человек (владелец) читает его, чтобы понимать гарантии компонента; агент
> приводит реализацию к контракту. Расхождение кода с контрактом — задача
> на рефакторинг, а не правка контракта «под код». Источник истины по фактам:
> `crates/canvas-render/src/minimap.rs`, `crates/canvas-render/src/minimap_pass.rs`,
> `crates/canvas-app/src/app/stage.rs`. Актуализировано: 2026-10-10
> (волны T/C/L, issue #47).

## 1. Назначение
Навигационная карта канваса в углу экрана: обзор сцены, рамка видимой
области, быстрый переход.

## 2. Анатомия и размеры (screen px)
| Параметр | Значение |
|---|---|
| Размер | MINIMAP_W 220 × MINIMAP_H 140 |
| Отступ от угла | MINIMAP_MARGIN 16 |
| Радиус | 8 (CORNER_RADIUS) |
| Рамка вьюпорта | 2 px (VIEWPORT_FRAME_PX) |
| Рёбра на карте | только при ≤ 500 нод (MAX_NODES_FOR_EDGES) |
| Слой | Panels (L3), capture = Capture |

## 3. Токены
Статичный набор MINIMAP_* токенов (не тематизируется поверх тем): фон
MINIMAP_BG (полупрозрачный), контур MINIMAP_BORDER, ноды по роду —
MINIMAP_NODE_FILE / TEXT / GROUP / BROKEN, рёбра MINIMAP_EDGE,
вьюпорт MINIMAP_VIEWPORT (белая, непрозрачная).

## 4. Состояния
Свернута (не рисуется — v1 не имеет toggle) / видима / активный drag.

## 5. Взаимодействие
- **Клик по карте** — центрирование камеры в точку (set_center,
  мгновенно; камера-полёт 300 мс остался у поиска, не у минимапы).
- **Drag** — непрерывное панорамирование (world-точка следует за курсором).
- **Drag рамки вьюпорта** — изменение зума/области (v1, не пересматривалось).
- Колесо поверх минимапы — зум канваса (как над миром).

## 6. Граничные случаи
- > 500 нод: рёбра скрываются (читаемость), ноды остаются точками.
- Пустая сцена: карта пуста, рамка вьюпорта по центру.
- Малый вьюпорт: минимапа держит margin 16; при нехватке места скрывается
  (HideBelow-политика поверхности).

## 7. Где в коде
`crates/canvas-render/src/minimap.rs` (константы 18–32, цвета-токены 36–50);
GPU-квад — `crates/canvas-render/src/minimap_pass.rs` (T13-B); surface —
`crates/canvas-app/src/app/ui_registry.rs` (MINIMAP: Panels/Capture);
клик/drag — `crates/canvas-app/src/app/stage.rs` (click_minimap 2059,
center_camera_on_minimap_cursor 488).

## 8. Что меняется при правке файла
Размеры/отступы → minimap.rs. Порог 500 → константа minimap.rs. Поведение
кликов — stage.rs (центрирование/панорамирование), цвета — tokens.rs
MINIMAP_*.
