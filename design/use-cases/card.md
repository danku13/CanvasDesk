# Карточка ноды (Node Card)

> **Контракт поведения компонента.** Нормативный документ контура `design/`:
> человек (владелец) читает его, чтобы понимать гарантии компонента; агент
> приводит реализацию к контракту. Расхождение кода с контрактом — задача
> на рефакторинг, а не правка контракта «под код». Источник истины по фактам:
> `crates/canvas-render/src/cards.rs`, `crates/canvas-render/src/text.rs`,
> `crates/canvas-render/src/row_grid.rs`, `crates/canvas-app/src/lib.rs`.
> Актуализировано: 2026-10-10 (волны T/C/L, issue #47).

## 1. Назначение
Главная сущность канваса: файл-карточка (Numi-лист/заметка/виджет/шаблон).
Содержит заголовок, тело (проза/таблица значений), порты, результат-футер.

## 3. Токены
fill = card_fill; рамка selected = accent; broken = #737373; группа:
group_fill/group_border (accent α0.08/0.40 dark, α0.10/0.50 light);
заголовок title 16/22, тело body 14/20, результат result 12/16 (моно);
секционные пунктиры AutoRowBg/AutoRowDash (амбер); severity-таблицы dark/light;
explain_leaf — дерево расчёта. Пользовательские цветные заливки — text через
auto-contrast (`rules/04-contrast-a11y.md §A2`).

## 4. Состояния
| Состояние | Проявление |
|---|---|
| Обычная | card_fill, без рамки |
| Selected | рамка accent (приоритет 1) |
| Broken | рамка #737373 (приоритет 2) |
| В группе | полупрозрачная accent-заливка/рамка (приоритет 3) |
| Severity (LOD) | рамка серьёзности: zoom ≥ 0.25; бейджи: effective zoom ≥ 0.6; ring растит карточку на GROW 3 |
| Цветной пресет «1–6» | dark: muted / light: pastel |
| Виджет-нода | прозрачная карточка, accent-полоса hover на хедере (CR-004); битый пакет — серая карточка-плейсхолдер |

## 5. Взаимодействие
- **Мышь**: клик — выделение (рамка accent); drag — перемещение (порог 4 px);
  угол 16 px — resize; двойной клик — вход в редактор заголовка/тела
  (500 мс & ≤5 px).
- **Порты**: hover — точка растёт (10→26 по зоне); drag от порта — резиновая
  связь (draft accent α0.70); drop на порт — создание связи; дубликаты/циклы
  валидируются (DAG).
- **Таблица тела**: клик по заголовку блока — сворачивание (150 мс); клик
  «⋯ целиком ▾» — раскрытие клампа описания; hover бейджа ошибки — тултип.
- **Клавиатура (редактор)**: Enter/Ctrl+Enter — коммит, Shift+Enter —
  перенос, Esc — отмена; Ctrl+B/I/H — разметка; undo 50.
- **Контекстное меню** (правый клик): дублировать (+32,32), удалить, цвет,
  групповые операции от 3 выделенных (ALIGN_MIN_SELECTION 3).

## 6. Граничные случаи
- Мин. ширина 160: заголовок ellipsis, клип = w − 2·TITLE_PADDING − резервы
  (чип категории/иконка файла); физ. кегль < 4 px — заголовок не рисуется.
- Прилипание: сетка 20/100, допуск 6 screen px по умолчанию (пресеты
  [4,6,8,12,16], snap).
- Проливание значения: результат появляется в футере + пульс рамки
  (pulse_result, 1200 мс); каскад — волна рёбер (600/200 мс).
- Свернутый блок: Σ-строка скрыта; refit высоты по контенту (рост-only
  автоматом, ужимание — вне v1, I-6).

RowParts — `crates/canvas-ui/src/component/row.rs`. Взаимодействие:
`crates/canvas-app/src/lib.rs` (MIN_NODE_* 215–216, SELECT_DRAG_THRESHOLD 706,
DUPLICATE_OFFSET 845, ALIGN_MIN_SELECTION 1372), порты/зоны —
`crates/canvas-core/src/edgegeom.rs` (10–16). Токены: `crates/canvas-core/src/tokens.rs`
(CARD_*, TABLE_*, SEVERITY_*).

## 8. Что меняется при правке файла
Размеры → tokens.rs + dimensions.json (паритет I-5). Цвета/состояния →
01-colors/08-states. Поведение кликов → app.rs (контракты хитов) + G4-линт.
