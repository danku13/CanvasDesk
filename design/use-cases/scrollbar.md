# Скроллбар (ScrollBar)

> **Контракт поведения компонента.** Нормативный документ контура `design/`:
> человек (владелец) читает его, чтобы понимать гарантии компонента; агент
> приводит реализацию к контракту. Расхождение кода с контрактом — задача
> на рефакторинг, а не правка контракта «под код». Источник истины по фактам:
> `crates/canvas-ui/src/component/list.rs`.
> Актуализировано: 2026-10-10 (волны T/C/L, issue #47).

## 1. Назначение
Прокрутка переполненных списков/панелей: галерея схем (видимое окно строк),
дропдауны, docs viewer, настройки.

## 2. Анатомия и размеры
| Параметр | Значение |
|---|---|
| Ширина трека | SCROLLBAR_WIDTH 4 (docs viewer: 6, DOCS_SCROLLBAR_W) |
| Мин. длина кноба | SCROLLBAR_KNOB_MIN 20 |
| Длина кноба | viewport/content × трек (пропорция) |
| Радиус кноба | RADIUS_CHIP 6 (капсула; кит List — w/2) |
| Зазор трека до контента | 2–4 px |

## 3. Токены
Трек — прозрачный (не рисуется как полоса). Кноб — слот scrollbar_thumb
(docs viewer, FR-070) / control_border (кит List, радиус w/2); hover/drag-
дифференциации в ките нет («control_fill hover → control_hover_fill,
drag — accent» — v1, не пересматривалось). Никаких стрелок-кнопок.

## 4. Состояния
Скрыт / виден / drag. Автопоявление только при переполнении (needs_scroll);
исчезает при достаточной высоте контента.

## 5. Взаимодействие
- **Drag кноба** — прямое скроллирование (пропорционально).
- **Колесо** над списком — скролл без наведения на кноб (шаг = строка × 3).
- **Клик по треку** — страница вверх/вниз (не «к краю»).
- Клавиатура: ↑/↓ — по строкам, PgUp/PgDn — по страницам (в рамках
  keyboard-scope поверхности).

## 6. Граничные случаи
- Контент чуть больше вьюпорта: кноб не мельче SCROLLBAR_KNOB_MIN 20.
- Списки с фиксированной видимой высотой (галерея ROW_H 62 × N): скролл
  целыми строками, «полустроки» не показываются (кит list_rows включает
  частичные строки краёв — K3; целые строки — политика поверхности).
- Тонкий кноб (4 px) трудно попасть: drag-зона кноба расширяется до 12 px
  (hit ≥ визуал, A3), трек-клик — по всей ширине полосы.

## 7. Где в коде
`crates/canvas-ui/src/component/list.rs` — ScrollState/list_rows/scroll_bar
(17–106), List-компонент (paint — только бегунок); константы SCROLLBAR_* —
`crates/canvas-ui/src/component/mod.rs` (457–459); docs viewer —
`crates/canvas-app/src/docs_ui.rs` (DOCS_SCROLLBAR_W 6, close —
kit::stage_close_button), thumb слотом scrollbar_thumb — `app/overlays.rs`
docs_overlay; списки контекстных меню — list_rows + ScrollState (app.rs).

## 8. Что меняется при правке файла
Ширины/мин. кноб → SCROLLBAR_* в `component/mod.rs`. Шаг колеса — константы
поверхности. Расширение hit-зоны — A3 (не ломает «hit ≥ визуал»).
