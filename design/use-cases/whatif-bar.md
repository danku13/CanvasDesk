# What-if бар (сценарии)

> **Контракт поведения компонента.** Нормативный документ контура `design/`:
> человек (владелец) читает его, чтобы понимать гарантии компонента; агент
> приводит реализацию к контракту. Расхождение кода с контрактом — задача
> на рефакторинг, а не правка контракта «под код». Источник истины по фактам:
> `crates/canvas-app/src/whatif_ui.rs`,
> `crates/canvas-app/src/app/ui_registry.rs`,
> `crates/canvas-core/src/whatif.rs`. Актуализировано: 2026-10-10
> (волны T/C/L, issue #47).

## 1. Назначение
Режим сценариев «что если» (FR-017/053/064): создание сценариев, подмены
значений, сравнение с базой. Нижняя панель режима + пилюля входа.

## 3. Токены
Фон бара menu_fill (α 0.97), строка сценария WHATIF_FILL [0.30,0.55,0.95,0.22],
активный чип WHATIF_CHIP, приглушённый WHATIF_CHIP_DIM #242A33, дельта-бейдж
WHATIF_BADGE #DFA63E; disabled-текст кнопок #8A909C (control_disabled_text).
Индикатор и дельты — токен-слоты, не литералы.

## 4. Состояния
- Вне режима: пилюля «What-if» bottom-center (клик — вход Ctrl+Shift+I).
- В режиме: бар с индикатором, чипами сценариев, кнопками; без сравнения /
  сравнение открыто (таблица).
- Чип: активный / приглушённый (неактивный сценарий) / hover / ✕.

## 5. Взаимодействие
- **Вход/выход**: Ctrl+Shift+I (кириллица — «Ш») или пилюля; ✕ бара / Esc
  (верхний scope) — выход.
- **Сценарии**: «+» — новый сценарий (авто-имя, тост CR-016); клик чипа —
  активный сценарий; ✕ чипа — удаление (confirm-диалог, заморозка
  одноимённого снимка снимается; персистентно, один undo-шаг).
- **Сброс — полный** (CJM-фикс, docs/dev-researches/whatif-scope-cjm-analysis.md):
  confirm-диалог → удалить ВСЕ сценарии с подменами + снять все заморозки,
  персистентно в `.canvas` одним undo-шагом; активация → «База»; текст нод
  не меняется (инвариант 2). Гейт кнопки — есть хоть один сценарий или
  заморозка. Скоуп сценариев — весь канвас (не схема).
- **Подмены**: в редакторе ноды значения помечаются в сценарий; раскрытый
  список подмен (480) — правка/удаление подмены (✕ 22).
- **Заморозка**: кнопка «Заморозить/Разморозить» активного сценария
  (FR-064 P2) — pinned-снимок значений.
- **Сравнение**: кнопка «Сравнить» — таблица «переменная | База | С1 | С2» с
  downstream-дельтами; pinned-снимки; имена персистентны.
- **Клавиатура**: Tab — цикл по контролам бара; Enter — Apply; Esc —
  закрыть раскрытый список → выйти из режима (ступенчато).

## 6. Граничные случаи
- Много чипов: переполнение — политика SqueezeTail (сжатие хвоста по
  измеренной ширине), высота бара фиксирована 44; «ряд Wrap с ростом
  высоты» — v1, не пересматривалось.
- Окно < 900×600: бар И пилюля скрываются (единый HideBelow-гейт
  WHATIF_DEGRADATION), режим остаётся активным.
- Тяжёлый пересчёт: на воркере (FR-064), UI отвечает ≤ 2 кадров; деградация
  — sync + warn, идентичный результат.
- Клик по канвасу в режиме — обычная работа с нодами (Capture только по
  hit-rect'ам бара).

## 7. Где в коде
`crates/canvas-app/src/whatif_ui.rs` (константы 40–91, выше — цитаты), бар/чипы —
`crates/canvas-app/src/app/overlays.rs` (whatif_overlay 378, сборка кадра L3),
сценарии — canvas-core/whatif.rs + воркер canvas-scene (FR-064), MCP —
whatif_* инструменты (9 шт., skills синхронизированы). Токены — colors.json
state.whatif_*.

## 8. Что меняется при правке файла
Размеры → whatif_ui.rs (значения обязаны оставаться на spacing-scale).
Цвета → colors.json + tokens.rs. Порог скрытия → WHATIF_DEGRADATION в
ui_registry.rs. Клавиши → HOTKEYS + user-docs/hotkeys.md.
