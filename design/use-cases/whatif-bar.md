# What-if бар (сценарии)

## 1. Назначение
Режим сценариев «что если» (FR-017/053/064): создание сценариев, подмены
значений, сравнение с базой. Нижняя панель режима + пилюля входа.

## 2. Анатомия и размеры (screen px)
| Параметр | Значение |
|---|---|
| Маржа/паддинг бара | BAR_MARGIN 12 (LG) / BAR_PADDING 10 (MD) |
| Высота бара | BAR_HEIGHT 44 |
| Пилюля входа | PILL 104×30, bottom-center |
| Чип сценария | CHIP_HEIGHT 26, пад 12, шрифт 13 |
| Зазор элементов | BAR_GAP 6 (S) |
| Индикатор «WHAT-IF» | INDICATOR_WIDTH 78 |
| Кнопки Apply/Сброс/Сравнить | мин. BTN_WIDTH 74 (пад 12), ✕ 28 |
| Раскрытый список подмен | LIST_WIDTH 480, строки 24, ✕ строки 22 |
| Таблица сравнения | строки 24, шапка 26, колонка 190, поля 8 |
| Деградация | скрыт ниже 900×600 (HideBelow) |
| Слой | Panels (L3), capture = Capture |

## 3. Токены
Фон бара menu_fill (α 0.97), строка сценария WHATIF_FILL [0.30,0.55,0.95,0.22],
активный чип WHATIF_CHIP, приглушённый WHATIF_CHIP_DIM #242A33, дельта-бейдж
WHATIF_BADGE #DFA63E; disabled-текст кнопок #8A909C (control_disabled_text).
Индикатор и дельты — токен-слоты, не литералы.

## 4. Состояния
- Вне режима: пилюля «What-if» bottom-center (клик — вход Ctrl+Shift+I).
- В режиме: бар с индикатором, чипами сценариев, кнопками; без сравнения /
  сравнение открыто (таблица).
- Чип: активный / приглушённый (неактивный сценарий) / hover / ✕.

## 5. Взаимодействие
- **Вход/выход**: Ctrl+Shift+I или пилюля; ✕ бара / Esc (верхний scope) —
  выход.
- **Сценарии**: «+» — новый сценарий (авто-имя, тост CR-016); клик чипа —
  активный сценарий; ✕ чипа — удаление (confirm-диалог).
- **Подмены**: в редакторе ноды значения помечаются в сценарий; раскрытый
  список подмен (480) — правка/удаление подмены (✕ 22).
- **Сравнение**: кнопка «Сравнить» — таблица «переменная | База | С1 | С2» с
  downstream-дельтами; pinned-снимки; имена персистентны.
- **Клавиатура**: Tab — цикл по контролам бара; Enter — Apply; Esc —
  закрыть раскрытый список → выйти из режима (ступенчато).

## 6. Граничные случаи
- Много чипов: ряд Wrap, высота бара растёт вверх (тосты поднимаются +26).
- Окно < 900×600: бар скрывается целиком (деградация), режим остаётся
  активным (индикатор в HUD).
- Тяжёлый пересчёт: на воркере (FR-064), UI отвечает ≤ 2 кадров; деградация
  — sync + warn, идентичный результат.
- Клик по канвасу в режиме — обычная работа с нодами (Capture только по
  hit-rect'ам бара).

## 7. Где в коде
`canvas-app/src/whatif_ui.rs` (константы 13–68, выше — цитаты), бар/чипы —
app.rs (сборка кадра L3), сценарии — flow/scenario worker (FR-064), MCP —
whatif_* инструменты (9 шт., skills синхронизированы). Токены — colors.json
state.whatif_*.

## 8. Что меняется при правке файла
Размеры → whatif_ui.rs (значения обязаны оставаться на spacing-scale).
Цвета → colors.json + tokens.rs. Порог скрытия → SurfaceDecl HideBelow в
ui_registry.rs. Клавиши → HOTKEYS + user-docs/hotkeys.md.
