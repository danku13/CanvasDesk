# Радиальное меню шаблонов (Wheel Menu)

> **Контракт поведения компонента.** Нормативный документ контура `design/`:
> человек (владелец) читает его, чтобы понимать гарантии компонента; агент
> приводит реализацию к контракту. Расхождение кода с контрактом — задача
> на рефакторинг, а не правка контракта «под код». Источник истины по фактам:
> `crates/canvas-app/src/template_ui.rs`, `crates/canvas-render/src/sectors.rs`,
> `crates/canvas-app/src/app/overlays.rs`. Актуализировано: 2026-10-10
> (волны T/C/L, issue #47).

## 1. Назначение
Быстрое создание нод из каталога шаблонов вокруг точки канваса: кольцо
категорий → кольцо шаблонов выбранной категории → хаб.

## 2. Анатомия и размеры (screen px)
| Параметр | Значение |
|---|---|
| Толщина кольца | WHEEL_RING_THICKNESS 68 |
| Зазор колец | WHEEL_RING_GAP 8 |
| Зазор секторов | WHEEL_SECTOR_GAP 0.0436 rad (2.5°) |
| Мин. дуга сектора | WHEEL_MIN_SECTOR_ARC 60 px (из неё выводится вместимость кольца) |
| Секторов на кольцо | максимум WHEEL_RING_CAP 6; больше — концентрические под-кольца |
| Хаб | радиус 24 (D 48, WHEEL_HUB_D — сенсорная цель ≥ 44) |
| Отступ от краёв | WHEEL_SCREEN_MARGIN 8 |
| Текст шаблона | 2 строки, кегль 11, слот WHEEL_TPL_TEXT_W 64 px (перенос по измеренной ширине — CR-015) |
| Кегли | категории 12, шаблоны 11 (2 строки), хаб 10 |

## 3. Токены
Дим-диск WHEEL_DIM [0,0,0,0.35]; сектор категории WHEEL_CATEGORY
[0.17,0.18,0.22,0.92]; сектор шаблона WHEEL_TEMPLATE [0.20,0.22,0.27,0.92];
hover/активный хаб WHEEL_HOVER [0.18,0.29,0.48,0.95]; рамка WHEEL_BORDER.
Прозрачности 0.90–0.95 обязательны — под меню виден канвас. Слой
WorldOverlay (L1) для секторов + поверхность WHEEL (Block): пока меню
открыто, глотается любой клик — мимо секторов «рядом» глотается,
заметно дальше (extent + 12) — закрытие.

## 4. Состояния
Закрыто / открыто (категории) / раскрыта категория (шаблоны) / hover сектора /
активный хаб. Hover сектора — заливка WHEEL_HOVER, без анимационных переходов
(мгновенно).

## 5. Взаимодействие
- **Открытие**: Shift+клик по пустому месту канваса (FR-018; нода/связь
  под курсором обрабатываются как обычно).
- **Выбор категории**: клик по сектору внешнего кольца — раскрытие
  внутреннего кольца шаблонов (hover только подсвечивает).
- **Выбор шаблона**: клик по сектору шаблона — создание ноды в точке
  открытия (world-точка инстанциации); drag от сектора — v1, не
  пересматривалось (не реализовано).
- **Хаб**: клик — «назад» (сброс категории) или «закрыть», если категория
  не выбрана (FR-022); подпись «закрыть» / крошка «← имя».
- **Клавиатура**: Esc — закрытие; цифры/стрелки — v1, не пересматривалось.
- **Указатель**: hover сектора подсвечивает и его подпись (обе строки).

## 6. Граничные случаи
- > 6 категорий: кольцо капится WHEEL_RING_CAP 6 — остальные раскладываются
  концентрическими под-кольцами (внешние вместительнее; план сбалансирован:
  10 → [5,5], 15 → [5,5,5]).
- Мало места у края: колесо клампится к вьюпорту с margin 8; сектор может
  уходить под край экрана только частично (мин. 60 px дуга видна).
- Длинные названия шаблонов: перенос на 2 строки по измеренной ширине
  слота 64 px (CR-015; строки, не влезающие в слот, переносятся, не
  клипаются).
- Меню поверх модалки не открывается (модалка Block глотает клик).

## 7. Где в коде
Геометрия/константы — `crates/canvas-app/src/template_ui.rs` (1258–1287
WHEEL_*, кольца/сектора/хит 1355–1440), отрисовка —
`crates/canvas-app/src/app/overlays.rs` (wheel_overlay 3390+) + GPU-проход
секторов `crates/canvas-render/src/sectors.rs` (SDF, `shaders/sectors.wgsl`),
цвета — `crates/canvas-core/src/tokens.rs` WHEEL_* (102–112), клики —
`crates/canvas-app/src/app/input.rs` (click_wheel_menu 1793).

## 8. Что меняется при правке файла
Радиусы/кольца/кегли → WHEEL_* константы. Цвета → colors.json wheel.* +
tokens.rs (паритет). Максимум категорий — константа кольца (архитектурно
связано с каталогом шаблонов).
