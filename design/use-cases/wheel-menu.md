# Радиальное меню шаблонов (Wheel Menu)

## 1. Назначение
Быстрое создание нод из каталога шаблонов вокруг точки канваса: кольцо
категорий → кольцо шаблонов выбранной категории → хаб.

## 2. Анатомия и размеры (screen px)
| Параметр | Значение |
|---|---|
| Толщина кольца | WHEEL_RING_THICKNESS 68 |
| Зазор колец | WHEEL_RING_GAP 8 |
| Зазор секторов | 0.0436 rad (2.5°) |
| Мин. дуга сектора | 60 px |
| Категорий максимум | 6 на кольцо |
| Хаб | радиус 24 (D 48) |
| Отступ от краёв | 8 |
| Текст шаблона | ≤ 15 символов (2 строки, кегль 11) |
| Кегли | категории 12, шаблоны 11 (2 строки), хаб 10 |

## 3. Токены
Дим-диск WHEEL_DIM [0,0,0,0.35]; сектор категории WHEEL_CATEGORY
[0.17,0.18,0.22,0.92]; сектор шаблона WHEEL_TEMPLATE [0.20,0.22,0.27,0.92];
hover/активный хаб WHEEL_HOVER [0.18,0.29,0.48,0.95]; рамка WHEEL_BORDER.
Прозрачности 0.90–0.95 обязательны — под меню виден канвас. Слой
WorldOverlay (L1) для секторов + Capture-поверхность на время показа
(клики вне секторов глотаются, пока меню открыто).

## 4. Состояния
Закрыто / открыто (категории) / раскрыта категория (шаблоны) / hover сектора /
активный хаб. Hover сектора — заливка WHEEL_HOVER, без анимационных переходов
(мгновенно).

## 5. Взаимодействие
- **Открытие**: правый клик по пустому месту канваса (или хоткей контекста).
- **Выбор категории**: клик/наведение сектора внешнего кольца — раскрытие
  внутреннего кольца шаблонов.
- **Выбор шаблона**: клик по сектору шаблона — создание ноды в точке
  открытия; drag от сектора — создание + сразу перенос (drag-порог 4 px).
- **Хаб**: клик — закрытие без выбора; показывает контекст (координаты/режим).
- **Клавиатура**: Esc — закрытие; цифры 1–6 — выбор категории (если задано
  контекстом); стрелки — цикл по секторам.
- **Указатель**: hover сектора подсвечивает и его подпись (обе строки).

## 6. Граничные случаи
- > 6 категорий: ринг капится (6) — остальные через повторный вход из хаба
  выбранной группы (каталог структурируется под 6).
- Мало места у края: колесо клампится к вьюпорту с margin 8; сектор может
  уходить под край экрана только частично (мин. 60 px дуга видна).
- Длинные названия шаблонов: ellipsis на 15 символах, полное имя — тултип.
- Меню поверх модалки не открывается (модалка Block глотает правый клик).

## 7. Где в коде
Геометрия/константы — `canvas-app/src/template_ui.rs` (823–843 WHEEL_*),
отрисовка — app.rs (7833–7967), цвета — tokens.rs WHEEL_* (93–103),
drag-порог — template_ui.rs (285, 4 px).

## 8. Что меняется при правке файла
Радиусы/кольца/кегли → WHEEL_* константы. Цвета → colors.json wheel.* +
tokens.rs (паритет). Максимум категорий — константа кольца (архитектурно
связано с каталогом шаблонов).
