# Переключатель (Switch)

> **Контракт поведения компонента.** Нормативный документ контура `design/`:
> человек (владелец) читает его, чтобы понимать гарантии компонента; агент
> приводит реализацию к контракту. Расхождение кода с контрактом — задача
> на рефакторинг, а не правка контракта «под код». Источник истины по фактам:
> `crates/canvas-ui/src/component/button.rs`.
> Актуализировано: 2026-10-10 (волны T/C/L, issue #47).

## 1. Назначение
Бинарный toggle в настройках (settings modal): вкл/выкл опций без
промежуточных значений. Используется там, где чекбокс неуместен визуально.

## 2. Анатомия и размеры
| Параметр | Значение |
|---|---|
| Трек | SWITCH_W 36 × SWITCH_H 20 |
| Радиус трека | RADIUS_PILL 12 (капсула) |
| Кноб | диаметр = SWITCH_H − 2·SWITCH_KNOB_PAD = 16 |
| Кноб-пад | SWITCH_KNOB_PAD 2 |
| Сдвиг кноба | W − H = 16 px между крайними положениями |
| Компакт-вариант настроек | — (W-c: PILL_* удалены; settings_ui использует kit-метрики SWITCH_* через control_rect/pill_knob_rect) |

## 3. Токены
- Трек off: control_fill, рамка control_border.
- Трек on: control_primary (акцент-родственный слот).
- Кноб: fill = text_title (гарантированный контраст против обоих треков —
  правило кита, а не произвольный белый); disabled — disabled_text.

## 4. Состояния
Полная матрица ST1: Disabled > Pressed > Hovered > Selected(off/on — это
value, не KitState.Selected) > Normal. Кит значение on/off не анимирует
(M3/K1.3 — переход мгновенный); v1-формулировка «BoolAnim (0..1), 150 мс» не
пересматривалась — анимация кноба возможна только на стороне потребителя
(dt-детерминизм M2).

## 5. Взаимодействие
- **Мышь**: клик по треку = toggle (клик-контракт press+release внутри).
- **Клавиатура**: участие в FocusRing; Space/Enter — toggle; рамка фокуса
  accent.
- Изменение значения применяется к настройкам сразу (без «Сохранить»),
  persistence — контракту settings (canvas-core::settings).

## 6. Граничные случаи
- Disabled: не тогглится, кноб — disabled_text, текст подписи
  control_disabled_text.
- Узкий слот (compact): отдельных деформаций нет (W-c: PILL_TRACK 34×18
  удалён — настройки на kit-метриках); деформация = правка кита, не
  локальный литерал.
- (v1, не пересматривалось) потребительская анимация обрывается вводом —
  состояние скачком = целевое (без откатов); кит-переключение мгновенно.

## 7. Где в коде
`crates/canvas-ui/src/component/button.rs` — switch (240–291); константы
SWITCH_* — `crates/canvas-ui/src/component/mod.rs` (462–466); inline-вариант —
`settings_ui.rs` (control_rect/pill_knob_rect над kit-метриками; прежние
PILL_* удалены волной W-c).

## 8. Что меняется при правке файла
Размеры → SWITCH_* в `component/mod.rs` (компакт-вариант настроек — те же
kit-метрики). Цвет трека on → слот control_primary (правка через
`rules/01-colors.md §C7`, не локально).
