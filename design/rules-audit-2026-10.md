## 2. Пробелы правил — чего НЕ хватает (обратный аудит)

Приоритет: **P1** — правила, без которых новые компоненты строятся «по
вкусу»; **P2** — консистентность документации; **P3** — фиксация v2-планов.

- **B1 (P1). 11 компонентов кита без поведенческих контрактов.**
  Use-cases есть у 10 «старых» сущностей (button, chip-badge, text-field,
  switch, dropdown, tooltip, toast, modal-dialog, scrollbar, icon + канвас).
  Компоненты волн FR-058/FR-068/FR-UI-* контрактов не имеют:
  `banner`, `chat_bubble`, `crumbs`, `footer`, `list` (+ScrollState),
  `panel_header`, `radio_card`, `row` (частично покрыт T3-7/S6), `table`,
  `two_column`, `icon`-композиции (частично в icon.md). → Закрывается новым
  файлом `design/rules/10-components.md` (реестр + анатомия + состояния +
  токены каждого) с последующим дроблением в use-cases по мере споров.
- **B2 (P1). Реестр слотов KitPalette не зафиксирован.** 19 слотов
  (panel_fill … rule_color) нигде в правилах не перечислены; семантика
  success/warning/scrollbar_thumb/rule_color известна только из комментариев
  кода. → Дописан в `10-components.md §K2` + ссылки из TH6.
- **B3 (P2). Alpha-tint слота — неописанное исключение из slot-only.**
  `paint.rs::tint` (подмена альфы слота константой из C2) используется
  banner/radio_card/chat_bubble. П4/C8 трактовать буквально — нарушение.
  → В П4/C8 внесено: alpha-tint слота разрешён, rgb-подмена/умножение — нет.
- **B4 (P2). C2 не содержала реально используемую альфу 0.38** (рамки
  chat-bubble). Внесена в ступени (фиксация используемого набора — дух C2).
- **B5 (P2). T2 не знала шкалы UI-оверлеев `ui_typography`** (18/13/11/10),
  на которой стоит половина кита, и T5 запрещал «вне шкалы». Дописана.
- **B6 (P2). S3 не знала высот шапок панелей S/M/L** (PANEL_HEADER_H_*)
  и не фиксировала живые отклонения (галерея 40, explain 56, autolink 58).
  Дописано; отклонения оформлены задачами бэклога W1.
- **B7 (P2). TH3 счётчик «36» устарел (37), TH4/TH6 не знают слотов FR-070.**
  Исправлено.
- **B8 (P2). ST2 противоречила button_style по Pressed.** Исправлено
  (правило приведено к факту; отдельный pressed-слот — осознанный v2).
- **B9 (P2). A4 противоречила IN2 по Enter/Esc** (пункт про
  Enter/Ctrl+Enter/Shift+Enter описывает инлайн-редактор заметки ноды, не
  kit-поля). Уточнено.
- **B10 (P3). S2 не разделяла радиус карточки (10, FR-075) и минимапы (8).**
  Исправлено.
- **B11 (P3). G3: перечень проверяемых контраст-пар живёт только в тестах**
  theme.rs/theme_presets.rs. Правило A1 ссылается на «машину по каждой теме»
  без состава пар. → Задача: приложить перечень пар в A1 (низкий приоритет,
  при следующей правке контраст-машины).
- **B12 (P3). M3 не фиксирует статичность кита** (компоненты кита не
  анимируют; длительности M1 — на стороне потребителя). Дописано.
