# 05 — Слои и перехват ввода

> Код: `crates/canvas-ui/src/layer.rs`, `capture.rs`, `registry.rs`,
> `hit.rs`, `keyboard.rs`. Гайд: `docs/ui-kit.md`.

## L1. Девять фиксированных полос отрисовки

| Слой | Что живёт | Примеры |
|---|---|---|
| L0 World | канвас | карточки, рёбра, сетка |
| L1 WorldOverlay | оверлеи мира | секторы wheel-меню, гиды прилипания, пульс what-if |
| L2 Widgets | инлайн-элементы мира | текстовые поля в нодах, порты |
| L3 Panels | закреплённые панели | what-if бар, дока палитры, поиск, настройки, help |
| L4 Popups | всплывающие | тултипы, дропдауны, контекстные меню, flyout |
| L5 Modals | модальные | онбординг, галерея, диалоги, main stage |
| L6 Drag | перетаскивание | призрак dragged-карточки/шаблона |
| L7 Toasts | тосты | уведомления |
| L8 Debug | отладка | F9 DebugOverlay |

Порядок draw = `UiLayer::DRAW_ORDER`; внутри полосы — порядок сборки кадра.
Новый слой не добавляется «по месту» — только правкой enum + DRAW_ORDER.

## L2. Capture-политики

| Политика | Клики по поверхности | Клики мимо (backdrop) | Примеры |
|---|---|---|---|
| `Block` | перехватывает всё | контракт поверхности (закрыть/глотнуть) | настройки, docs, галерея, онбординг, stage, диалоги |
| `Capture` | по своим hit-rect'ам | уходит ниже | what-if бар, дока палитры, хоткеи-хинт, миникарта |
| `PassThrough` | не перехватывает | уходит ниже | мир |
| `Passive` | нет hit-rect'ов вовсе | уходит ниже | тосты |

`intercept_outside()` — поведение backdrop'а (Block=true, остальные=false).

## L3. Реестр поверхностей — единая точка

`SurfaceDecl { id, layer, capture, keyboard_scope, degradation }`.
Дубликат id — паника на старте. Порядок pick: верхний слой первым; внутри
слоя — обратный порядок регистрации. Ручные z-списки запрещены.

## L4. Клавиатура

- `KeyboardRouter`: стек keyboard-scope, верхний scope глотает свои клавиши;
  дефолтный scope канваса — `KeyboardScopeId::CANVAS`.
- Esc-стек = обратный порядок регистрации Block/scope-поверхностей
  (`esc_stack`) — верхняя модальность закрывается первой.
- FocusRing — Tab-кольцо контент-rect'ов одной поверхности.

## L5. Scissor-политика

Один scissor-rect на полосу слоя; клип никогда не увеличивает видимую
область. Поверхность без `clip` в `SurfaceFrame` не собирается (clip
обязателен).

## L6. Правила проверки

- Пик-матрица: клик под Block/Capture никогда не доходит до канваса
  (юнит-тесты hit.rs).
- Линт G4: 0 пересечений интерактивных rect'ов **разных** поверхностей одного
  слоя; 0 выходов за вьюпорт (3 вьюпорта × RU/EN).
- Пересечения интерактивных rect'ов **одной** поверхности допустимы
  (например чип поверх бара), но порядок внутри поверхности обязан быть
  детерминирован порядком hit-rect'ов.
