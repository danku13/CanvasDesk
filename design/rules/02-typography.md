# 02 — Typography

> Fonts: `crates/canvas-render/src/text.rs` (embedded into the binary, SIL OFL).
> Measurement: `crates/canvas-ui/src/measure.rs` (TextMeasurer). Scale:
> `design/tokens/dimensions.json → typography` ↔ `canvas_core::tokens`.

## T1. Families

| Family | File | Role |
|---|---|---|
| Noto Sans Display (Medium 500) | NotoSansDisplay-Medium.ttf | base UI and canvas text |
| Noto Sans Display (Bold 700) | NotoSansDisplay-Bold.ttf | accent words, block headings |
| Noto Sans Mono (Regular 400) | NotoSansMono-Regular.ttf | Numi lines, results, code fences, table values |
| Noto Sans Mono (Bold 700) | NotoSansMono-Bold.ttf | bold mono spans |
| CanvasDesk Mono Oblique | CanvasDeskMonoOblique.ttf | spilled values (a synthetic 11° oblique — Noto Sans Mono has no official italic; generated by `scripts/gen_oblique_font.py`) |

Parity rule (CR-009): measurement and render must use one (family, weight)
pair — cosmic-text matches the face by the exact weight. The test
`ui_measure_weight_matches_render_attrs` enforces this. Mono in measurement = NORMAL 400,
sans = MEDIUM 500.

## T2. Type scale

World px (scaled by zoom):

| Role | Size | Line height | Usage |
|---|---|---|---|
| title | 16 | 22 | the heading of a node card |
| body | 14 | 20 | node body, prose |
| edge_label | 12 | 16 | edge captions |
| result | 12 | 16 | result lines/footer |
| zone_label | 10.5 | 16 | section captions «ПАРАМЕТРЫ · N» ("PARAMETERS · N") |
| auto_row | — | 18 | auto rows of the body table |

Screen px (not scaled by zoom):

| Role | Size | Line height | Usage |
|---|---|---|---|
| hud | 14 | 18 | the F3 overlay |
| badge | 10 | 12 | badges (severity, what-if deltas) |
| UI screen lines | 13 | 13·1.3≈17 | gallery/list lines |

Screen text: `line_height = size × 1.3` (SCREEN_LINE_FACTOR) — a measurement
constant, not a call parameter.

The screen scale of UI overlays `ui_typography` (tokens.dimensions.json ↔
`canvas_core::tokens` FONT_*; kit and surface sizes, screen px) —
part of the T2 scale, not "outside the scale":

| Token | Size | Usage |
|---|---|---|
| FONT_TITLE_LG | 18 | large headings (onboarding, modals) |
| FONT_BODY | 13 | UI body: captions, list lines, button labels, text field |
| FONT_CAPTION | 11 | sub-labels, banner/chat-bubble/crumbs, hint-caret |
| FONT_HINT | 10 | micro-captions, hints, feature chips |

A new UI size = an edit of the token scale + this table (T5 applies
to it in the same way).

## T3. Typesetting rules

1. Widths for layout — only TextMeasurer (real shaping). No
   `chars × constant`.
2. Truncation — by a deliberate policy: Wrap (wrap), Ellipsis (binary search
   of the prefix + "…"), Clip (clip by the rect). A silent `take()` is forbidden.
3. The caret and word boundaries in fields — in Unicode characters, not in bytes.
4. Text selection — accent α0.35; the `==текст==` highlight — a yellow fill
   [0.85,0.75,0.30,0.30]. Both are slots, not literals.
5. The minimum physical size of a card heading is 4 px; below that — the heading
   is not drawn at all (not "squeezed into mush").
6. An edge caption is drawn on a backing quad with padding [6,3]; the backing —
   the theme's edge_label_fill.
7. A node body table: values/units — mono, right-align on the RowGuides column;
   a badge — a capsule of height `size·1.1 + 6` px.

## T4. Formula segments

Formulas in the node body: operators — the formula_op slot (dark #666A7C / light
#4B5563), functions — formula_fn (dark #C792EA / light #6B21A8). The slots
are derived from the link/quote themes (see 07-theming) — direct value edits
apply to link/quote, not to formula_*.

## T5. Forbidden

- A third font. A new text role = a new line of the T2 scale, not "I'll take
  Helvetica".
- Local letter stretching/compression; letter-spacing is not configurable.
- Text as an image/texture.
- Sizes outside the T2 scale (a new size = an edit of the scale + token).
