# 04 — Контраст и доступность

> Машина: `crates/canvas-render/src/contrast.rs` (WCAG 2.1).
> Триггер: CR-007 — тематический текст на цветных карточках падал до 2.3–4.1:1.

## A1. Цели контраста

| Что | Норма | Стандарт |
|---|---|---|
| Текст на любой заливке | ≥ 4.5:1 | WCAG AA 1.4.3 |
| Графика, несущая смысл (рамки severity, гиды, explain-лист) | ≥ 3:1 | WCAG 1.4.11 |
| Собственные управляемые заливки (self-controlled) | цель 7:1 | WCAG AAA |

Цели зашиты в код (`contrast.rs`, `theme.rs` readable_on_card) и гоняются
контраст-машиной по каждой теме — G3. Новая тема/слот без прохождения G3
не принимается.

## A2. Контраст-машина (auto-contrast)

Для пользовательских заливок карточек (color presets «1–6», цветные фоны)
цвет текста не фиксирован — вычисляется:

1. Если `contrast_ratio(fg, bg) ≥ target` — оставить как есть.
2. Иначе — сдвиг fg к крайнему (чёрному/белому) с сохранением оттенка,
   бинарный поиск до комфортной цели `target + 1.55`.
3. Фолбэк — лучший из ink-кандидатов (чистые чёрный/белый); `pick_ink`
   гарантирует ≥ 4.5:1 против любой заливки (худший случай #777 → 4.66:1).

Правило: компонент никогда не «угадывает» чернила — вызывает
`pick_ink`/`ensure_contrast`, а не делает текст белым по вкусу.

## A3. Hit-зоны (минимальные площади взаимодействия)

| Элемент | Зона |
|---|---|
| Порт связи | 10 px (пресеты 10/14/20/28/40, растёт с зумом, кламп [10,40]) |
| Ребро (тело) | 6 px вокруг оси (или полтолщины + 2) |
| Ресайз-ручка карточки | 16 px угол |
| Hover-пад бейджа ошибки строки | +10 px к габаритам |
| Пункт меню | высота 26 px всей строки, не только текста |

Hit-зона ≥ визуала всегда; hit-rect'ы строятся теми же layout-функциями, что
и отрисовка (П5).

## A4. Клавиатура и фокус

- Рамка фокуса — слот `accent` (паттерн TextField витрины).
- FocusRing: Tab/Shift+Tab по контент-rect'ам поверхности; порядок
  перестраивается с сохранением позиции (`FocusRing::retain_order`).
- Esc-стек закрывает верхнюю Block/scope-поверхность — лестница выводится из
  реестра автоматически.
- В полях: Enter/Ctrl+Enter — коммит, Shift+Enter — перенос, Esc — отмена.
- Undo-глубина редактора — 50.

## A5. Деградация и читаемость

- Ниже минимума поверхности — скрытие целиком (`HideBelow`), не сжатие:
  what-if бар < 900×600; референсы линта 1280×800 / 1024×640 / 800×560.
- Тексты HUD/бейджей имеют тень/подложку для читаемости поверх канваса
  (HUD-тень #101012).
- Минимапа рёбра не рисует при > 500 нод (читаемость важнее полноты).
- Минимальный читаемый кегль заголовка карточки — 4 px физ.; ниже — не рисуем.

## A6. Моушн-доступность

Анимации только подсветки/перемещения камеры, без мигания с высокой
частотой: пульс результата 1200 мс — плавная синусоида альфы, «дыхание»
фокуса 1600 мс. Никаких стробов/резких вспышек в циклах.
