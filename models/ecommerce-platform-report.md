## Стоимость масштабирования

- База: **2122 $/мес** (compute 547.521 + egress 772.476 + storage 12 + managed 790)
- Чёрная пятница ×3: **4515.99 $/мес** (×2.13) — дельта 2393.99 $/мес
- Чёрная пятница ×5: **6909.99 $/мес** (×3.26) — дельта 4787.99 $/мес

Рост суб-линейный по compute (базовая часть БД не масштабируется с трафиком), линейный по egress, ступенчатый по managed-сервисам (коэффициент 0.3).

## Как пользоваться моделью

1. Открыть `models/ecommerce-platform.canvas` в CanvasDesk (десктоп или [web-версия](https://danku13.github.io/CanvasDesk/app/)).
2. What-if: `Ctrl+Shift+I` → чипы «Чёрная пятница ×3» / «×5» → «Сравнить» — дельты по всему графу; файл модели не меняется.
3. Узкие места: `Ctrl+B` — утилизация и перегрузка (ρ ≥ 1) прямо на нодах.
4. Стартовые допущения — только в ноде «Допущения» и «Режим» (`mult`); всё остальное проливается по value-связям.
