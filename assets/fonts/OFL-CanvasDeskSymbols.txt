This file — CanvasDeskSymbols-Regular.ttf — is a DERIVATIVE WORK of three
SIL OFL 1.1 Noto fonts, built as a symbol subset for CanvasDesk (revision
2026-10-02: UI glyphs must render without system font fallback, e.g. in
the wasm build):

  - Noto Sans Symbols 2 Regular — 16 glyphs:
    U+25A6 U+25B2 U+25B4 U+25B8 U+25BC U+25BE U+25CE U+25D0
    U+26A0 U+270E U+2713 U+2715 U+2717 U+2725 U+2726 U+2744
  - Noto Sans Symbols Regular — 2 glyphs:
    U+2699 U+2315
  - Noto Sans Math Regular — 3 glyphs:
    U+21BB U+21C4 U+22EF

Subsets merged with fontTools (fontTools.subset + fontTools.merge), family
renamed. Per the SIL Open Font License Version 1.1, the derivative does NOT
use the Reserved Font Name "Noto" and is distributed under the same license
with the original copyright notice preserved (same practice as
CanvasDeskMonoOblique.ttf, see OFL-CanvasDeskMonoOblique.txt).

These glyphs are the fallback layer for UI strings (check marks, settings
tab glyphs, status symbols) and are covered by the embedded-font regression
test `ui_symbol_glyphs_covered_by_embedded_fonts` (crates/canvas-render).
